# 物质的量

**物质的量 n**：表示含有一定数目粒子的集合体，单位摩尔（mol）。

## 四个核心公式

- `n = N / NA`（NA ≈ 6.02×10²³ mol⁻¹ 阿伏伽德罗常数）
- `n = m / M`（M 摩尔质量，数值上等于相对分子/原子质量）
- `n = V / Vm`（标况下 Vm = 22.4 L/mol，**只适用于气体**）
- `n = c · V`（溶液中：物质的量浓度 × 体积）

## 易错点

- 22.4 L/mol 的使用前提：**标准状况（0℃、101kPa）+ 气体**
- 标况下 H₂O、SO₃、CCl₄、苯不是气体，不能用 22.4
- 1 mol Na₂O₂ 含 3 mol 离子（2Na⁺ + O₂²⁻）

## NA 陷阱速查

- 特殊物质组成：D₂O 中子数、O₃ 与 O₂ 混合物
- 弱电解质电离、盐水解导致离子数偏小
- 可逆反应不能进行到底
