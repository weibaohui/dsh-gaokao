# 化学反应类型

## 概述
化学反应（化学变化）有多种类型。根据反应物和生成物的种类及数目关系，可将化学反应分为不同类型。

## 分解反应
- **定义**：一种物质发生化学反应后生成两种（或两种以上）新物质的化学反应
- **通式**：AB → A + B
- **举例**：
  - 水在电流作用下分解：2H₂O → 2H₂↑ + O₂↑
  - 氧化汞加热分解：2HgO → 2Hg + O₂↑
- **注意**：混和物分离为组分物质不属于化学反应，也不是分解反应

## 化合反应
- **定义**：两种或两种以上的物质生成一种新物质的化学反应
- **通式**：A + B → AB
- **举例**：
  - 氯化氢与氨反应：NH₃ + HCl = NH₄Cl
  - 碳燃烧：C + O₂ = CO₂

## 置换反应
- **定义**：一种单质跟一种化合物反应，生成另一种单质和另一种化合物的化学反应
- **通式**：A + BC → AC + B
- **举例**：
  - 锌跟酸反应：Zn + H₂SO₄ = ZnSO₄ + H₂↑
  - 锌跟硫酸铜反应：Zn + CuSO₄ = ZnSO₄ + Cu

## 复分解反应
- **定义**：两种化合物互相交换成分，生成两种新化合物的化学反应
- **通式**：AB + CD → AD + CB
- **举例**：
  - 碳酸钠跟盐酸反应：Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑

## 化学反应的本质
- 化学反应的本质是物质分子里的原子重新组合成另一些新的分子
- 反应过程中分子改变，但原子本身不发生变化
- 原子是物质发生化学变化的最小单位
