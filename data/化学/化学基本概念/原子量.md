# 原子量

## 定义
以1个碳原子（碳12）质量的1/12作为标准比较而得的相对重量。

## 标准
- 统一将碳12（¹²C）的质量定为12
- 以碳12一个原子质量的1/12作为比较标准
- 原子量是相对重量，没有单位

## 常见原子量
| 元素 | 符号 | 原子量 |
|---|---|---|
| 氢 | H | 1 |
| 碳 | C | 12 |
| 氮 | N | 14 |
| 氧 | O | 16 |
| 钠 | Na | 23 |
| 镁 | Mg | 24 |
| 铝 | Al | 27 |
| 硫 | S | 32 |
| 氯 | Cl | 35.5 |
| 钾 | K | 39 |
| 钙 | Ca | 40 |
| 铁 | Fe | 56 |
| 铜 | Cu | 63.5 |
| 锌 | Zn | 65 |

## 原子的实际重量（参考）
- 1个碳12原子 = 1.994×10⁻²³克
- 1个氧16原子 = 2.657×10⁻²³克
- 1个氢1原子 = 1.661×10⁻²⁴克
- 用"克"做单位太不便，故用相对重量表示

## 与分子量的关系
- 分子量 = 组成分子的所有原子的原子量的总和
- 原子量是计算分子量的基础
