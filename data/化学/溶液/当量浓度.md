# 当量浓度

## 定义
用1升（即1000毫升）溶液中所溶解的溶质克当量个数来表示的溶液浓度，称为**当量浓度**。符号为N。

## 公式
$$\text{当量浓度}(N) = \frac{\text{溶质的克当量数}}{\text{溶液的升数}}$$

即：溶质克当量数 = 当量浓度 × 溶液升数

## 当量的概念
- **元素的当量**：元素在化合物中的当量 = 原子量 / 化合价
- **酸的当量**：酸的当量 = 酸的分子量 / 参与反应的氢离子数（即被置换的H⁺数）
- **碱的当量**：碱的当量 = 碱的分子量 / 参与反应的氢氧根数（即被置换的OH⁻数）
- **盐的当量**：盐的当量 = 盐的分子量 / 盐中正价（或负价）总数

## 与克分子浓度的关系
$$\text{当量浓度}(N) = \text{克分子浓度}(M) \times n$$

其中n为每分子溶质所提供的H⁺（或OH⁻）数或化合价总数。

### 举例
- HCl：1分子提供1个H⁺，故 N = M
- H₂SO₄：1分子提供2个H⁺，故 N = 2M
- NaOH：1分子提供1个OH⁻，故 N = M
- Na₂CO₃：1分子提供2个正价，故 N = 2M

## 重要特点
- 体积相同、当量浓度也相同的任何溶液中，溶质的克当量数相同
- 在化学反应中，两种物质完全反应时，它们的克当量数相等（当量定律）
- 即：N₁ × V₁ = N₂ × V₂

## 在酸碱中和反应中的应用
酸和碱完全中和时：酸的克当量数 = 碱的克当量数
$$N_{\text{酸}} \times V_{\text{酸}} = N_{\text{碱}} \times V_{\text{碱}}$$

## 与其他浓度的比较

| | 百分比浓度 | 克分子浓度 | 当量浓度 |
|------|----------|----------|----------|
| 定义 | 100重量单位溶液里溶质重量单位数 | 1升溶液里溶质克分子个数 | 1升溶液里溶质克当量个数 |
| 公式 | (溶质重量/溶液重量)×100% | 溶质克分子数/溶液升数 | 溶质克当量数/溶液升数 |
| 符号 | % | M | N |
| 特点 | 重量相同→溶质重量相同 | 体积相同→分子数相同 | 体积相同→当量数相同 |
| 反应计算 | 不便 | 需看系数比 | 直接用N₁V₁=N₂V₂ |

## 优点
- 在化学反应（尤其是酸碱中和、氧化还原）的计算中极为方便
- 不需要考虑化学方程式中分子式前的系数，因为反应物之间的克当量数相等
- 广泛应用于容量分析（滴定分析）
