# 氢氧化铝

## 名称与性质
- 化学式：Al(OH)₃。
- 外观为白色凝胶状沉淀，难溶于水（其溶解度比 Mg(OH)₂ 还要低）。
- 无法通过 Al₂O₃ 与水直接化合来制备（这一点与一般不溶性碱的制备方法一致）。

## 制法
可由铝盐溶液与可溶性碱反应来制备：
- Al₂(SO₄)₃ + 6NaOH = 2Al(OH)₃↓ + 3Na₂SO₄
- AlCl₃ + 3NaOH = Al(OH)₃↓ + 3NaCl
- 离子方程式：Al³⁺ + 3OH⁻ = Al(OH)₃↓

## 受热分解
经强热灼烧后即分解为纯净的氧化铝：
- 2Al(OH)₃ →(灼热) Al₂O₃ + 3H₂O

## 化学性质（典型的两性氢氧化物）
Al(OH)₃ 既能与酸发生中和反应而溶解，产物为铝盐和水；也能与碱发生中和反应而溶解，产物为偏铝酸盐和水（在此情况下氢氧化铝表现出酸性，可写作 H₃AlO₃）。

### 与酸反应
- Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O

### 与碱反应
- H₃AlO₃ + NaOH = NaAlO₂ + 2H₂O

## 两性的本质（动态平衡）
氢氧化铝在水中虽然难溶，但也并非完全不溶。在溶液中存在以下动态平衡：
```
Al³⁺ + 3OH⁻  ⇌  Al(OH)₃  ⇌  H₃AlO₃  ⇌  3H⁺ + AlO₂⁻ + H₂O
```

- **加酸时**：H⁺ 与 OH⁻ 结合成水，使 OH⁻ 浓度大幅下降，平衡向**左**移动，反应趋于完全；
- **加碱时**：OH⁻ 与 H⁺ 结合成水，使 H⁺ 浓度大幅下降，平衡向**右**移动，反应趋于完全。

需要指出：在未遇酸或碱的情况下，Al(OH)₃ 的两种电离趋势都极其微弱，普通指示剂既检测不出碱性也检测不出酸性。其碱性仅在遇到酸时才表现出来，酸性仅在遇到碱时才表现出来。且**氢氧化铝的酸性比碱性更弱**。
