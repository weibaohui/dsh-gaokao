# 氢氧化铝

## 名称与性质
- 化学式：Al(OH)₃。
- 白色凝胶状沉淀，不溶于水（溶解度比 Mg(OH)₂ 更小）。
- 不能由 Al₂O₃ 跟水直接化合制得（与一般不溶性碱的制法相同）。

## 制法
由铝盐跟可溶性碱反应制得：
- Al₂(SO₄)₃ + 6NaOH = 2Al(OH)₃↓ + 3Na₂SO₄
- AlCl₃ + 3NaOH = Al(OH)₃↓ + 3NaCl
- 离子方程式：Al³⁺ + 3OH⁻ = Al(OH)₃↓

## 受热分解
灼热即分解成纯净的氧化铝：
- 2Al(OH)₃ →(灼热) Al₂O₃ + 3H₂O

## 化学性质（典型的两性氢氧化物）
Al(OH)₃ 既能跟酸反应（中和）而溶解，生成铝盐和水；又能跟碱反应（中和）而溶解，生成偏铝酸盐和水（此时氢氧化铝作为酸，可写成 H₃AlO₃）。

### 与酸反应
- Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O

### 与碱反应
- H₃AlO₃ + NaOH = NaAlO₂ + 2H₂O

## 两性的本质（动态平衡）
氢氧化铝虽难溶于水，但并非绝对不溶。在溶液里存在如下动态平衡：
```
Al³⁺ + 3OH⁻  ⇌  Al(OH)₃  ⇌  H₃AlO₃  ⇌  3H⁺ + AlO₂⁻ + H₂O
```

- **加入酸时**：H⁺ 与 OH⁻ 结合为水，OH⁻ 大减，平衡**左移**，反应近完全；
- **加入碱时**：OH⁻ 与 H⁺ 结合成水，H⁺ 大减，平衡**右移**，反应近完全。

应指出：当 Al(OH)₃ 不与酸或碱相遇时，两种电离趋势都极弱；用一般指示剂既检验不出碱性也检验不出酸性。其碱性只有在跟酸反应时才显现，酸性只有在跟碱反应时才显现。**氢氧化铝的酸性比碱性更弱**。
