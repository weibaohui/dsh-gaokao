# 铝热法

## 定义

利用铝夺取金属氧化物中的氧，将金属离子还原出来以冶炼高熔点金属的方法，称为**铝热法**。

## 原理

- 铝与氧极易化合，且化合过程中释放大量热（每克铝氧化放热 7.47 千卡）
- 反应释放的大量热使还原出的金属呈熔融状态，从而与炉渣分离

## 实例

- 炼铬：`2Al + Cr₂O₃ = Al₂O₃ + 2Cr`
- 炼锰：`8Al + 3Mn₃O₄ = 4Al₂O₃ + 9Mn`
- 铝热剂焊接钢轨：铝粉 + Fe₃O₄（按 1:3 比例）+ 过氧化钡助燃剂，用镁带引燃
  - `8Al + 3Fe₃O₄ = 4Al₂O₃ + 9Fe + 795千卡`
  - 反应温度可达 3500 °C，铁呈熔融状态，用于焊接钢轨（铝焊接术）

## 用途

- 冶炼高熔点金属（铬、锰、钨等）
- 焊接钢轨（铝焊接术）
- 制造照明弹、信号弹
