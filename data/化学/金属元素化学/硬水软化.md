# 硬水软化

## 定义
在将硬水投入使用之前，通过适当处理手段去除或减少其中的 Ca²⁺ 和 Mg²⁺ 离子含量，使水的硬度降低，这一过程称为硬水软化。

## 一、暂时硬水的软化方法

### 1. 加热煮沸法
- 利用酸式碳酸盐的热不稳定性，加热使其分解为难溶碳酸盐沉淀而去除：
  - Ca(HCO₃)₂ →(加热) CaCO₃↓ + CO₂↑ + H₂O
  - Mg(HCO₃)₂ →(加热) MgCO₃↓ + CO₂↑ + H₂O
- 不足之处：大规模处理时燃料消耗量大，经济性差。

### 2. 加碱法（石灰法）
向暂时硬水中加入适量碱液，使酸式碳酸盐转化为难溶碳酸盐沉淀。工业上通常采用消石灰（成本最低的碱）来软化暂时硬水：
- Mg(HCO₃)₂ + Ca(OH)₂ = MgCO₃↓ + CaCO₃↓ + 2H₂O
- 离子方程式：Ca²⁺ + CO₃²⁻ = CaCO₃↓；Mg²⁺ + CO₃²⁻ = MgCO₃↓

**消石灰的用量必须严格控制**（需先分析水样以确定用量）：若消石灰过量则会引入新的 Ca²⁺，反而达不到软化效果。若以 NaOH 替代消石灰则无此弊端，但成本较高。

加碱法与加热法的基本原理相同：都是促使 Ca²⁺、Mg²⁺ 与 CO₃²⁻ 结合形成难溶碳酸盐沉淀。

## 二、永久硬水的软化法

加热煮沸法无法软化永久硬水。加碱虽能使 Mg²⁺ 形成 Mg(OH)₂ 沉淀，但 Ca²⁺ 仍无法去除（因 Ca(OH)₂ 溶解度较大，不会析出）。

### 1. 加纯碱法
纯碱在水中电离产生大量 CO₃²⁻，与硬水中的 Ca²⁺、Mg²⁺ 结合生成难溶的 CaCO₃ 和 MgCO₃ 沉淀：
- Ca²⁺ + CO₃²⁻ = CaCO₃↓
- Mg²⁺ + CO₃²⁻ = MgCO₃↓

加入纯碱可同时降低暂时硬度和永久硬度。再投入适量明矾助沉，经沉降或过滤后即可获得洁净的软水。

### 2. 离子交换法（人造沸石法）
现代工业广泛采用"软化剂"来软化硬水。人造沸石是一种不溶于水的铝硅酸钠盐（Na₂O·Al₂O₃·2SiO₂，可简写为 Na₂Z）。

当硬水流经人造沸石时，水中的 Ca²⁺、Mg²⁺ 与 Na⁺ 发生交换：
- Na₂Z + Ca²⁺ = CaZ + 2Na⁺
- Na₂Z + Mg²⁺ = MgZ + 2Na⁺

当 Na⁺ 被全部置换后，沸石便失去软化能力，此时可用 10% 的食盐溶液通过使其再生：
- CaZ + 2Na⁺ = Na₂Z + Ca²⁺
- MgZ + 2Na⁺ = Na₂Z + Mg²⁺
随后用水冲洗排除置换出的钙盐和镁盐，即可恢复软化能力。

人造沸石法能同时降低暂时硬度和永久硬度，操作简便、占地面积小，仅消耗食盐溶液，经济性较好。
