# 硬水软化

## 定义
在使用硬水之前，加以适当处理，除去或减少硬水里所含的 Ca²⁺ 离子和 Mg²⁺ 离子，降低水的硬性，称为硬水的软化。

## 一、暂时硬水的软化方法

### 1. 加热煮沸法
- 利用酸式碳酸盐不稳定，加热分解为难溶碳酸盐沉淀而除去：
  - Ca(HCO₃)₂ →(加热) CaCO₃↓ + CO₂↑ + H₂O
  - Mg(HCO₃)₂ →(加热) MgCO₃↓ + CO₂↑ + H₂O
- 缺点：处理大量水时消耗很多燃料，不经济。

### 2. 加碱法（石灰法）
在暂时硬水里加适量碱，使酸式碳酸盐变难溶碳酸盐沉淀。工业上常用消石灰（最廉价碱）软化暂时硬水：
- Mg(HCO₃)₂ + Ca(OH)₂ = MgCO₃↓ + CaCO₃↓ + 2H₂O
- 离子方程式：Ca²⁺ + CO₃²⁻ = CaCO₃↓；Mg²⁺ + CO₃²⁻ = MgCO₃↓

**石灰用量必须适量**（须先分析水样确定用量）：过量消石灰会引入新的 Ca²⁺，仍达不到软化目的。若用 NaOH 代替消石灰无此缺点，但价格较高。

加碱法与加热法的实质相似：都是使 Ca²⁺、Mg²⁺ 与 CO₃²⁻ 结合成难溶碳酸盐沉淀。

## 二、永久硬水的软化法

加热煮沸法不能使永久硬水软化。加碱虽能使 Mg²⁺ 变成 Mg(OH)₂ 沉淀，但 Ca²⁺ 仍不能除去（Ca(OH)₂ 溶解度较大不析出）。

### 1. 加纯碱法
纯碱在水溶液里电离生成大量 CO₃²⁻，与硬水中 Ca²⁺、Mg²⁺ 结合成难溶 CaCO₃ 和 MgCO₃ 沉淀：
- Ca²⁺ + CO₃²⁻ = CaCO₃↓
- Mg²⁺ + CO₃²⁻ = MgCO₃↓

加入纯碱可使暂时硬性和永久硬性一起降低。再加入适量明矾，沉降或过滤后得洁净软水。

### 2. 离子交换法（人造沸石法）
现代工业广泛使用"软化剂"软化硬水。人造沸石是一种不溶于水的铝硅酸钠盐（Na₂O·Al₂O₃·2SiO₂ 或写成 Na₂Z）。

把硬水通过人造沸石时，Ca²⁺、Mg²⁺ 与 Na⁺ 进行交换：
- Na₂Z + Ca²⁺ = CaZ + 2Na⁺
- Na₂Z + Mg²⁺ = MgZ + 2Na⁺

当 Na⁺ 全部被代替后失去能力，可用 10% 食盐溶液通过使其再生：
- CaZ + 2Na⁺ = Na₂Z + Ca²⁺
- MgZ + 2Na⁺ = Na₂Z + Mg²⁺
再用水冲洗掉代替出来的钙盐、镁盐，恢复软化能力。

人造沸石法能把暂时硬性和永久硬性都降低，手续简便，占地小，只消耗食盐溶液，比较经济。
