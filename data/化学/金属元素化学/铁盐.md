# 铁盐

## 定义
铁盐是指铁处于 +3 价时所形成的盐类（即 Fe³⁺ 对应的盐），通常在铁与强氧化剂（如氯气）作用时生成。

## 重要铁盐

### 氯化铁 FeCl₃
- **性质**：外观为棕黑色固体；含 6 个结晶水的六水合物呈深黄色，易潮解；
- **还原反应**：遇还原剂（如 H₂、Fe 等）可被还原为氯化亚铁：
  - 2FeCl₃ + H₂ = 2FeCl₂ + 2HCl
  - 2FeCl₃ + Fe = 3FeCl₂
- **制法**：
  - 氧化铁与盐酸反应：Fe₂O₃ + 6HCl = 2FeCl₃ + 3H₂O
  - 氯化亚铁与氯气反应：2FeCl₂ + Cl₂ = 2FeCl₃
- **用途**：在医药上用作止血剂；在染料工业中用作氧化剂。

### 硫酸铁 Fe₂(SO₄)₃
- 硫酸亚铁在空气中容易氧化为黄褐色的硫酸铁：
  - 空气中 FeSO₄ → Fe₂(SO₄)₃（晶体失水并氧化）

### 铁铵矾 (NH₄)₂SO₄·Fe₂(SO₄)₃·24H₂O 或 NH₄Fe(SO₄)₂·12H₂O
- 属于一种**矾**（参见 [[铝盐]]）：由 1 价 NH₄⁺ 与 3 价 Fe³⁺ 共同形成的复盐。

## 铁盐的检验
可利用无色的**硫氰化钾（KCNS）溶液**来检验可溶性铁盐（Fe³⁺）：
- 向铁盐溶液中滴入数滴 KCNS 溶液，溶液立即变为深红色，这是因为生成了深红色的硫氰化铁 Fe(CNS)₃；
- 化学方程式：FeCl₃ + 3KCNS = Fe(CNS)₃ + 3KCl
- 离子方程式：**Fe³⁺ + 3CNS⁻ = Fe(CNS)₃**
- **亚铁盐遇 KCNS 不显红色**——这是鉴别 Fe²⁺ 与 Fe³⁺ 的重要方法。

## 外观颜色
- 铁盐（Fe³⁺）的水溶液呈棕黄色；
- 亚铁盐（Fe²⁺）的水溶液呈浅绿色。

## Fe²⁺ ⇌ Fe³⁺ 的相互转化
- 在氧化剂作用下 Fe²⁺ → Fe³⁺；
- 在还原剂作用下 Fe³⁺ → Fe²⁺；
- 这是 +2 价铁与 +3 价铁在一定条件下可相互转化的典型实例。
