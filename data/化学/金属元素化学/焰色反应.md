# 焰色反应

## 定义

某些金属或其化合物在无色火焰中灼烧时，会使火焰呈现出该金属所特有的颜色，这种反应称为**焰色反应**。可用于检验金属离子的存在。

## 操作方法

- 取一根光洁无锈的铁丝（最好用铂丝），蘸取少量盐酸清洗表面
- 再蘸取待测晶体或溶液，置于无色火焰中灼烧
- 观察火焰所呈现的特征颜色

## 常见金属的焰色

| 金属 | 焰色 |
|------|------|
| 钠 | 黄色 |
| 钾 | 紫色 |
| 钙 | 砖红色 |
| 锶 | 洋红色 |
| 钡 | 黄绿色 |

## 注意

- 钠盐的焰色反应极为灵敏，即使含量极微也能产生鲜明的黄色火焰
- 检验钾盐时必须隔着蓝色钴玻璃观察（钴玻璃可吸收钠产生的黄色光，从而排除钠的干扰）
