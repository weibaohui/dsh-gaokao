# 焰色反应

## 定义

某些金属或金属化合物在无色火焰中灼烧时，火焰呈现特征颜色的反应，叫做**焰色反应**。用于检验金属离子。

## 操作方法

- 用光洁无锈的铁丝（最好铂丝）蘸取少量盐酸洗净
- 沾取晶体或溶液，在无色火焰中灼烧
- 观察火焰呈现的特征颜色

## 常见金属的焰色

| 金属 | 焰色 |
|------|------|
| 钠 | 黄色 |
| 钾 | 紫色 |
| 钙 | 砖红色 |
| 锶 | 洋红色 |
| 钡 | 黄绿色 |

## 注意

- 钠盐反应很灵敏，即使微量也产生强烈黄色火焰
- 检验钾盐须隔蓝色钴玻璃观察（吸收钠的黄色光，排除钠的干扰）
