# 钙的化合物

## 一、氧化钙 CaO（生石灰 / 石灰）
- 白色固体，由碳酸钙经强热分解制得：CaCO₃ →(煅烧) CaO + CO₂↑（工业上以石灰石在窑中煅烧进行大规模生产）。
- 极易与水反应（该过程称为石灰的**消化或熟化**）：CaO + H₂O = Ca(OH)₂，反应放出大量热，水蒸气逸出，体积显著膨胀。
- 吸湿性很强，可用作干燥剂（前提是被干燥气体不与 CaO 或 Ca(OH)₂ 反应）。
- 运输石灰时必须防止雨淋或受潮，否则可能引起燃烧或损坏运输工具。

## 二、氢氧化钙 Ca(OH)₂（消石灰 / 熟石灰）
- 白色粉末状固体，在水中溶解度不大（但比 Mg(OH)₂ 的溶解度大）。
- **石灰乳**：将 Ca(OH)₂ 在水中搅动后所得的乳白色悬浊液。
- **石灰水**：石灰乳静置后上层的澄清液体，即 Ca(OH)₂ 的饱和溶液。
- 属于中等强度的碱，电离方式为 Ca(OH)₂ = Ca²⁺ + 2OH⁻；OH⁻ 浓度有限，碱性远弱于 NaOH、KOH。
- 具有可溶性碱的通性。易与 CO₂（酸性氧化物）反应生成 CaCO₃ 沉淀，使石灰水变浑浊：
  - Ca²⁺ + 2OH⁻ + CO₂ = CaCO₃↓ + H₂O（可用于检验 CO₂）
- 盛放石灰水的试剂瓶使用后须立即盖紧（防止吸收空气中的 CO₂）。
- 用途：建筑材料（消石灰 + 砂 + 水 = "三合土"，用于粘合砖石，吸收 CO₂ 后生成 CaCO₃ 晶体而硬化）；"石灰肥料"（降低酸性土壤的酸度、改良土壤结构、提高肥力、促进微生物繁殖）；注意不可与氨态氮肥同时施用（会生成 NH₃ 逸散）；防治农作物病虫害，用于配制波尔多液、石灰硫黄合剂。

## 三、碳化钙 CaC₂（电石）
- 工业上以焦炭在电炉中（3000 °C）还原生石灰制得：3C + CaO →(强热) CaC₂ + CO↑。
- 纯 CaC₂ 为无色透明固体；工业品因含杂质而呈暗灰色，质地粗松坚硬。
- 遇水立即反应生成乙炔（电石气）和氢氧化钙：CaC₂ + 2H₂O = C₂H₂↑ + Ca(OH)₂。
- 是重要的工业原料。

## 四、钙盐
### 1. 碳酸钙 CaCO₃
- 是自然界分布最广的碳酸盐。纯净者为白色粉末，性质与 MgCO₃ 相似，不溶于水。
- 可溶于含 CO₂ 的水中，生成可溶性碳酸氢钙：CaCO₃ + H₂O + CO₂ = Ca(HCO₃)₂。
- 天然产的石灰石、大理石、白垩是重要的建筑材料。
- 石灰石还可用作炼铁熔剂，以及制造生石灰、CO₂、玻璃等；碾米时加入少量石灰石粉末可防止米粒破裂。

### 2. 硫酸钙 CaSO₄
- **石膏**：天然产的含 2 个结晶水的硫酸钙 CaSO₄·2H₂O。
- 加热至 180 °C 时失去 3/4 的结晶水，转变为**烧石膏** [(CaSO₄)₂·H₂O]：2CaSO₄·2H₂O →(180 °C) (CaSO₄)₂·H₂O + 3H₂O。
- 烧石膏能与水重新化合恢复为石膏，硬化速度快且伴有轻微膨胀，可用于制作石膏像、石膏模型以及外科固定绷带。
- 若加热至 200 °C 以上则全部结晶水脱去，成为无水 CaSO₄，称为"过烧石膏"或"焦石膏"，无法再吸水硬化。
