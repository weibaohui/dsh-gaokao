# 钙的化合物

## 一、氧化钙 CaO（生石灰 / 石灰）
- 白色固体，由碳酸钙强热分解制得：CaCO₃ →(煅烧) CaO + CO₂↑（工业上用石灰石在窑内煅烧大量生产）。
- 极易跟水反应（叫石灰的**消化或熟化**）：CaO + H₂O = Ca(OH)₂，放出大量热，水蒸气逸出，体积增大很多。
- 吸湿性强，可作干燥剂（被干燥气体不能与 CaO 或 Ca(OH)₂ 反应）。
- 运输石灰时须防止被雨淋湿或着水，否则会引起着火燃烧或损坏运输工具。

## 二、氢氧化钙 Ca(OH)₂（消石灰 / 熟石灰）
- 白色粉末状固体，水中溶解度不大（但比 Mg(OH)₂ 大）。
- **石灰乳**：Ca(OH)₂ 在水中搅动所得乳白色悬浊液。
- **石灰水**：石灰乳静置后上层澄清液体，是 Ca(OH)₂ 饱和溶液。
- 是中等强度碱，电离 Ca(OH)₂ = Ca²⁺ + 2OH⁻；OH⁻ 浓度不大，碱性比 NaOH、KOH 弱得多。
- 具可溶性碱的通性。易与 CO₂（酸性氧化物）反应生成 CaCO₃ 沉淀使石灰水变浑浊：
  - Ca²⁺ + 2OH⁻ + CO₂ = CaCO₃↓ + H₂O（用于检验 CO₂）
- 盛石灰水的试剂瓶用毕须立即盖紧（防空气 CO₂）。
- 用途：建筑材料（消石灰 + 砂 + 水 = "三合土"粘合砖石，吸收 CO₂ 变 CaCO₃ 晶体结硬块）；"石灰肥料"（降酸性土壤酸性、改进土壤结构、增高肥力、促微生物繁殖）；不能与氨态氮肥同时使用（生成 NH₃ 逸散）；防治农作物病虫害，配制波尔多液、石灰硫黄合剂。

## 三、碳化钙 CaC₂（电石）
- 工业上用焦炭在电炉（3000 °C）还原生石灰制得：3C + CaO →(强热) CaC₂ + CO↑。
- 纯 CaC₂ 为无色透明固体；工业品因含杂质呈暗灰色粗松坚硬物质。
- 遇水立即反应生成乙炔（电石气）和氢氧化钙：CaC₂ + 2H₂O = C₂H₂↑ + Ca(OH)₂。
- 是重要的工业原料。

## 四、钙盐
### 1. 碳酸钙 CaCO₃
- 自然界分布最广的碳酸盐。纯净者为白色粉末，性质与 MgCO₃ 相似，不溶于水。
- 溶于含 CO₂ 的水生成可溶性碳酸氢钙：CaCO₃ + H₂O + CO₂ = Ca(HCO₃)₂。
- 天然产的石灰石、大理石、白垩是重要建筑材料。
- 石灰石可用作炼铁熔剂、制造生石灰、CO₂、玻璃等；辗米加少量石灰石粉末防米粒破裂。

### 2. 硫酸钙 CaSO₄
- **石膏**：天然产含 2 个分子结晶水的 CaSO₄·2H₂O。
- 加热到 180 °C 失结晶水 3/4 成**烧石膏** [(CaSO₄)₂·H₂O]：2CaSO₄·2H₂O →(180 °C) (CaSO₄)₂·H₂O + 3H₂O。
- 烧石膏能跟水化合重新变成石膏，很快硬化并稍稍膨胀，用于塑石膏像、制石膏模型、外科固定绷带。
- 加热 200 °C 以上失全部结晶水成无水 CaSO₄，称"过烧石膏"或"焦石膏"，不能再吸水硬化。
