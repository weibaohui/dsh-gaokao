# 镁

## 物理性质
银白色轻金属，即使在粉末状态下仍能保持金属光泽。熔点 651 °C（介于锌的 419 °C 和铝的 660 °C 之间）。

## 化学性质
镁是化学性质较活泼的金属，在金属活动性顺序中仅次于 K、Na、Ca 等少数几种。反应时失去最外层的 2 个电子形成 Mg²⁺。

1. **跟氧反应**：
   - 常温下与空气中的氧缓慢反应，表面生成致密的氧化膜，保护内层金属不再继续氧化，因此镁可以保存在空气中；
   - 在空气中加热时剧烈燃烧，发出含紫外线的强白光（由 MgO 微粒灼热至白炽状态所致）：2Mg + O₂ = 2MgO；
   - 能夺取某些氧化物中的氧：2Mg + CO₂ = 2MgO + C（将燃烧的镁条放入 CO₂ 中仍能继续燃烧，同时析出黑色碳）。
2. **跟卤素、硫、氮气反应**：常温下与氯反应；加热时与溴、硫、氮直接化合。
   - Mg + Br₂ = MgBr₂
   - 3Mg + N₂ = Mg₃N₂（镁在空气中燃烧时会有少量生成）
3. **跟水、稀酸反应**：
   - 与冷水反应缓慢，与热水反应较显著：Mg + 2H₂O = Mg(OH)₂ + H₂↑（加酚酞变红，呈碱性）
   - 与稀盐酸或稀硫酸反应剧烈：Mg + 2H⁺ = Mg²⁺ + H₂↑

## 自然界存在
镁以化合态存在，是地壳中分布较广的元素之一。主要矿物有：菱镁矿（MgCO₃）、白云石（CaCO₃·MgCO₃）、光卤石（KCl·MgCl₂·6H₂O）、滑石（3MgO·4SiO₂·H₂O）、石棉（CaO·3MgO·4SiO₂）。海水中含有少量 MgCl₂（导致苦味）。土壤中含有镁盐，镁是构成植物叶绿素的重要成分。

## 制法
工业上通常采用电解熔融氯化镁的方法：将脱去结晶水的光卤石加热熔化后进行电解。
- MgCl₂ = Mg²⁺ + 2Cl⁻
- 阴极：Mg²⁺ + 2e → Mg
- 阳极：2Cl⁻ - 2e → Cl₂↑
- 总反应：MgCl₂ →(熔融电解) Mg + Cl₂↑

## 用途
- 制造轻合金："电子合金"含 80% 镁及微量 Al、Cu、Mn，比重仅 1.8，兼具较高的硬度和韧性，广泛用于飞机和汽车制造；
- 制造球墨铸铁：在生铁中加入 0.05% 的镁，可使其抗拉强度和耐磨性接近钢；
- 镁粉用作发光剂：制造照明弹以及照相照明（闪光粉由镁粉 + 氯酸钾组成）。
