# 镁

## 物理性质
银白色轻金属，粉末状态仍能保持金属光泽。熔点 651 °C（介于锌 419 °C 和铝 660 °C 之间）。

## 化学性质
镁是相当活动的金属，在金属活动顺序里仅次于 K、Na、Ca 等少数几种。失去最外层 2 个电子成 Mg²⁺。

1. **跟氧反应**：
   - 常温下与空气中氧缓慢作用，表面生成致密氧化膜保护内层不再氧化，可保存在空气里；
   - 在空气中加热能剧烈燃烧，发出含紫外线的强白光（MgO 微粒灼热白炽所致）：2Mg + O₂ = 2MgO；
   - 能夺取某些氧化物中的氧：2Mg + CO₂ = 2MgO + C（燃着的镁条放进 CO₂ 中仍继续燃烧，同时析出黑色碳）。
2. **跟卤素、硫、氮气反应**：常温与氯反应；加热与溴、硫、氮直接化合。
   - Mg + Br₂ = MgBr₂
   - 3Mg + N₂ = Mg₃N₂（镁在空气里燃烧时少量生成）
3. **跟水、稀酸反应**：
   - 与冷水反应缓慢，与热水反应显著：Mg + 2H₂O = Mg(OH)₂ + H₂↑（酚酞变红，呈碱性）
   - 与稀盐酸或稀硫酸反应剧烈：Mg + 2H⁺ = Mg²⁺ + H₂↑

## 自然界存在
化合态存在，地壳中分布广的元素之一。主要矿物：菱镁矿（MgCO₃）、白云石（CaCO₃·MgCO₃）、光卤石（KCl·MgCl₂·6H₂O）、滑石（3MgO·4SiO₂·H₂O）、石棉（CaO·3MgO·4SiO₂）。海水含少量 MgCl₂（味苦）。土壤含镁盐，镁是构成植物叶绿素的重要成分。

## 制法
工业上常用电解熔融氯化镁：将脱去结晶水的光卤石加热熔化后电解。
- MgCl₂ = Mg²⁺ + 2Cl⁻
- 阴极：Mg²⁺ + 2e → Mg
- 阳极：2Cl⁻ - 2e → Cl₂↑
- 总反应：MgCl₂ →(熔融电解) Mg + Cl₂↑

## 用途
- 制造轻合金："电子合金"含 80% 镁及微量 Al、Cu、Mn，比重 1.8，硬度和韧性大，广泛用于飞机和汽车制造；
- 制球墨铸铁：在生铁里加 0.05% 镁，抗拉强度、耐磨性接近钢；
- 镁粉作发光剂：照明弹制造、照相照明（闪光粉为镁粉 + 氯酸钾）。
