# 铁的氧化物

## 概述
铁能形成 +2 价和 +3 价两类化合物，其氧化物共有氧化亚铁、氧化铁、四氧化三铁三种。

## 一、氧化亚铁 FeO（黑色）
- 铁在空气中灼热或在氧气中燃烧时，与 Fe₂O₃ 同时生成：
  - 2Fe + O₂ →(灼热) 2FeO
- 黑色固体。

## 二、氧化铁 Fe₂O₃（红色）
- 铁在空气中灼热或在氧气中燃烧时生成：
  - 4Fe + 3O₂ = 2Fe₂O₃
- 红色固体。

## 三、四氧化三铁 Fe₃O₄（暗褐色）
- FeO 与 Fe₂O₃ 结合形成暗褐色的 Fe₃O₄；
- 可视为 FeO·Fe₂O₃，其中 2 个铁原子为 +3 价，1 个铁原子为 +2 价；
- 锤击赤热铁时产生的"铁渣"即 Fe₃O₄；
- 赤热的铁与水蒸气反应也生成 Fe₃O₄：3Fe + 4H₂O →(高温) Fe₃O₄ + 4H₂↑。

## 还原反应
氧化铁在高温下与氢气或一氧化碳反应，可被还原为氧化亚铁乃至铁：
- Fe₂O₃ + 3H₂ →(高温) 2Fe + 3H₂O
- Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂↑

## 共同性质
- 三种氧化物均不溶于水，且与水不发生反应；
- 都属于**碱性氧化物**，能与酸反应生成盐：
  - FeO + H₂SO₄ = FeSO₄ + H₂O
  - Fe₂O₃ + 6HCl = 2FeCl₃ + 3H₂O

## 涉及的氧化-还原过程（FeO 与 Fe₂O₃ 互变）
- 3Fe₂O₃ + CO →(高温) 2Fe₃O₄ + CO₂↑（赤铁矿被 CO 第一步还原）
- Fe₃O₄ + CO →(高温) 3FeO + CO₂↑
- FeO + CO →(高温) Fe + CO₂↑（最终还原出铁）
