# 亚铁盐

## 定义
亚铁盐是指铁处于 +2 价时所形成的盐类（即 Fe²⁺ 对应的盐），通常在铁与氧化能力较弱的物质（如硫、稀酸）作用时生成。在此过程中，铁原子从最外层失去 2 个电子而转变为 Fe²⁺。

## 重要亚铁盐

### 硫酸亚铁 FeSO₄
- 俗称**绿矾**的是七水合硫酸亚铁晶体 FeSO₄·7H₂O，外观呈浅绿色，在水中溶解度很大；
- 放置在空气中时容易脱去结晶水，并逐步被氧化为黄褐色的硫酸铁 Fe₂(SO₄)₃；
- 制备途径：铁屑与稀硫酸反应即可得到：Fe + H₂SO₄(稀) = FeSO₄ + H₂↑；
- 应用方面：可用于防治农业害虫，也可用于制备颜料和墨水，染色工艺中充当媒染剂。

### 氯化亚铁 FeCl₂
- 可通过还原剂（如 H₂、Fe 等）作用于氯化铁来制备：
  - 2FeCl₃ + H₂ = 2FeCl₂ + 2HCl
  - 2FeCl₃ + Fe = 3FeCl₂
- 若遇氯气则又被氧化为氯化铁：2FeCl₂ + Cl₂ = 2FeCl₃。

## 性质要点
- 亚铁盐的水溶液呈现浅绿色，而铁盐（Fe³⁺）溶液则呈棕黄色；
- 向亚铁盐中滴加 KCNS 溶液不会出现红色，这一点可与 Fe³⁺ 加以鉴别；
- 亚铁盐在空气中易被氧化，逐步转变为对应的 +3 价铁盐。

## Fe²⁺ 与 Fe³⁺ 的相互转化
**核心规律**：在适当条件下，+2 价铁与 +3 价铁之间可以互相转化。
- **Fe²⁺ →(氧化剂) Fe³⁺**：如 2FeCl₂ + Cl₂ = 2FeCl₃；4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃；
- **Fe³⁺ →(还原剂) Fe²⁺**：如 2FeCl₃ + H₂ = 2FeCl₂ + 2HCl；2FeCl₃ + Fe = 3FeCl₂。

## 典型反应系列（FeCl₃ ⇌ FeCl₂）
- 取新配制的无色氯化亚铁溶液，通入氯气后溶液转为棕黄色，说明有 Fe³⁺ 生成；
- 随后加入镁粉，溶液又恢复无色，表明 Fe³⁺ 被重新还原为 Fe²⁺。
