# 亚铁盐

## 定义
亚铁盐指铁的 +2 价化合物（Fe²⁺ 对应的盐类），是铁跟较弱氧化剂（如硫、稀酸）反应时生成的产物。铁原子失去最外电子层 2 个电子成为亚铁离子 Fe²⁺。

## 重要亚铁盐

### 硫酸亚铁 FeSO₄
- 通常所见的**绿矾**即含 7 个结晶水的硫酸亚铁晶体 FeSO₄·7H₂O，呈浅绿色，很易溶于水；
- 在空气里易失去结晶水，同时氧化成黄褐色的硫酸铁 Fe₂(SO₄)₃；
- 制法：用铁屑跟稀硫酸反应制得：Fe + H₂SO₄(稀) = FeSO₄ + H₂↑；
- 用途：杀灭农作物害虫；制造某些颜料、墨水；织物染色时用作媒染剂。

### 氯化亚铁 FeCl₂
- 可由氯化铁被还原剂（H₂、Fe 等）还原得到：
  - 2FeCl₃ + H₂ = 2FeCl₂ + 2HCl
  - 2FeCl₃ + Fe = 3FeCl₂
- 可被氯气氧化回氯化铁：2FeCl₂ + Cl₂ = 2FeCl₃。

## 性质要点
- 亚铁盐溶液呈浅绿色（铁盐 Fe³⁺ 呈棕黄色）；
- 亚铁盐遇 KCNS 溶液**不显红色**（与 Fe³⁺ 区别）；
- 在空气中容易被氧化为对应的 +3 价铁盐。

## Fe²⁺ 与 Fe³⁺ 的相互转化
**核心规律**：+2 价铁和 +3 价铁在一定条件下可相互转化。
- **Fe²⁺ →(氧化剂) Fe³⁺**：如 2FeCl₂ + Cl₂ = 2FeCl₃；4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃；
- **Fe³⁺ →(还原剂) Fe²⁺**：如 2FeCl₃ + H₂ = 2FeCl₂ + 2HCl；2FeCl₃ + Fe = 3FeCl₂。

## 典型反应系列（FeCl₃ ⇌ FeCl₂）
- 新制的无色氯化亚铁溶液通入氯气 → 变棕黄色（Fe³⁺ 生成）；
- 再放入镁粉 → 又变无色（Fe³⁺ 被还原回 Fe²⁺）。
