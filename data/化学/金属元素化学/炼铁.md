# 炼铁

## 定义
生铁的冶炼（炼铁）是在**高炉**（又称鼓风炉或炼铁炉）中进行的工业过程，目的是从铁矿石中提取生铁。

## 炼铁的原料
1. **铁矿石**：要求含铁量尽可能高，硫、磷等杂质尽可能少。常用的有磁铁矿（Fe₃O₄）和赤铁矿（Fe₂O₃）；黄铁矿（FeS₂）因含硫量高，不能直接用于炼铁。
2. **焦炭**：既充当燃料提供热量，又充当还原剂。
3. **熔剂**：最常用的是石灰石（CaCO₃）或白云石（CaCO₃·MgCO₃），其作用是去除矿石中的脉石（SiO₂ 等杂质）。
4. **空气**：为焦炭燃烧提供所需的氧气。

## 炼铁的原理
从铁矿石中提炼生铁属于氧化-还原过程，主要依靠一氧化碳作为还原剂，将铁从其氧化物中还原出来。

### 一氧化碳的生成
- C + O₂ →(灼热) CO₂（放大量热，温度可达 1800 °C）
- CO₂ + C = 2CO

### 铁矿石的逐步还原（赤铁矿为例）
- 3Fe₂O₃ + CO →(高温) 2Fe₃O₄ + CO₂↑
- Fe₃O₄ + CO →(高温) 3FeO + CO₂↑
- FeO + CO →(高温) Fe + CO₂↑

### 其他还原反应
- 锰的化合物：3MnO + CO = Mn₃O₄ + CO₂；Mn₃O₄ + CO = 3MnO + CO₂；MnO + C →(高温) Mn + CO↑
- 硅：SiO₂ + 2C →(高温) Si + 2CO↑
- 硫和磷同样被还原

还原所得的铁在高温下与 C、Si、Mn、S、P 等熔合形成合金，即为**生铁**，其熔点为 1140~1150 °C。

### 熔剂造渣
- CaCO₃ →(高温) CaO + CO₂↑
- CaO + SiO₂ →(高温) CaSiO₃（炉渣，浮在铁水上面）

## 高炉的构造
现代高炉以耐火砖砌筑，外部覆以钢壳，高度可达数十米，一昼夜能产 2000~3000 吨生铁。其结构自上而下为：
- **炉喉**（最上部，1200~500 °C）：用于装料和导出高炉煤气
- **炉身/炉胸**（截头圆锥体，~800 °C）：铁矿石在此逐步被还原（Fe₂O₃ + 3CO = 2Fe + 3CO₂）
- **炉腰**（最宽处）：CaCO₃ 在此分解，铁开始与碳等元素熔合
- **炉腹**（倒截头圆锥体，~1000 °C，下部可达 1800 °C）：CaO + SiO₂ = CaSiO₃；铁与碳等熔合形成生铁
- **炉缸**：设有风口（6~16 个，连接热风总管）吹入热风；出渣口位置略高，出铁口位置略低

配备 3~4 座**热风炉**轮流预热空气（热风温度 900~1000 °C）：高炉煤气在燃烧室中燃烧以加热蓄热室砖格，随后冷空气反向通过以吸收热量完成预热。

## 冶炼的过程
1. **装料**：炉料（矿石、焦炭、石灰石）由装料车提升至炉顶，经装料机（采用双料钟双料斗结构）加入炉内，以防止高炉煤气外泄；热风从风口鼓入炉缸上部，与炉料形成逆向流动。
2. **生铁的熔炼**：焦炭在风口附近与热空气反应生成 CO₂ 并放热，CO₂ 再被焦炭还原为 CO；CO 自下而上与铁矿石接触，将铁还原出来；生成的 CO₂ 又被焦炭还原为 CO，形成循环；锰、硅、磷等也在此过程中被还原，与铁熔合形成生铁。
3. **出铁和出渣**：铁水和炉渣在炉缸中分层（下层为生铁，上层为炉渣），炉渣覆盖在铁水表面以防止铁被氧化；定期从出铁口放出铁水（送往炼钢或铸锭），从出渣口放出炉渣（可用于制造水泥或铺路材料）。
4. **高炉煤气的生成**：含约 60% N₂、30% CO、10% CO₂ 及少量 H₂、CH₄。导出后作为气体燃料用于预热空气。每生产一吨生铁约产生 5000 立方米高炉煤气。
5. **空气的预热**：热风炉轮流运行，一座用于加热蓄热室，另一座用于加热通过的空气，空闲的则进行清扫或备用。

## 高炉利用系数
用于衡量高炉的技术水平：指高炉有效容积每立方米在一昼夜内所产生铁的吨数。
