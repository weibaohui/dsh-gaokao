# 炼铁

## 定义
生铁的冶炼（炼铁）是在**高炉**（又名鼓风炉或炼铁炉）里进行的工业过程，从铁矿石中提炼生铁。

## 炼铁的原料
1. **铁矿石**：含铁量越高越好，硫、磷杂质越低越好。常用磁铁矿（Fe₃O₄）、赤铁矿（Fe₂O₃）；黄铁矿（FeS₂）含硫多不能直接炼铁。
2. **焦炭**：作燃料（供给热量）兼还原剂。
3. **熔剂**：最常用石灰石（CaCO₃）或白云石（CaCO₃·MgCO₃），用来除去矿石中的脉石（SiO₂ 等杂质）。
4. **空气**：供给焦炭燃烧所需氧气。

## 炼铁的原理
从铁矿石里提炼生铁是氧化-还原过程，主要用一氧化碳作还原剂把铁从氧化物中还原出来。

### 一氧化碳的生成
- C + O₂ →(灼热) CO₂（放大量热，温度可达 1800 °C）
- CO₂ + C = 2CO

### 铁矿石的逐步还原（赤铁矿为例）
- 3Fe₂O₃ + CO →(高温) 2Fe₃O₄ + CO₂↑
- Fe₃O₄ + CO →(高温) 3FeO + CO₂↑
- FeO + CO →(高温) Fe + CO₂↑

### 其他还原反应
- 锰化合物：3MnO + CO = Mn₃O₄ + CO₂；Mn₃O₄ + CO = 3MnO + CO₂；MnO + C →(高温) Mn + CO↑
- 硅：SiO₂ + 2C →(高温) Si + 2CO↑
- 硫、磷也被还原

还原出的铁在高温下与 C、Si、Mn、S、P 生成合金即**生铁**，熔点 1140~1150 °C。

### 熔剂造渣
- CaCO₃ →(高温) CaO + CO₂↑
- CaO + SiO₂ →(高温) CaSiO₃（炉渣，浮在铁水上面）

## 高炉的构造
现代高炉用耐火砖砌成，外面包钢壳，高达几十米，一昼夜可产 2000~3000 吨生铁。结构：
- **炉喉**（最上部，1200~500 °C）：装料、导出高炉煤气
- **炉身/炉胸**（截头圆锥体，~800 °C）：铁矿石逐步还原（Fe₂O₃ + 3CO = 2Fe + 3CO₂）
- **炉腰**（最阔部分）：CaCO₃ 分解，铁开始与碳等熔合
- **炉腹**（倒截头圆锥体，~1000 °C，下部可达 1800 °C）：CaO + SiO₂ = CaSiO₃；铁与碳等形成生铁
- **炉缸**：风口（6~16 个，连热风总管）入热风；出渣口（略高）；出铁口（略低）

配 3~4 座**热风炉**轮流预热空气（热风温度 900~1000 °C）：高炉煤气在燃烧室燃烧加热蓄热室砖格子，然后冷空气反向通过吸收热量预热。

## 冶炼的过程
1. **装料**：炉料（矿石、焦炭、石灰石）装料车升至炉顶，用装料机（双料钟双料斗结构）加入炉内，防止高炉煤气逸出；热风由风口鼓入炉缸上部，与炉料形成逆流。
2. **生铁的熔炼**：焦炭在风口附近与热空气反应生成 CO₂ 放热，再被焦炭还原为 CO；CO 自下而上与铁矿石相遇还原铁；生成的 CO₂ 又被焦炭还原为 CO 循环使用；锰、硅、磷等也被还原出来与铁熔合成生铁。
3. **出铁和出渣**：铁水和炉渣在炉缸分层（下层生铁、上层炉渣），炉渣盖在铁水面防铁氧化；定期从出铁口放出铁水（运往炼钢或铸锭），从出渣口放出渣（可制水泥、铺路材料）。
4. **高炉煤气的生成**：含约 60% N₂、30% CO、10% CO₂ 及少量 H₂、CH₄。导出后用作气体燃料预热空气。每吨生铁约得 5000 立方米高炉煤气。
5. **空气的预热**：热风炉轮流使用，一座加热蓄热室，另一座加热通过空气，空闲的清扫或备用。

## 高炉利用系数
衡量高炉技术水平：高炉有效容积每立方米在一昼夜所能生产生铁的吨数。
