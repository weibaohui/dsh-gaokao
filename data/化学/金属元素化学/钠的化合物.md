# 钠的化合物

## 一、氧化物
- **Na₂O（氧化钠）**：白色粉末，由钠在 180 °C 以下跟氧化合生成；与水反应生成 NaOH：Na₂O + H₂O = 2NaOH。
- **Na₂O₂（过氧化钠）**：淡黄色粉末，钠在空气或纯氧中燃烧生成；结构 Na—O—O—Na（钠仍为 +1 价）。与水反应生成 NaOH 并放出 O₂：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑。强氧化剂，工业上用作漂白剂（漂白麦杆、羽毛等）。与 CO₂ 反应：2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂↑，可用于防毒面具、潜水艇吸收 CO₂ 供氧。须密封保存。

## 二、氢氧化钠 NaOH（烧碱、苛性钠）
- 白色易潮解固体，溶解度大，溶解时放出大量热；溶液有肥皂样滑腻感，浓溶液腐蚀性强；
- 强电解质（强碱），几乎完全电离；具有碱的通性（与酸、酸酐、盐反应）；
- 玻璃瓶不可用玻璃塞（与 SiO₂ 反应生成水玻璃粘住塞子）；熔化或蒸煮浓溶液不可用玻璃、瓷坩埚，可用铁坩埚；
- 工业制法：电解食盐水溶液法（详见下方）或苛化法（纯碱 + 熟石灰）；
- 主要用于制造肥皂、精炼石油、造纸、制造人造丝等。

### 氢氧化钠的工业制法（电解食盐水溶液）
化学原理：
2NaCl + 2H₂O →(电解, 80~85 °C) 2NaOH + H₂↑ + Cl₂↑
- 阴极：2H⁺ + 2e → H₂↑（H⁺ 比 Na⁺ 易结合电子）
- 阳极：2Cl⁻ - 2e → Cl₂↑（Cl⁻ 比 OH⁻ 易放电）
- 溶液中：Na⁺ + OH⁻ = NaOH

为防止 H₂ 与 Cl₂ 混合爆炸、Cl₂ 与 NaOH 副反应（生成 NaClO），电解槽设**石棉隔膜**。常用水平式或垂直式隔膜电解槽：阳极用石墨，阴极用铁板，容器、导管用铁或陶器。

食盐溶液须精制（除去 Ca²⁺、Mg²⁺、SO₄²⁻）。电解碱液经蒸发浓缩分离 NaCl 后得 NaOH。

苛化法：Na₂CO₃ + Ca(OH)₂ = CaCO₃↓ + 2NaOH。

## 三、钠盐（重要者）
| 俗名 | 化学式 | 性质 | 用途 |
|---|---|---|---|
| 食盐 | NaCl | 白色晶体，易溶，味咸 | 调味，制钠及其他钠化物 |
| 芒硝 | Na₂SO₄·10H₂O | 白色晶体，易溶 | 制造玻璃 |
| 智利硝 | NaNO₃ | 无色晶体，易溶 | 泻剂、印染 |
| 氰化钠 | NaCN | 无色晶体，剧毒，易潮解 | 制 HCN，灭鼠杀虫 |
| **纯碱** | Na₂CO₃ | 白色粉末，易潮解，水溶液呈碱性 | 制玻璃、炼钢、纺织、造纸、肥皂、净化石油 |
| 洗涤碱 | Na₂CO₃·10H₂O | 无色晶体 | 洗涤 |
| **小苏打** | NaHCO₃ | 白色粉末，水溶液弱碱性 | 制发酵粉、灭火机药剂 |

### 焰色反应检验
钠盐火焰呈黄色；钾盐火焰呈紫色。检验时用光洁无锈铁丝（最好铂丝）蘸盐酸洗净，沾晶体或溶液灼烧；钠盐很灵敏，即使微量也产生强烈黄色火焰；检钾盐须隔蓝色钴玻璃观察（吸收黄光）。

## 四、碳酸钠 Na₂CO₃（纯碱）的工业制法

### 氨碱法（苏尔维法）
化学原理：
1. CaCO₃ →(高温) CaO + CO₂↑
2. CO₂ + NH₃ + H₂O = NH₄HCO₃
3. NH₄HCO₃ + NaCl = NaHCO₃↓ + NH₄Cl
4. 2NaHCO₃ =（煅烧）Na₂CO₃ + CO₂↑ + H₂O↑

关键条件：
- 温度 30~36 °C（低温利于 NH₃ 和 CO₂ 溶解及 NaHCO₃ 析出）；
- CO₂ 须过量（避免生成 Na₂CO₃ 不沉淀，须形成 HCO₃⁻）；
- 先在饱和食盐水中通 NH₃ 至饱和，再降温通入过量 CO₂；
- NaHCO₃ 沉淀析出是方法成功的关键；
- 氨可循环使用：2NH₄Cl + Ca(OH)₂ → 2NH₃↑ + CaCl₂ + 2H₂O。

工业流程：高位槽 → 吸氨塔（食盐溶液吸 NH₃，26 °C）→ 碳酸塔（通过量 CO₂，30~36 °C）→ 过滤机（得 NaHCO₃ 晶体）→ 转炉（煅烧得纯碱）。

优点：原料便宜、产品纯、氨和部分 CO₂ 可循环、适合大规模。
缺点：食盐利用率仅 70%；副产 CaCl₂ 用途不大且污染；NH₄Cl 被回收为氨气不合理。

### 联合制碱法（我国科学家创立）
将制碱与合成氨联合：氨由合成氨厂直接供给；CO₂ 来自发生炉煤气和水煤气变换（不用石灰石）；母液中 NH₄Cl 结晶析出即为氮肥，剩余 NaCl 循环使用。同时得到纯碱和氯化铵两种产品，充分利用物资。
