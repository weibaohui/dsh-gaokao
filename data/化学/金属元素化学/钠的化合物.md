# 钠的化合物

## 一、氧化物
- **Na₂O（氧化钠）**：白色粉末，由钠在 180 °C 以下与氧化合生成；与水反应生成 NaOH：Na₂O + H₂O = 2NaOH。
- **Na₂O₂（过氧化钠）**：淡黄色粉末，由钠在空气或纯氧中燃烧生成；结构为 Na—O—O—Na（钠仍为 +1 价）。与水反应生成 NaOH 并释放 O₂：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑。它是一种强氧化剂，工业上用作漂白剂（用于漂白麦杆、羽毛等）。与 CO₂ 反应：2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂↑，可用于防毒面具和潜水艇中吸收 CO₂ 并供氧。需密封保存。

## 二、氢氧化钠 NaOH（烧碱、苛性钠）
- 白色易潮解的固体，在水中溶解度很大，溶解时放出大量热；溶液触感有肥皂样滑腻感，浓溶液腐蚀性很强；
- 属强电解质（强碱），几乎完全电离；具有碱的通性（与酸、酸酐、盐反应）；
- 不可使用玻璃塞盖玻璃瓶（NaOH 与 SiO₂ 反应生成水玻璃会将塞子粘住）；熔化或蒸煮浓溶液时不可使用玻璃或瓷坩埚，应使用铁坩埚；
- 工业制法：电解食盐水溶液法（详见下方）或苛化法（纯碱 + 熟石灰）；
- 主要用于制造肥皂、精炼石油、造纸和生产人造丝等。

### 氢氧化钠的工业制法（电解食盐水溶液）
化学原理：
2NaCl + 2H₂O →(电解, 80~85 °C) 2NaOH + H₂↑ + Cl₂↑
- 阴极：2H⁺ + 2e → H₂↑（H⁺ 比 Na⁺ 更容易获得电子）
- 阳极：2Cl⁻ - 2e → Cl₂↑（Cl⁻ 比 OH⁻ 更容易放电）
- 溶液中：Na⁺ + OH⁻ = NaOH

为防止 H₂ 与 Cl₂ 混合引发爆炸，以及 Cl₂ 与 NaOH 发生副反应（生成 NaClO），电解槽中设有**石棉隔膜**。常用的有水平式或垂直式隔膜电解槽：阳极采用石墨，阴极采用铁板，容器和导管使用铁或陶瓷材料。

食盐溶液须经过精制处理（去除 Ca²⁺、Mg²⁺、SO₄²⁻ 等杂质）。电解所得碱液经蒸发浓缩分离出 NaCl 后即得 NaOH。

苛化法：Na₂CO₃ + Ca(OH)₂ = CaCO₃↓ + 2NaOH。

## 三、钠盐（重要者）
| 俗名 | 化学式 | 性质 | 用途 |
|---|---|---|---|
| 食盐 | NaCl | 白色晶体，易溶，味咸 | 调味，制钠及其他钠化物 |
| 芒硝 | Na₂SO₄·10H₂O | 白色晶体，易溶 | 制造玻璃 |
| 智利硝 | NaNO₃ | 无色晶体，易溶 | 泻剂、印染 |
| 氰化钠 | NaCN | 无色晶体，剧毒，易潮解 | 制 HCN，灭鼠杀虫 |
| **纯碱** | Na₂CO₃ | 白色粉末，易潮解，水溶液呈碱性 | 制玻璃、炼钢、纺织、造纸、肥皂、净化石油 |
| 洗涤碱 | Na₂CO₃·10H₂O | 无色晶体 | 洗涤 |
| **小苏打** | NaHCO₃ | 白色粉末，水溶液弱碱性 | 制发酵粉、灭火机药剂 |

### 焰色反应检验
钠盐的火焰呈黄色；钾盐的火焰呈紫色。检验方法：取光洁无锈的铁丝（最好用铂丝），蘸盐酸清洗后沾取晶体或溶液灼烧观察；钠盐反应极为灵敏，即使含量极微也能产生强烈的黄色火焰；检验钾盐时必须隔着蓝色钴玻璃观察（钴玻璃可吸收钠产生的黄光以排除干扰）。

## 四、碳酸钠 Na₂CO₃（纯碱）的工业制法

### 氨碱法（苏尔维法）
化学原理：
1. CaCO₃ →(高温) CaO + CO₂↑
2. CO₂ + NH₃ + H₂O = NH₄HCO₃
3. NH₄HCO₃ + NaCl = NaHCO₃↓ + NH₄Cl
4. 2NaHCO₃ =（煅烧）Na₂CO₃ + CO₂↑ + H₂O↑

关键条件：
- 温度控制在 30~36 °C（较低温度有利于 NH₃ 和 CO₂ 的溶解以及 NaHCO₃ 的析出）；
- CO₂ 需过量（若 CO₂ 不足则生成 Na₂CO₃，不会产生沉淀，必须确保形成 HCO₃⁻）；
- 操作顺序：先在饱和食盐水中通入 NH₃ 至饱和，再降温并通入过量 CO₂；
- NaHCO₃ 能否以沉淀形式析出是该法成功的关键；
- 氨可循环利用：2NH₄Cl + Ca(OH)₂ → 2NH₃↑ + CaCl₂ + 2H₂O。

工业流程：高位槽 → 吸氨塔（食盐水吸收 NH₃，26 °C）→ 碳酸塔（通入过量 CO₂，30~36 °C）→ 过滤机（分离出 NaHCO₃ 晶体）→ 转炉（煅烧后得到纯碱）。

优点：原料成本低、产品纯度高、氨和部分 CO₂ 可循环使用、适宜大规模生产。
缺点：食盐利用率仅约 70%；副产物 CaCl₂ 用途有限且造成污染；NH₄Cl 被回收为氨气不够合理。

### 联合制碱法（我国科学家创立）
将制碱与合成氨联合：氨由合成氨厂直接供给；CO₂ 来自发生炉煤气和水煤气变换（不使用石灰石）；母液中 NH₄Cl 结晶析出即为氮肥，剩余 NaCl 可循环利用。同一流程同时产出纯碱和氯化铵两种产品，物尽其用。
