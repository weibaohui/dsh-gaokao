# 氢氧化铁

## 概述
铁的氢氧化物有氢氧化亚铁 Fe(OH)₂ 和氢氧化铁 Fe(OH)₃ 两种，分别对应 +2 价和 +3 价铁的化合物。均不溶于水。

## 一、氢氧化亚铁 Fe(OH)₂
### 制法
由亚铁盐溶液跟碱溶液反应制得：
- FeSO₄ + 2NaOH = Fe(OH)₂↓ + Na₂SO₄
- 离子方程式：Fe²⁺ + 2OH⁻ = Fe(OH)₂↓

### 性质
- 絮状的**白色沉淀**；
- 在空气里很快被氧化，颜色变化：白色 → 淡蓝色 → 淡绿色 → 红褐色（Fe(OH)₃）；
  - 4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃

## 二、氢氧化铁 Fe(OH)₃
### 制法
由铁盐溶液跟碱溶液反应制得：
- FeCl₃ + 3NaOH = Fe(OH)₃↓ + 3NaCl
- 离子方程式：Fe³⁺ + 3OH⁻ = Fe(OH)₃↓

### 性质
- 絮状的**红褐色沉淀**；
- 受热失水生成红色氧化铁粉末：
  - 2Fe(OH)₃ →(加热) Fe₂O₃ + 3H₂O

## Fe²⁺ 与 Fe³⁺ 的相互转化
氢氧化亚铁易被空气中的 O₂ 氧化为 Fe(OH)₃，是 +2 价铁和 +3 价铁相互转化的典型例证之一：
- Fe²⁺ →(氧化剂) Fe³⁺
- Fe³⁺ →(还原剂) Fe²⁺

例如：
- FeCl₃ 在还原剂作用下变 FeCl₂：2FeCl₃ + H₂ = 2FeCl₂ + 2HCl；2FeCl₃ + Fe = 3FeCl₂；
- FeCl₂ 在氧化剂作用下变 FeCl₃：2FeCl₂ + Cl₂ = 2FeCl₃。
