# 炼钢

## 定义
钢的冶炼（炼钢）是把生铁炼成钢的工业过程。

## 炼钢的原理
把生铁炼成钢也是氧化-还原过程。主要是把熔融生铁进行氧化，使其中所含大部分杂质变成气体和炉渣除去，再脱氧。

生铁含较多碳及相当多的硅、锰、硫、磷等杂质，性质松脆不易机械加工。要把生铁炼成钢，就要降低含碳量，并尽量除去硫、磷等有害杂质。

### 阶段 1：氧化生铁中的杂质
液态生铁中铁含量大，氧化剂先使铁氧化成 FeO 并放热：
- 2Fe + O₂ →(高温) 2FeO + 热

FeO 再使生铁中杂质硅、锰、碳依次氧化：
- Si + 2FeO →(高温) SiO₂ + 2Fe + 热
- Mn + FeO →(高温) MnO + Fe + 热
- C + FeO →(高温) CO + Fe - 热

总放热大于吸热，炉内温度仍能提高。

**除磷**（须加大量生石灰）：
- 2P + 5FeO →(高温) P₂O₅ + 5Fe
- P₂O₅ + 3FeO →(高温) Fe₃(PO₄)₂
- 3CaO + Fe₃(PO₄)₂ →(高温) Ca₃(PO₄)₂ + 3FeO（炉渣）

**除硫**（硫以 FeS 形式存在）：
- FeS + CaO →(高温) CaS + FeO（炉渣）

### 阶段 2：使炼成的钢脱氧
所有氧化反应完毕、炉渣排出后，液态合金里仍含少量 FeO，会**使钢发生热脆性**，并跟碳结合生成 CO 使钢里发生气泡，降低钢的坚固性。故加**脱氧剂**（锰铁、硅铁或金属铝）：
- FeO + Mn（锰铁）→(高温) Fe + MnO
- 2FeO + Si（硅铁）→(高温) 2Fe + SiO₂
- 3FeO + 2Al →(高温) 3Fe + Al₂O₃

加入锰铁、硅铁还可调整钢里 Si、Mn 含量。

注：阶段 1 的 2FeO + Si → 2Fe + SiO₂ 与阶段 2 看似相同，但目的不同：前者是除杂质（FeO 作氧化剂），后者是脱氧（FeO 中 Fe²⁺ 被还原为 Fe）。

## 三种炼钢法比较

| 项目 | 转炉 | 平炉 | 电炉 |
|---|---|---|---|
| 原料 | 液态生铁 | 废钢、废铁、生铁、铁矿石 | 废钢、钢液 |
| 氧的来源 | 空气 | 空气、氧化气体或铁矿石 | 氧化铁、铁矿石 |
| 热的来源 | 杂质氧化时放出的热 | 气体或液体燃料燃烧 | 电能 |
| 产品及优缺点 | 出钢快，不用燃料，设备简单；铁损耗大，管理不便，钢质量较差 | 质量高，管理方便，可制合金钢；反应时间长，消耗燃料，建设费用高 | 制钨、钼等高级合金钢；反应时间较短，管理方便；电耗大，成本高 |

### 1. 转炉炼钢法
- 氧化剂是空气里的氧气；
- 转炉外形像梨，内壁衬耐火砖，炉侧有许多小孔（风口）吹入压缩空气，又称**侧吹转炉**；
- 操作：注入约 1300 °C 液态生铁 + 生石灰 → 鼓风并转炉直立 → 剧烈反应 → 几分钟后碳开始氧化（钢液沸腾、炉口大火焰）→ 磷氧化生成 Ca₃(PO₄)₂ 炉渣 → 火焰退落、出现 Fe₃O₄ 褐色蒸气时钢炼成 → 停风、倾炉、加脱氧剂脱氧；
- 整个过程约 16 分钟；
- **底吹转炉（柏塞麦法）**：空气由炉底吹入，钢含氮量高，但吹炼损失比侧吹小。

### 2. 平炉炼钢法（马丁法）
- 现代炼钢主要方法；
- 氧化剂：通入的空气和炉料里的氧化物（废钢、废铁、铁矿石）；
- 热量由燃烧气体燃料（高炉煤气、发生炉煤气）或液体燃料（重油）供给；
- 平炉炉膛用耐火砖砌成，前墙装料口、后墙出钢口和出渣口；两端各有炉头导入燃料与热空气或导出炉气；
- 原料：废钢、废铁、铁矿石、生铁和熔剂（石灰石或生石灰）；
- 燃料与空气在**蓄热室**预热（每对蓄热室一个加热燃料、一个加热空气；每 30~40 分钟交替方向）；
- 优点：炉料无严格限制、容积大、钢损耗少、可炼各种碳钢与合金钢、质量高；
- 缺点：建筑费用高、热能利用率低；用富氧空气可提高生产率 70%、缩短 2~4 小时、节约燃料。

### 3. 电炉炼钢法
- 以电能为热源，应用最广的是**电弧炉**；
- 圆柱形炉，直径 2.5~6 m，容量 3.5~80 吨；炉壁、炉底用耐火砖衬里，球面拱形炉顶；
- 电极用石墨制成，装在炉顶用青铜箍夹住；热量来自电极与炉料间生成的电弧及电流通过炉料所产生的热；
- 电极可上下移动调节温度并补充消耗；炉温可达 2000 °C，钢液沸腾；
- 用冷的废钢或热钢液作原料；冶炼约需 3 小时；
- 可炼各种合金钢包括含钨、钼等难熔金属的合金钢；合金元素损失少；电耗大、成本高。

## 钢的成分调整
钢里硅、锰含量需符合不同标准。通过脱氧剂加入可同时调整成分。冶炼将完成时用快速分析法（几分钟）检验钢的成分是否合乎要求。
