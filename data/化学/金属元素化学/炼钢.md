# 炼钢

## 定义
钢的冶炼（炼钢）是将生铁转化为钢的工业生产过程。

## 炼钢的原理
将生铁炼成钢同样属于氧化-还原过程。核心思路是对熔融生铁进行氧化处理，使其中的大部分杂质转化为气体或炉渣而排出，随后再进行脱氧。

生铁中碳含量偏高，还含有不少硅、锰、硫、磷等杂质，导致材质松脆、难以进行机械加工。要将其炼成钢，必须降低碳含量，同时尽可能去除硫、磷等有害杂质。

### 阶段 1：氧化生铁中的杂质
由于液态生铁中铁所占比例最大，氧化剂首先与铁反应生成 FeO 并释放热量：
- 2Fe + O₂ →(高温) 2FeO + 热

FeO 随后依次将生铁中的硅、锰、碳等杂质氧化：
- Si + 2FeO →(高温) SiO₂ + 2Fe + 热
- Mn + FeO →(高温) MnO + Fe + 热
- C + FeO →(高温) CO + Fe - 热

总体放热量超过吸热量，炉内温度仍可持续升高。

**除磷**（需加入大量生石灰）：
- 2P + 5FeO →(高温) P₂O₅ + 5Fe
- P₂O₅ + 3FeO →(高温) Fe₃(PO₄)₂
- 3CaO + Fe₃(PO₄)₂ →(高温) Ca₃(PO₄)₂ + 3FeO（炉渣）

**除硫**（硫以 FeS 的形式存在）：
- FeS + CaO →(高温) CaS + FeO（炉渣）

### 阶段 2：使炼成的钢脱氧
当氧化反应全部完成、炉渣排出之后，液态合金中仍残留少量 FeO，这会**导致钢产生热脆性**，还会与碳结合生成 CO，在钢中形成气泡，从而降低钢的强度。因此需要加入**脱氧剂**（锰铁、硅铁或金属铝）：
- FeO + Mn（锰铁）→(高温) Fe + MnO
- 2FeO + Si（硅铁）→(高温) 2Fe + SiO₂
- 3FeO + 2Al →(高温) 3Fe + Al₂O₃

加入锰铁、硅铁还可以同时调节钢中 Si、Mn 的含量。

注：阶段 1 中的 2FeO + Si → 2Fe + SiO₂ 与阶段 2 的脱氧反应虽然形式相似，但目的截然不同：前者是为了去除杂质（FeO 充当氧化剂），后者是为了脱氧（FeO 中的 Fe²⁺ 被还原为 Fe）。

## 三种炼钢法比较

| 项目 | 转炉 | 平炉 | 电炉 |
|---|---|---|---|
| 原料 | 液态生铁 | 废钢、废铁、生铁、铁矿石 | 废钢、钢液 |
| 氧的来源 | 空气 | 空气、氧化气体或铁矿石 | 氧化铁、铁矿石 |
| 热的来源 | 杂质氧化时放出的热 | 气体或液体燃料燃烧 | 电能 |
| 产品及优缺点 | 出钢快，不用燃料，设备简单；铁损耗大，管理不便，钢质量较差 | 质量高，管理方便，可制合金钢；反应时间长，消耗燃料，建设费用高 | 制钨、钼等高级合金钢；反应时间较短，管理方便；电耗大，成本高 |

### 1. 转炉炼钢法
- 氧化剂来自空气中的氧气；
- 转炉呈梨形，内壁衬有耐火砖，炉体侧面开有若干小孔（风口）用于吹入压缩空气，因此也称为**侧吹转炉**；
- 操作流程：注入约 1300 °C 的液态生铁和生石灰 → 鼓入空气并将炉体转至直立 → 反应剧烈进行 → 数分钟后碳开始被氧化（钢液沸腾、炉口冒出大火焰）→ 磷被氧化后与 CaO 结合生成 Ca₃(PO₄)₂ 炉渣 → 当火焰消退、出现 Fe₃O₄ 褐色烟气时即表示炼钢完成 → 停风、倾炉、加入脱氧剂进行脱氧；
- 整个冶炼过程约 16 分钟；
- **底吹转炉（柏塞麦法）**：空气从炉底吹入，所得钢含氮量偏高，但吹炼损耗比侧吹法小。

### 2. 平炉炼钢法（马丁法）
- 是现代炼钢的主要方法；
- 氧化剂为通入的空气及炉料中的氧化物（废钢、废铁、铁矿石）；
- 热量由气体燃料（高炉煤气、发生炉煤气）或液体燃料（重油）燃烧供给；
- 平炉炉膛以耐火砖砌筑，前墙设有装料口，后墙设有出钢口和出渣口，两端各有一个炉头用于导入燃料与热空气或导出炉气；
- 原料包括废钢、废铁、铁矿石、生铁及熔剂（石灰石或生石灰）；
- 燃料与空气先在**蓄热室**中预热（每对蓄热室分别加热燃料和空气，每 30~40 分钟切换一次气流方向）；
- 优点：对炉料要求不严、容积大、钢损耗少、可冶炼各种碳钢和合金钢、产品质量高；
- 缺点：建设费用高、热能利用率低；若使用富氧空气可使生产率提高 70%、缩短冶炼时间 2~4 小时并节约燃料。

### 3. 电炉炼钢法
- 以电能为热源，其中应用最普遍的是**电弧炉**；
- 炉体呈圆柱形，直径 2.5~6 m，容量 3.5~80 吨；炉壁和炉底衬有耐火砖，炉顶为球面拱形；
- 电极采用石墨材料，安装于炉顶并用青铜箍固定；热量来源于电极与炉料之间产生的电弧以及电流流经炉料时所产生的热量；
- 电极可上下移动以调节炉温并补充损耗；炉温最高可达 2000 °C，钢液呈沸腾状态；
- 以冷态废钢或热态钢液为原料；一次冶炼约需 3 小时；
- 可冶炼各类合金钢，包括含钨、钼等难熔金属的合金钢；合金元素损耗少；但电耗大、成本较高。

## 钢的成分调整
钢中硅、锰的含量需符合相应标准。通过加入脱氧剂可同时实现成分调整。冶炼接近完成时，采用快速分析法（仅需数分钟）检测钢的成分是否达标。
