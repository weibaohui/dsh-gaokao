# 氧化铝

## 名称与形态
- 化学式：Al₂O₃，也称作**矾土**。
- 是一种难熔的白色固体，熔点超过 2000 °C。
- 自然界中存在较纯净的结晶态氧化铝，称为**刚玉**，为无色透明且硬度极高的晶体（硬度仅次于金刚石）。
- **红宝石**：刚玉中含少量氧化铬而呈现红色；
- **蓝宝石**：刚玉中含微量铁和钛的氧化物而呈现蓝色。
- 人造宝石的制法：将矾土置于电炉中高温熔融，并掺入微量其他金属氧化物，可获得各种颜色的宝石，其组成和性能与天然宝石相近。广泛用于制作机械高速转动部件的轴承以及钟表中的钻石。

## 制法
- 高纯度氧化铝可通过灼烧氢氧化铝来获取：2Al(OH)₃ →(灼热) Al₂O₃ + 3H₂O，产物为白色粉末。
- 工业上则以铝土矿为原料经提纯获得（详见 [[铝]] 卡的冶炼部分）。

## 化学性质（典型两性氧化物）
Al₂O₃ 既能溶于酸（此时表现出碱性氧化物的特征），也能溶于碱（此时表现出酸性氧化物的特征）。

### 与酸反应（作为碱性氧化物）
产物为铝盐和水：
- Al₂O₃ + 6HCl = 2AlCl₃ + 3H₂O
- 离子方程式：Al₂O₃ + 6H⁺ = 2Al³⁺ + 3H₂O

### 与碱反应（作为酸性氧化物）
产物为偏铝酸盐（或铝酸盐）和水：
- Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O
- 离子方程式：Al₂O₃ + 2OH⁻ = 2AlO₂⁻ + H₂O

注：偏铝酸（HAlO₂）是铝酸（H₃AlO₃）脱去一分子水后的产物，其对应的盐称为偏铝酸盐（如 NaAlO₂），其中 AlO₂⁻ 为 -1 价酸根。

## 溶解性
- 氧化铝晶体在酸溶液和碱溶液中均难以溶解；
- 仅在高温条件下才能与熔融苛性碱反应，生成偏铝酸盐。

## 用途
- 用于制造耐火材料（因熔点高、难熔）；
- 刚玉及各类宝石可用于制作轴承和钟表钻石；
- 作为电解炼铝的原料。
