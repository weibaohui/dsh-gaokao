# 铝盐

铝的化合物由于铝处在由金属元素过渡到非金属元素的中间位置，特别明显地表现出两性特点。氢氧化铝碱性极弱，铝盐在水溶液里一般都容易发生水解反应并使溶液呈酸性。

## 一、硫酸铝 Al₂(SO₄)₃

### 制法
- 由硫酸跟氧化铝反应制得：Al₂O₃ + 3H₂SO₄ = Al₂(SO₄)₃ + 3H₂O
- 工业上用热的硫酸跟高岭土（Al₂O₃·2SiO₂·2H₂O）反应，晶体 Al₂(SO₄)₃·18H₂O 自溶液析出：
  - Al₂O₃·2SiO₂·2H₂O + 3H₂SO₄ + 13H₂O = Al₂(SO₄)₃·18H₂O + 2SiO₂

### 性质
- 强酸（H₂SO₄）与弱碱（Al(OH)₃）所成的盐，溶于水起水解反应，溶液呈酸性：
  - Al₂(SO₄)₃ + 6H₂O ⇌ 2Al(OH)₃ + 3H₂SO₄
  - 离子方程式：Al³⁺ + 3H₂O ⇌ Al(OH)₃ + 3H⁺
- 大量水时水解后生成微量 Al(OH)₃ 沉淀，吸附能力很强。

### 用途
- 水的清净剂（吸附水里悬浮物或微生物一起沉底）；
- 印染工业棉织物染色的媒染剂（Al(OH)₃ 吸附可溶性染料，与之化合成不溶性物质固着于纤维上）；
- 替代硫酸用于泡沫灭火器；加在焙粉（发酵粉）里与 NaHCO₃ 反应产生 CO₂。

## 二、硫酸钾铝 KAl(SO₄)₂（明矾）

### 名称与分子式
- 普通称**明矾**，分子式 K₂SO₄·Al₂(SO₄)₃·24H₂O 或 KAl(SO₄)₂·12H₂O。
- 无色透明晶体。

### 复盐
明矾是一种复盐。凡在水溶液里能电离生成两种阳离子和一种阴离子或两种阴离子和一种阳离子的复杂盐类叫做复盐。明矾电离：
- KAl(SO₄)₂ = K⁺ + Al³⁺ + 2SO₄²⁻

### 性质与用途
- 因溶液中也能电离出 Al³⁺ 和 SO₄²⁻，故可代替硫酸铝作净水剂和媒染剂；
- 制革工业鞣革；造纸工业上胶（使纸书写不化水）。

## 三、矾（复盐总称）
1 价金属硫酸盐与 3 价金属硫酸盐结合生成具有通式 M₂SO₄·M₂'(SO₄)₃·24H₂O 或 MM'(SO₄)₂·12H₂O 的复盐，总称矾。

- 易形成矾的 1 价金属：Li、Na、K、Rb、Cs、NH₄；
- 易形成矾的 3 价金属：Al、Cr、Fe、Mn 等。
- 例子：明矾（钾铝矾）、铁铵矾 (NH₄)₂SO₄·Fe₂(SO₄)₃·24H₂O 或 NH₄Fe(SO₄)₂·12H₂O、钾铬矾 K₂SO₄·Cr₂(SO₄)₃·24H₂O 或 KCr(SO₄)₂·12H₂O 等。

## 四、氯化铝 AlCl₃
- 制法：氯气流中加热铝；或红热 Al₂O₃ + C 混和物上通过氯气：
  - Al₂O₃ + 3C + 3Cl₂ = 2AlCl₃ + 3CO
- 无色物质，容易水解产生 HCl 和 Al(OH)₃，潮湿空气里会发烟。
- 无水 AlCl₃ 是石油和各种有机合成工业常用的催化剂。
- 铝溶解于盐酸可结晶出含 6 个分子结晶水的水合氯化铝晶体 AlCl₃·6H₂O。
