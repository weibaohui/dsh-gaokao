# 铝盐

由于铝处于由金属元素向非金属元素过渡的中间位置，其化合物表现出显著的两性特征。氢氧化铝的碱性极弱，因此铝盐在水溶液中通常容易发生水解反应，使溶液呈酸性。

## 一、硫酸铝 Al₂(SO₄)₃

### 制法
- 由硫酸与氧化铝反应制得：Al₂O₃ + 3H₂SO₄ = Al₂(SO₄)₃ + 3H₂O
- 工业上以热的硫酸与高岭土（Al₂O₃·2SiO₂·2H₂O）反应，硫酸铝晶体 Al₂(SO₄)₃·18H₂O 从溶液中析出：
  - Al₂O₃·2SiO₂·2H₂O + 3H₂SO₄ + 13H₂O = Al₂(SO₄)₃·18H₂O + 2SiO₂

### 性质
- 属强酸（H₂SO₄）与弱碱（Al(OH)₃）形成的盐，溶于水后发生水解反应，使溶液呈酸性：
  - Al₂(SO₄)₃ + 6H₂O ⇌ 2Al(OH)₃ + 3H₂SO₄
  - 离子方程式：Al³⁺ + 3H₂O ⇌ Al(OH)₃ + 3H⁺
- 在大量水中水解后会产生微量 Al(OH)₃ 沉淀，具有很强的吸附能力。

### 用途
- 用作水的净化剂（吸附水中的悬浮物和微生物，使其一同沉降）；
- 印染工业中用作棉织物染色的媒染剂（Al(OH)₃ 能吸附可溶性染料，与之结合成不溶性物质固着于纤维上）；
- 可替代硫酸用于泡沫灭火器；加入焙粉（发酵粉）中与 NaHCO₃ 反应产生 CO₂。

## 二、硫酸钾铝 KAl(SO₄)₂（明矾）

### 名称与分子式
- 俗称**明矾**，分子式为 K₂SO₄·Al₂(SO₄)₃·24H₂O 或 KAl(SO₄)₂·12H₂O。
- 无色透明的晶体。

### 复盐
明矾属于复盐。凡在水溶液中能电离出两种阳离子和一种阴离子，或两种阴离子和一种阳离子的复杂盐类，均称为复盐。明矾的电离：
- KAl(SO₄)₂ = K⁺ + Al³⁺ + 2SO₄²⁻

### 性质与用途
- 由于溶液中同样能电离出 Al³⁺ 和 SO₄²⁻，因此可替代硫酸铝用作净水剂和媒染剂；
- 制革工业中用于鞣革；造纸工业中用于上胶（使纸张书写时不洇水）。

## 三、矾（复盐总称）
1 价金属的硫酸盐与 3 价金属的硫酸盐结合，可生成具有通式 M₂SO₄·M₂'(SO₄)₃·24H₂O 或 MM'(SO₄)₂·12H₂O 的复盐，此类复盐总称为矾。

- 容易形成矾的 1 价金属：Li、Na、K、Rb、Cs、NH₄；
- 容易形成矾的 3 价金属：Al、Cr、Fe、Mn 等。
- 实例：明矾（钾铝矾）、铁铵矾 (NH₄)₂SO₄·Fe₂(SO₄)₃·24H₂O 或 NH₄Fe(SO₄)₂·12H₂O、钾铬矾 K₂SO₄·Cr₂(SO₄)₃·24H₂O 或 KCr(SO₄)₂·12H₂O 等。

## 四、氯化铝 AlCl₃
- 制法：在氯气流中加热铝；或在红热的 Al₂O₃ + C 混合物上通入氯气：
  - Al₂O₃ + 3C + 3Cl₂ = 2AlCl₃ + 3CO
- 无色物质，容易水解产生 HCl 和 Al(OH)₃，在潮湿空气中会发烟。
- 无水 AlCl₃ 是石油工业及各种有机合成工业中常用的催化剂。
- 铝溶于盐酸后可结晶出含 6 个结晶水的水合氯化铝晶体 AlCl₃·6H₂O。
