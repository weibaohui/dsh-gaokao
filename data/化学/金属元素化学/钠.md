# 钠

## 物理性质
| 性质 | 钠 |
|---|---|
| 颜色光泽 | 银白色有光泽（新切面） |
| 比重 | 0.97（比水轻） |
| 熔点 | 98 °C |
| 硬度 | 0.4（金属中最软之一，可刀切） |
| 导电传热 | 良导体 |

通常所见为淡黄色蜡状固体（表面氧化物所致）。

## 化学性质
一切有钠参与的化学反应都是其放出 1 个电子的过程：Na - e → Na⁺。反应一般都很剧烈。

1. **跟氧反应**：常温下生成 Na₂O；加热燃烧生成淡黄色过氧化钠（Na₂O₂），火焰呈黄色。
   - 4Na + O₂ = 2Na₂O
   - 2Na + O₂ = Na₂O₂
2. **跟氯气及其他非金属**：常温下就能燃烧；与硫反应会爆炸。
   - 2Na + Cl₂ = 2NaCl
3. **跟水反应**（常温即可）：钠浮水面熔成银白色小球游动，嘶嘶作响，反应放热，加酚酞变红（生成 NaOH）。
   - 2Na + 2H₂O = 2Na⁺ + 2OH⁻ + H₂↑
4. **跟酸反应**：比跟水反应更剧烈，因 H⁺ 浓度大。2Na + 2H⁺ = 2Na⁺ + H₂↑

钠是还原剂，非金属原子和 H⁺ 是氧化剂。

## 自然界存在
钠化学活动性强，仅以化合态存在。主要为 NaCl（海水、咸水湖、岩层）、Na₂SO₄、NaNO₃ 等。

## 制取
钠本身为强还原剂，一般还原剂无法还原其离子。工业上用电解法制取：
- 早期电解熔融 NaOH：4NaOH →(熔融电解) 4Na + 2H₂O + O₂↑
- 现用电解熔融 NaCl（阳极同时得 Cl₂）

## 保存
必须与空气隔绝：大量钠用密封钢筒存储；小量钠浸在煤油里。

## 用途
- 有机物合成中作还原剂或催化剂；
- 制造某些合金；
- 制取 NaCN、Na₂O₂ 等化合物。
