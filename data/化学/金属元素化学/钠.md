# 钠

## 物理性质
| 性质 | 钠 |
|---|---|
| 颜色光泽 | 银白色有光泽（新切面） |
| 比重 | 0.97（比水轻） |
| 熔点 | 98 °C |
| 硬度 | 0.4（金属中最软之一，可刀切） |
| 导电传热 | 良导体 |

通常所见为淡黄色蜡状固体（表面氧化物所致）。

## 化学性质
钠参与的一切化学反应，本质上都是它失去 1 个电子的过程：Na - e → Na⁺。这类反应通常十分剧烈。

1. **跟氧反应**：在常温下生成 Na₂O；若加热燃烧则生成淡黄色的过氧化钠（Na₂O₂），并伴有黄色火焰。
   - 4Na + O₂ = 2Na₂O
   - 2Na + O₂ = Na₂O₂
2. **跟氯气及其他非金属**：常温下即可燃烧；与硫混合时会发生爆炸。
   - 2Na + Cl₂ = 2NaCl
3. **跟水反应**（常温下即可发生）：钠浮于水面，熔化成银白色小球四处游动，发出嘶嘶声响，反应放出大量热，若加酚酞则溶液变红（因有 NaOH 生成）。
   - 2Na + 2H₂O = 2Na⁺ + 2OH⁻ + H₂↑
4. **跟酸反应**：由于酸中 H⁺ 浓度远高于水，反应比与水反应更为剧烈。2Na + 2H⁺ = 2Na⁺ + H₂↑

在上述反应中钠充当还原剂，非金属原子和 H⁺ 则充当氧化剂。

## 自然界存在
钠的化学活泼性极强，在自然界中只能以化合态形式存在。主要矿物资源有 NaCl（存在于海水、咸水湖和岩盐矿层中）、Na₂SO₄、NaNO₃ 等。

## 制取
由于钠本身是极强的还原剂，普通还原剂难以将其离子还原。工业上采用电解法制取：
- 早期方法是电解熔融 NaOH：4NaOH →(熔融电解) 4Na + 2H₂O + O₂↑
- 现行方法为电解熔融 NaCl（阳极可同时获得 Cl₂）

## 保存
钠必须与空气隔绝保存：大量钠储存在密封钢筒中；少量钠则浸没于煤油之中。

## 用途
- 在有机合成中用作还原剂或催化剂；
- 用于制备某些特定合金；
- 用于制造 NaCN、Na₂O₂ 等化合物。
