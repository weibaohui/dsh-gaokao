# 金属冶炼

## 本质
从矿石中取得金属的过程叫冶炼金属。其本质是把金属阳离子转变成中性原子的过程，即金属离子的一个**还原过程**。

## 金属在自然界的存在
- 极大多数金属以**化合态**存在；少数以**游离态（单质）**存在（如金、铂几乎全是单质，银、铜等有时也以单质存在）。
- 化合态形式：氧化物、硫化物、卤化物、碳酸盐、硫酸盐、磷酸盐、硅酸盐等。
- 化学活动性强或相当强的金属不可能长时间以单质存在于自然界中。

## 矿石与脉石
- **矿石**：在现在技术条件下可以用作且值得提炼的矿物或岩石。
- **脉石**：矿石里的杂质，主要是石英、石灰石、长石等，与金属矿物成层或搀杂混和存在。
- **选矿**：冶炼前去除大部分脉石的过程（一般用物理方法如水洗淘洗分离），使有效矿物浓缩。
- **贫矿与富矿**：区分只有相对意义，因金属而异（铁矿含铁 < 50% 即不合算，铜矿含铜 > 2% 即为富矿），各国标准不同。

## 最有利的矿石组成
- 氧化物矿最有利于冶炼（最易还原，阴离子氧易生成气态物质分离）；
- 其次是硫化物和碳酸盐矿（易转变为氧化物）。

## 冶炼方法（按金属活动性选取）

### 1. 加热法
用于排在金属活动性顺序后面的金属（如汞），其离子很容易结合电子。加强热即可还原氧化物或硫化物：
- 2HgO →(高温) 2Hg + O₂↑
- HgS + O₂ →(加热) Hg + SO₂↑（辰砂矿制汞）

### 2. 使用还原剂法
最普遍使用的方法，适用于活动性顺序中汞之前那些金属。常用还原剂：
- **焦炭**（最便宜普遍）：SnO₂ + 2C = Sn + 2CO↑；ZnCO₃ → ZnO + CO₂↑，ZnO + C = Zn + CO↑；
- **一氧化碳**（CO 实际上是高炉炼铁的主要还原剂）：Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂↑；
- **氢气**（还原能力强，不沾污金属）：WO₃ + 3H₂ →(加热) W + 3H₂O；
- **活动金属**（如铝热法）：Cr₂O₃ + 2Al = 2Cr + Al₂O₃ + 热；3MnO₂ + 4Al = 3Mn + 2Al₂O₃ + 热。

### 3. 电解法
用于活动性最强的轻金属（K、Na、Ca、Mg、Al 等），一般还原剂无法使其离子结合电子。用强有力的电子流强迫其还原。
- 电解熔融 NaOH 或 NaCl 制钠；
- 电解熔融 Al₂O₃-冰晶石制铝；
- 电解熔融 MgCl₂ 制镁；
- 电解熔融 CaCl₂ 制钙。
