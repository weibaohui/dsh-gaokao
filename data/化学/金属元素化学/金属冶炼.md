# 金属冶炼

## 本质
从矿石中提取金属的过程称为金属冶炼。其本质是将金属阳离子还原为中性原子的过程，即金属离子经历的一个**还原过程**。

## 金属在自然界的存在
- 绝大多数金属以**化合态**存在；少数金属以**游离态（单质）**存在（如金、铂几乎全为单质，银、铜等有时也能以单质形式出现）。
- 化合态的存在形式包括氧化物、硫化物、卤化物、碳酸盐、硫酸盐、磷酸盐、硅酸盐等。
- 化学活动性强或较强的金属不可能长期以单质形态存在于自然界中。

## 矿石与脉石
- **矿石**：在现有技术条件下，可以被利用且具有开采提炼价值的矿物或岩石。
- **脉石**：矿石中伴生的杂质，主要成分为石英、石灰石、长石等，与金属矿物呈层状或混杂状态共存。
- **选矿**：冶炼前去除大部分脉石的操作（一般采用水洗淘洗等物理方法分离），使有用矿物得到富集浓缩。
- **贫矿与富矿**：两者只有相对意义，因金属种类而异（铁矿含铁 < 50% 即不经济，铜矿含铜 > 2% 即属富矿），各国标准也有所不同。

## 最有利的矿石组成
- 氧化物矿最有利于冶炼（最容易还原，阴离子中的氧易生成气态物质而分离）；
- 其次是硫化物和碳酸盐矿（易于转化为氧化物）。

## 冶炼方法（按金属活动性选取）

### 1. 加热法
适用于排在金属活动性顺序后部的金属（如汞），其离子极易获得电子。加强热即可使氧化物或硫化物还原：
- 2HgO →(高温) 2Hg + O₂↑
- HgS + O₂ →(加热) Hg + SO₂↑（辰砂矿制汞）

### 2. 使用还原剂法
这是应用最广泛的冶炼方法，适用于活动性顺序中排在汞之前的金属。常用的还原剂有：
- **焦炭**（成本最低、来源最广）：SnO₂ + 2C = Sn + 2CO↑；ZnCO₃ → ZnO + CO₂↑，ZnO + C = Zn + CO↑；
- **一氧化碳**（CO 是高炉炼铁中实际发挥作用的还原剂）：Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂↑；
- **氢气**（还原能力强且不污染金属）：WO₃ + 3H₂ →(加热) W + 3H₂O；
- **活动金属**（如铝热法）：Cr₂O₃ + 2Al = 2Cr + Al₂O₃ + 热；3MnO₂ + 4Al = 3Mn + 2Al₂O₃ + 热。

### 3. 电解法
适用于活动性最强的轻金属（K、Na、Ca、Mg、Al 等），普通还原剂无法使其离子获得电子而还原。需借助强大的直流电迫使离子还原。
- 电解熔融 NaOH 或 NaCl 制取钠；
- 电解熔融 Al₂O₃-冰晶石体系制取铝；
- 电解熔融 MgCl₂ 制取镁；
- 电解熔融 CaCl₂ 制取钙。
