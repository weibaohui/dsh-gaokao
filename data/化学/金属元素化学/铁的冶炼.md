# 铁的冶炼

## 概述
铁的冶炼包括从铁矿石中冶炼生铁（**炼铁**）和把生铁炼成钢（**炼钢**）两个阶段。两者都是氧化-还原过程。

## 炼铁的原理（详见 [[炼铁]]）
主要是用一氧化碳作为还原剂，把铁从铁的氧化物里还原出来（铁是还原过程）：
- 一氧化碳的生成：C + O₂ → CO₂；CO₂ + C = 2CO
- 铁矿石（赤铁矿 Fe₂O₃）逐步还原：
  - 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂↑
  - Fe₃O₄ + CO → 3FeO + CO₂↑
  - FeO + CO → Fe + CO₂↑
- 副反应：Mn、Si、P 也被还原出来；S 还原出来。
- 还原出的铁在高温下与 C、Si、Mn、S、P 形成合金即**生铁**，熔点（1140~1150 °C）比纯铁（1535 °C）低。
- 熔剂造渣：CaCO₃ → CaO + CO₂↑；CaO + SiO₂ → CaSiO₃（炉渣）。

## 炼钢的原理（详见 [[炼钢]]）
把生铁炼成钢是**氧化-还原过程**。主要是把熔融生铁进行氧化，使大部分杂质变成气体和炉渣除去，再脱氧。

### 1. 氧化生铁中的杂质
液态生铁中铁含量最大，氧化剂先把铁氧化成 FeO，FeO 再氧化杂质：
- 2Fe + O₂ → 2FeO + 热
- Si + 2FeO → SiO₂ + 2Fe + 热
- Mn + FeO → MnO + Fe + 热
- C + FeO → CO + Fe - 热
- 磷：2P + 5FeO → P₂O₅ + 5Fe；P₂O₅ + 3FeO → Fe₃(PO₄)₂；3CaO + Fe₃(PO₄)₂ → Ca₃(PO₄)₂ + 3FeO（成炉渣）
- 硫（以 FeS 形式）：FeS + CaO → CaS + FeO（成炉渣）

### 2. 使炼成的钢脱氧
加脱氧剂（锰铁、硅铁或铝）除去 FeO：
- FeO + Mn → Fe + MnO
- 2FeO + Si → 2Fe + SiO₂
- 3FeO + 2Al → 3Fe + Al₂O₃

加入锰铁、硅铁不仅脱氧，还可调整钢里 Si、Mn 含量。

## 与炼铁的对比
| 方面 | 炼铁 | 炼钢 |
|---|---|---|
| 反应性质 | 还原过程（Fe 离子还原为原子） | 氧化-还原过程（杂质被氧化，FeO 被还原） |
| 主要还原剂/氧化剂 | CO | O₂ 或铁的氧化物 |
| 主要原料 | 铁矿石、焦炭、熔剂、空气 | 生铁、废钢、铁矿石等 |
| 产品 | 生铁（含 C 1.7% 以上） | 钢（含 C 0.04~1.7%） |
