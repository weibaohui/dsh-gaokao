# 铁的冶炼

## 概述
铁的冶炼包括从铁矿石中提炼生铁（**炼铁**）以及将生铁转化为钢（**炼钢**）两个阶段，两者均属于氧化-还原过程。

## 炼铁的原理（详见 [[炼铁]]）
核心是以一氧化碳作为还原剂，将铁从其氧化物中还原出来（铁经历还原过程）：
- 一氧化碳的生成：C + O₂ → CO₂；CO₂ + C = 2CO
- 铁矿石（赤铁矿 Fe₂O₃）的逐步还原：
  - 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂↑
  - Fe₃O₄ + CO → 3FeO + CO₂↑
  - FeO + CO → Fe + CO₂↑
- 副反应：Mn、Si、P 也被还原出来；S 同样被还原。
- 还原所得的铁在高温下与 C、Si、Mn、S、P 熔合形成合金即**生铁**，其熔点（1140~1150 °C）低于纯铁（1535 °C）。
- 熔剂造渣：CaCO₃ → CaO + CO₂↑；CaO + SiO₂ → CaSiO₃（炉渣）。

## 炼钢的原理（详见 [[炼钢]]）
将生铁炼成钢属于**氧化-还原过程**。核心是对熔融生铁进行氧化处理，使大部分杂质转化为气体或炉渣排出，随后再进行脱氧。

### 1. 氧化生铁中的杂质
由于液态生铁中铁含量最高，氧化剂首先将铁氧化为 FeO，FeO 再进一步氧化杂质：
- 2Fe + O₂ → 2FeO + 热
- Si + 2FeO → SiO₂ + 2Fe + 热
- Mn + FeO → MnO + Fe + 热
- C + FeO → CO + Fe - 热
- 磷：2P + 5FeO → P₂O₅ + 5Fe；P₂O₅ + 3FeO → Fe₃(PO₄)₂；3CaO + Fe₃(PO₄)₂ → Ca₃(PO₄)₂ + 3FeO（形成炉渣）
- 硫（以 FeS 形式存在）：FeS + CaO → CaS + FeO（形成炉渣）

### 2. 使炼成的钢脱氧
加入脱氧剂（锰铁、硅铁或铝）以去除残留的 FeO：
- FeO + Mn → Fe + MnO
- 2FeO + Si → 2Fe + SiO₂
- 3FeO + 2Al → 3Fe + Al₂O₃

加入锰铁、硅铁不仅用于脱氧，还可同时调节钢中 Si、Mn 的含量。

## 与炼铁的对比
| 方面 | 炼铁 | 炼钢 |
|---|---|---|
| 反应性质 | 还原过程（Fe 离子还原为原子） | 氧化-还原过程（杂质被氧化，FeO 被还原） |
| 主要还原剂/氧化剂 | CO | O₂ 或铁的氧化物 |
| 主要原料 | 铁矿石、焦炭、熔剂、空气 | 生铁、废钢、铁矿石等 |
| 产品 | 生铁（含 C 1.7% 以上） | 钢（含 C 0.04~1.7%） |
