# 钾

## 物理性质
| 性质 | 钾 |
|---|---|
| 颜色光泽 | 银白色有光泽（新切面） |
| 比重 | 0.86（比水轻，比钠还轻） |
| 熔点 | 62.3 °C |
| 硬度 | 0.5（金属中最软之一，可刀切） |
| 导电传热 | 良导体 |

通常为淡黄色蜡状固体（表面氧化物所致）。

## 化学性质
钾原子比钠原子更容易释放电子，化学活泼性强于钠，反应也更为剧烈。K - e → K⁺。

1. **跟氧反应**：常温下迅速生成 K₂O；加热燃烧则生成淡黄色的过氧化钾（K₂O₂），火焰呈**紫色**。
   - 4K + O₂ = 2K₂O
   - 2K + O₂ = K₂O₂
2. **跟氯气及其他非金属**：常温下即可燃烧生成 KCl；与硫混合时会发生爆炸。
3. **跟水反应**：比钠更为剧烈，反应放热常导致产生的氢气被引燃。
   - 2K + 2H₂O = 2K⁺ + 2OH⁻ + H₂↑
4. **跟酸反应**：由于酸中 H⁺ 浓度远高于水，反应比与水反应更剧烈。2K + 2H⁺ = 2K⁺ + H₂↑

钾在上述反应中充当还原剂。

## 自然界存在
钾的化学活泼性极强，在自然界中仅以化合态存在。钾的化合物在自然界中数量不少，但大多以组成复杂的岩石形式存在（如长石、云母等）；简单钾盐如 KCl 的矿床则较为稀少。钾是植物体内的重要元素，植物从土壤中吸收钾，因此陆生植物和海藻燃烧后的灰分中含有碳酸钾。

## 制取
工业上采用电解法制取（与钠的方法类似）：
- 早期方法为电解熔融 KOH：4KOH →(熔融电解) 4K + 2H₂O + O₂↑
- 现行方法为电解熔融 KCl。

## 用途
- 用于制造某些特定合金；
- 在有机合成中用作还原剂或催化剂；
- 用于制造 K₂O₂ 等化合物。

## 钾的化合物要点
- **氧化物**：K₂O（白色）；K₂O₂（淡黄色）。K₂O + H₂O = 2KOH；2K₂O₂ + 2H₂O = 4KOH + O₂↑。
- **氢氧化钾 KOH（苛性钾）**：白色易潮解的固体，属强碱；作用与 NaOH 基本相同，但成本更高；配制 1 mol KOH 需 56 g（而 NaOH 仅需 40 g），因此实验室一般使用 NaOH；仅在制备液态钾肥皂时才使用 KOH。
- **钾盐**：KNO₃（火硝，用于制造黑火药和氮钾混合肥）、KCl（用作肥料和制造钾玻璃）、K₂CO₃（钾碱，存在于草木灰中，用作肥料）。
- **钾肥**：氯化钾、硫酸钾、硝酸钾、碳酸钾均为常用钾肥；能增强植物的抗寒、抗旱和抗病菌感染能力，促进糖类和淀粉的合成，使茎秆坚实不易倒伏。
- **焰色反应**：钾盐的火焰呈紫色，观察时须隔着蓝色钴玻璃。
