# 钾

## 物理性质
| 性质 | 钾 |
|---|---|
| 颜色光泽 | 银白色有光泽（新切面） |
| 比重 | 0.86（比水轻，比钠还轻） |
| 熔点 | 62.3 °C |
| 硬度 | 0.5（金属中最软之一，可刀切） |
| 导电传热 | 良导体 |

通常为淡黄色蜡状固体（表面氧化物所致）。

## 化学性质
钾原子比钠原子更易放出电子，化学活动性比钠更强，反应更剧烈。K - e → K⁺。

1. **跟氧反应**：常温迅速生成 K₂O；加热燃烧生成淡黄色过氧化钾（K₂O₂），火焰呈**紫色**。
   - 4K + O₂ = 2K₂O
   - 2K + O₂ = K₂O₂
2. **跟氯气及其他非金属**：常温就能燃烧生成 KCl；跟硫反应会爆炸。
3. **跟水反应**：比钠更剧烈，温度升高常导致生成的氢气发火燃烧。
   - 2K + 2H₂O = 2K⁺ + 2OH⁻ + H₂↑
4. **跟酸反应**：比跟水反应更剧烈。2K + 2H⁺ = 2K⁺ + H₂↑

钾是还原剂。

## 自然界存在
钾化学活动性强，仅以化合态存在。钾的化合物在自然界中数量不少，但大都是组成复杂的岩石（长石、云母等）；简单钾盐如 KCl 矿床不多。钾是植物体内重要元素，植物从土壤吸收，因此陆生植物和海藻燃烧后的灰分里都含碳酸钾。

## 制取
工业上用电解法制取（与钠类似）：
- 早期电解熔融 KOH：4KOH →(熔融电解) 4K + 2H₂O + O₂↑
- 现用电解熔融 KCl。

## 用途
- 制造某些合金；
- 有机物合成中作还原剂或催化剂；
- 制取 K₂O₂ 等化合物。

## 钾的化合物要点
- **氧化物**：K₂O（白色）；K₂O₂（淡黄色）。K₂O + H₂O = 2KOH；2K₂O₂ + 2H₂O = 4KOH + O₂↑。
- **氢氧化钾 KOH（苛性钾）**：白色易潮解固体，强碱；与 NaOH 作用基本相同，但成本较高；1 mol KOH 需 56 g（NaOH 仅需 40 g），故实验室一般用 NaOH；制液态钾肥皂时才用 KOH。
- **钾盐**：KNO₃（火硝，制黑火药、氮钾混合肥）、KCl（肥料、制钾玻璃）、K₂CO₃（钾碱，存在于草木灰，肥料）。
- **钾肥**：氯化钾、硫酸钾、硝酸钾、碳酸钾为常用钾肥；能增强植物抗寒、抗旱、抗病菌感染能力，提高糖和淀粉合成能力，使茎秆坚实不易倒伏。
- **焰色反应**：钾盐火焰呈紫色，须隔蓝色钴玻璃观察。
