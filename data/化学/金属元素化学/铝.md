# 铝

## 周期表位置与原子结构
铝位于元素周期表第三周期第 III 类主族，其前方的镁为金属元素，后方的硅为非金属元素，恰好处在由金属向非金属过渡的位置，这决定了铝特殊的化学性质。

| 项目 | 值 |
|---|---|
| 原子序数 | 13 |
| 原子量 | 27 |
| 电子层结构 | 2, 8, 3 |
| 化合价 | +3 |

铝原子可失去最外层的 3 个电子形成 Al³⁺。由于失去 3 个电子的难度大于碱金属失去 1 个或碱土金属失去 2 个，因此铝的化学活动性和金属性都相对较弱。

## 物理性质
银白色轻金属。
| 物理常数 | 值 |
|---|---|
| 比重 | 2.70 |
| 熔点 | 660 °C |
| 沸点 | 2270 °C |
| 硬度 | 2.9（金刚石 = 10） |
| 导电性（汞 = 1） | 36.1 |

铝是热和电的良导体，导电性虽不及铜（铜为 56.9），但比重仅为铜的 30%，因此输送同等电量时所用铝线的重量远轻于铜线；加之价格低廉，电器工业中不少场合已用铝替代铜。铝的延展性极强：1 g 铝可拉成 37 m 长的细丝，也可展成面积达 60 m²、厚仅 0.00008 mm 的铝箔。纯铝的硬度和强度有限，但加入少量 Cu 等元素后可大幅提高。

## 化学性质
1. **跟氧反应**：铝极易与氧化合，表面会迅速生成一层致密且牢固的氧化铝薄膜（在电子显微镜下观察呈连续、无孔结构），能有效阻止内部金属继续氧化，即使在高温下仍具保护作用。铝粉在空气中加热时剧烈燃烧，释放大量热（每克铝氧化时放热 7.47 千卡，高于许多金属），并发出耀眼的光辉：4Al + 3O₂ = 2Al₂O₃。若铝表面有汞存在，氧化膜无法与铝紧密结合，铝会迅速被氧化。
2. **跟氯气及其他非金属**：与氯气在微热条件下即可剧烈燃烧生成 AlCl₃；高温下与硫反应生成 Al₂S₃（伴有火花闪光）。
3. **跟水反应**：表面有氧化膜时不反应；去除氧化膜后投入水中：2Al + 6H₂O = 3H₂↑ + 2Al(OH)₃（生成的凝胶状 Al(OH)₃ 会阻碍反应继续进行）。
4. **跟酸反应**：氧化膜对酸无保护作用（因 Al₂O₃ 可溶于酸）。与盐酸或稀硫酸反应剧烈：2Al + 6H⁺ = 2Al³⁺ + 3H₂↑。冷的浓硝酸、浓硫酸几乎不反应（**钝化**），因此铝制容器可用于贮存浓硝酸或浓硫酸。
5. **跟金属氧化物反应（铝热法）**：铝能夺取金属氧化物中的氧，将金属离子还原出来。反应释放的大量热使还原出的金属呈熔融状态。工业上常用铝热法冶炼高熔点金属：
   - 2Al + Cr₂O₃ = Al₂O₃ + 2Cr
   - 8Al + 3Mn₃O₄ = 4Al₂O₃ + 9Mn
   - 铝热剂：铝粉 + Fe₃O₄（按 1:3 比例）+ 过氧化钡助燃剂，用镁带引燃：8Al + 3Fe₃O₄ = 4Al₂O₃ + 9Fe + 795 千卡，温度可达 3500 °C，用于焊接钢轨（铝焊接术）。
6. **跟碱溶液反应**：一般金属不与碱反应，但铝与碱反应剧烈并放出 H₂。过程分三步进行：
   - 首先溶解氧化膜：Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O
   - 铝与水反应：2Al + 6H₂O = 2Al(OH)₃ + 3H₂↑
   - 氢氧化铝溶于碱：Al(OH)₃ + NaOH = NaAlO₂ + 2H₂O
   实质上是铝与水的反应；碱仅起到溶解氧化膜和 Al(OH)₃ 的作用，从而促使铝与水迅速反应。因此铝制容器不可盛放碱溶液或碱性物质。

## 自然界存在
铝是地壳中含量最多的金属元素（仅次于氧和硅，居第三位）。主要存在于铝硅酸盐中（如 K₂O·3Al₂O₃·6SiO₂·2H₂O）。最重要的铝矿物有：铝土矿（Al₂O₃·nH₂O，n=1 或 3）、冰晶石（Na₃AlF₆）、明矾石 [KAl(SO₄)₂·12H₂O]、霞石等。

## 冶炼方法
分两个阶段进行：
1. **从铝土矿提取纯 Al₂O₃**：
   - 将矿石与 NaOH 溶液共热，使 Al₂O₃ 转化为可溶性偏铝酸钠：Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O；
   - 滤除残渣（含 Si、Fe、Ti 等杂质），通入 CO₂ 使 Al(OH)₃ 析出：2AlO₂⁻ + CO₂ + 3H₂O = 2Al(OH)₃↓ + CO₃²⁻；
   - 在 1200 °C 下煅烧：2Al(OH)₃ → Al₂O₃ + 3H₂O。
2. **电解熔融 Al₂O₃**：以冰晶石（Na₃AlF₆）为熔剂（熔点约 1000 °C），混合物的熔点比纯 Al₂O₃（2050 °C）或冰晶石都低，电解温度为 940~960 °C：
   - 2Al₂O₃ →(熔融电解, Na₃AlF₆) 4Al + 3O₂↑
   - 阴极得到液态铝（因比电解质重，沉于槽底，无需隔膜）；阳极释放 O₂，与碳素阳极反应生成 CO/CO₂。
   - 电解槽结构：下部钢壳内衬耐火砖和碳块作为阴极；上部铝壳中注入碳糊，连续自动焙烧形成阳极。
   - 每生产一吨铝约耗电 1.7~2 万度。

## 用途
1. 铝合金比重小、强度高，用于制造交通运输工具（飞机中铝合金约占总重的 50%）和机器零件（如内燃机活塞）；
2. 导电、导热性能好且可塑性强，可用于制作电线电缆、无线电器材和炊具；铝箔用于包装香烟、糖果等起防潮作用；
3. 抗蚀性强，可用于制造化学反应器、输送管道和食品工业容器；铝粉可制成银色油漆以防止其他金属锈蚀；
4. 与氧化合时释放大量热，铝粉可用于冶炼高熔点金属，制造照明弹、信号弹和爆炸物（硝酸铵 + 铝粉）；铝热剂可用于焊接钢轨。
