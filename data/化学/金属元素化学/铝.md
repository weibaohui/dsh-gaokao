# 铝

## 周期表位置与原子结构
铝在元素周期表第三周期第 III 类主族，前面是镁（金属元素），后面是硅（非金属元素），正好处在由金属元素过渡到非金属元素的地位，决定其特殊的化学性质。

| 项目 | 值 |
|---|---|
| 原子序数 | 13 |
| 原子量 | 27 |
| 电子层结构 | 2, 8, 3 |
| 化合价 | +3 |

铝原子可失去最外层 3 个电子成 Al³⁺。失去 3 个电子比碱金属失去 1 个或碱土金属失去 2 个困难，故化学活动性和金属性都较弱。

## 物理性质
银白色轻金属。
| 物理常数 | 值 |
|---|---|
| 比重 | 2.70 |
| 熔点 | 660 °C |
| 沸点 | 2270 °C |
| 硬度 | 2.9（金刚石 = 10） |
| 导电性（汞 = 1） | 36.1 |

热和电的良导体，导电性虽比铜差（铜 56.9），但比重仅为铜的 30%，故传导同量电所用铝线重量比铜线轻得多；且价格便宜，电器工业上不少地方正在用铝代铜。延展性极强：1 g 铝可拉 37 m 细丝，可展成面积 60 m²、厚 0.00008 mm 的铝箔。纯铝硬度强度不大，加少量 Cu 等可大增。

## 化学性质
1. **跟氧反应**：非常容易化合，表面很快生成致密牢固的氧化铝薄膜（电子显微镜下连续、无孔），可防止内部金属继续氧化，高温下也能起保护作用。铝粉在空气里加热剧烈燃烧，放出大量热（每克铝氧化时放 7.47 千卡，比许多金属多），发出夺目光辉：4Al + 3O₂ = 2Al₂O₃。若铝表面有汞存在，氧化膜不能跟铝紧密联结，会迅速氧化。
2. **跟氯气及其他非金属**：与氯气在微热下剧烈燃烧生成 AlCl₃；高温与硫反应生成 Al₂S₃（火花闪光）。
3. **跟水反应**：表面有氧化膜时不反应；去氧化膜后投入水中：2Al + 6H₂O = 3H₂↑ + 2Al(OH)₃（凝胶状 Al(OH)₃ 阻碍反应继续）。
4. **跟酸反应**：氧化膜对酸不能产生保护作用（Al₂O₃ 溶于酸）。与盐酸或稀硫酸反应剧烈：2Al + 6H⁺ = 2Al³⁺ + 3H₂↑。冷的浓硝酸、浓硫酸几乎不起反应（**钝化**），故铝容器可贮存浓硝酸或浓硫酸。
5. **跟金属氧化物反应（铝热法）**：能夺取金属氧化物中的氧，把金属离子还原出来。反应放出大量热使还原金属呈熔融状态。工业上常用铝热法冶炼高熔点金属：
   - 2Al + Cr₂O₃ = Al₂O₃ + 2Cr
   - 8Al + 3Mn₃O₄ = 4Al₂O₃ + 9Mn
   - 铝热剂：铝粉 + Fe₃O₄（按 1:3）+ 过氧化钡助燃剂；用镁带引火：8Al + 3Fe₃O₄ = 4Al₂O₃ + 9Fe + 795 千卡，温度可达 3500 °C，用于焊接钢轨（铝焊接术）。
6. **跟碱溶液反应**：一般金属不与碱反应，但铝与碱剧烈反应放出 H₂。三步骤：
   - 先溶去氧化膜：Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O
   - 铝跟水反应：2Al + 6H₂O = 2Al(OH)₃ + 3H₂↑
   - 氢氧化铝溶于碱：Al(OH)₃ + NaOH = NaAlO₂ + 2H₂O
   实质上是铝跟水的反应；碱只起溶解氧化膜和 Al(OH)₃ 的作用，促使铝跟水迅速反应。故铝容器不能盛碱溶液或碱性物质。

## 自然界存在
地壳中含量最多的金属元素（仅次于氧和硅，居第三位）。主要存在于铝硅酸盐中（如 K₂O·3Al₂O₃·6SiO₂·2H₂O）。最重要铝矿物：铝土矿（Al₂O₃·nH₂O，n=1 或 3）、冰晶石（Na₃AlF₆）、明矾石 [KAl(SO₄)₂·12H₂O]、霞石等。

## 冶炼方法
分两阶段：
1. **从铝土矿提取纯 Al₂O₃**：
   - 矿石与 NaOH 溶液共热，Al₂O₃ 变可溶性偏铝酸钠：Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O；
   - 滤去残渣（Si、Fe、Ti 杂质），通入 CO₂ 析出 Al(OH)₃：2AlO₂⁻ + CO₂ + 3H₂O = 2Al(OH)₃↓ + CO₃²⁻；
   - 1200 °C 煅烧：2Al(OH)₃ → Al₂O₃ + 3H₂O。
2. **电解熔融 Al₂O₃**：用冰晶石（Na₃AlF₆）作熔剂（熔点约 1000 °C），混和物熔点比纯 Al₂O₃（2050 °C）或冰晶石都低，电解温度 940~960 °C：
   - 2Al₂O₃ →(熔融电解, Na₃AlF₆) 4Al + 3O₂↑
   - 阴极得液态铝（比电解质重，沉槽底，不需隔膜）；阳极放出 O₂，与碳素阳极反应生成 CO/CO₂。
   - 电解槽：下部钢壳内衬耐火砖和碳块作阴极；上部铝壳注入碳糊连续自动焙烧阳极。
   - 每吨铝耗电约 1.7~2 万度。

## 用途
1. 铝合金比重小、强度大，制造交通运输工具（飞机铝合金占总重约 50%）、机器零件（内燃机活塞）；
2. 导电、传热好，可塑性强，制电线电缆、无线电器材、炊具；铝箔包装香烟、糖果防潮；
3. 抗蚀性强，制化学反应器、输送管子、食品工业容器；铝粉制银色油漆防其他金属锈蚀；
4. 与氧结合放大量热，铝粉冶炼高熔点金属，制照明弹、信号弹、爆炸物（硝酸铵 + 铝粉）；铝热剂焊接钢轨。
