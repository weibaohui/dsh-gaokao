# 葡萄糖

## 定义
葡萄糖（C₆H₁₂O₆）是最重要的一种单糖，属于还原性糖。其分子中含有5个羟基和1个醛基，兼具醛与多元醇的双重化学性质。

## 分子结构
- 分子式：C₆H₁₂O₆（含碳40%、氢6.67%、氧53.33%，分子量180）
- 结构简式：CH₂OH—(CHOH)₄—CHO

确定其结构的依据：
1. 葡萄糖能与乙酸反应生成五乙酸葡萄糖酯，表明分子中含5个羟基
2. 葡萄糖能发生银镜反应，表明分子中含醛基
3. 5个羟基分别连接在5个碳原子上（一个碳原子上连两个羟基不稳定，但葡萄糖稳定）
4. 醛基位于碳链末端

## 物理性质
- 为白色晶体，易溶于水
- 带有甜味，但甜度不及蔗糖
- 广泛存在于生物体中，尤其在葡萄和成熟水果中含量丰富
- 也存在于蜂蜜和动物血液中

## 化学性质

### 1. 与氧化剂的反应（还原性）
银镜反应：CH₂OH(CHOH)₄CHO + Ag₂O = CH₂OH(CHOH)₄COOH + 2Ag↓
（生成葡萄糖酸）

被氢氧化铜氧化：加热后生成红色氧化亚铜（Cu₂O）沉淀

葡萄糖属于还原性糖——即可被温热的银氨溶液或氢氧化铜氧化的糖。

### 2. 酯化反应
葡萄糖与乙酸反应生成五乙酸葡萄糖酯（一个羟基与一个羧基作用）：
C₆H₇O(OH)₅ + 5CH₃COOH = C₆H₇O(OCOCH₃)₅ + 5H₂O

### 3. 发酵作用
在酒化酶催化下发酵生成醇：
C₆H₁₂O₆ = (酒化酶) 2C₂H₅OH + 2CO₂↑

### 4. 氧化供能
在人体组织内氧化释放热量：
C₆H₁₂O₆ + 6O₂ = 6CO₂ + 6H₂O + 673千卡

## 用途
1. 用作营养剂（人体活动所需能量的来源，以及病人的营养剂）
2. 用于制药工业（制取葡萄糖酸钙、合成维生素C等）
3. 用作棉织物印染的浆料
4. 制镜时用作银的还原剂

## 制取
利用自然界中的多糖或二糖水解来制取。工业上以淀粉、木屑和稻草为原料，在酸性溶液中水解：
(C₆H₁₀O₅)n + nH₂O = (H⁺, 酸) nC₆H₁₂O₆
