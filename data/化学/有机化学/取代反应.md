# 取代反应

## 定义
有机化合物分子中的氢原子被其他原子或原子团所替换的反应，称为取代反应。

## 典型实例
- **甲烷跟氯气**（光照下分步取代）：
  - CH₄ + Cl₂ → CH₃Cl + HCl（一氯甲烷）
  - CH₃Cl + Cl₂ → CH₂Cl₂ + HCl（二氯甲烷）
  - CH₂Cl₂ + Cl₂ → CHCl₃ + HCl（三氯甲烷/氯仿）
  - CHCl₃ + Cl₂ → CCl₄ + HCl（四氯甲烷/四氯化碳）
- **苯跟溴**（催化剂下）：
  - C₆H₆ + Br₂ =(Fe) C₆H₅Br + HBr（溴苯）

## 要点
- 取代反应是饱和烃（[[烷烃]]）和[[苯]]的特征反应之一；
- 苯发生取代反应比饱和烃更易进行；
- 取代反应与[[加成反应]]不同：取代是"替换"，加成是"加上"。
