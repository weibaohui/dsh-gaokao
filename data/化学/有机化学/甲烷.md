# 甲烷

## 定义
甲烷（CH₄）是最简单的烃，在理论上可以说它是一切有机物的母体。分子中仅含一个碳原子和四个氢原子。

## 分子结构
碳原子处于正四面体的中心，四个价键由中心指向四面体的四个顶点，与四个氢原子以相同的共价键结合。碳原子和四个氢原子不在同一平面上。

- 分子式：CH₄
- 电子式：H:C:H（其中":"表示共用电子对）
- 结构式：H—C—H（"—"表示价键）

## 物理性质
- 无色、无嗅、无味的气体
- 比重0.717克/升，约比空气轻一半（与空气重量比为0.5517）
- 难溶于水（20°C时每1升水约溶38毫升）

## 化学性质

### 1. 可燃性
在氧气充足时完全燃烧，发出淡蓝色火焰，放出大量热：
CH₄ + 2O₂ = CO₂ + 2H₂O + 210.8千卡

氧气不足时燃烧不完全，产生黑烟：
CH₄ + O₂ = C + 2H₂O

甲烷与空气按体积1:10混合点燃会发生猛烈爆炸。

### 2. 受热分解
- 1000~1100°C：CH₄ → C + 2H₂
- 1600°C电弧高温：2CH₄ → C₂H₂ + 3H₂

### 3. 稳定性
常温下化学性质很不活泼，不能被高锰酸钾氧化，不跟强酸强碱反应。

### 4. 取代反应（跟卤素）
甲烷跟氯气在漫射光下分步发生取代反应：
- CH₄ + Cl₂ → CH₃Cl + HCl（一氯甲烷）
- CH₃Cl + Cl₂ → CH₂Cl₂ + HCl（二氯甲烷）
- CH₂Cl₂ + Cl₂ → CHCl₃ + HCl（三氯甲烷/氯仿）
- CHCl₃ + Cl₂ → CCl₄ + HCl（四氯甲烷/四氯化碳）

## 来源
- **天然气**：主要成分是甲烷（体积约占85~95%）
- **沼气**：池沼底下有机物受菌类发酵产生
- **坑气**：煤的形成过程中植物残体分解产生

## 制取
实验室：无水醋酸钠跟碱石灰共热
CH₃COONa + NaOH =(加热) CH₄↑ + Na₂CO₃

工业上：主要来自天然气；农村可用发酵法制取（甲烷菌发酵）

## 用途
1. 燃料（家庭和工业用气体燃料）
2. 化工原料（制氯代物、炭黑、氢气、乙炔等）
