# 甲烷

## 定义
甲烷（CH₄）属于最简单的一种烃，从结构上看可视为各类有机物的原始模板。其分子仅由一个碳原子与四个氢原子构成。

## 分子结构
碳原子位于正四面体的中心位置，四条价键从中心伸向四面体的四个顶点，分别与四个氢原子形成等长的共价键。碳原子与其所连的四个氢原子并不共面。

- 分子式：CH₄
- 电子式：H:C:H（其中":"表示共用电子对）
- 结构式：H—C—H（"—"表示价键）

## 物理性质
- 外观为无色、无嗅、无味的气体
- 比重0.717克/升，约为空气的一半（与空气重量比为0.5517）
- 水溶性很差（20°C时每1升水约溶38毫升）

## 化学性质

### 1. 可燃性
氧气供给充足时可完全燃烧，火焰呈淡蓝色，并释放大量热量：
CH₄ + 2O₂ = CO₂ + 2H₂O + 210.8千卡

若氧气不足，则燃烧不充分，会析出黑烟：
CH₄ + O₂ = C + 2H₂O

当甲烷与空气以体积比1:10混合后点燃，会引起剧烈爆炸。

### 2. 受热分解
- 1000~1100°C：CH₄ → C + 2H₂
- 1600°C电弧高温：2CH₄ → C₂H₂ + 3H₂

### 3. 稳定性
常温条件下性质极不活泼，既不被高锰酸钾氧化，也不与强酸、强碱作用。

### 4. 取代反应（跟卤素）
在漫射光照射下，甲烷与氯气分步骤发生取代反应：
- CH₄ + Cl₂ → CH₃Cl + HCl（一氯甲烷）
- CH₃Cl + Cl₂ → CH₂Cl₂ + HCl（二氯甲烷）
- CH₂Cl₂ + Cl₂ → CHCl₃ + HCl（三氯甲烷/氯仿）
- CHCl₃ + Cl₂ → CCl₄ + HCl（四氯甲烷/四氯化碳）

## 来源
- **天然气**：其主体成分为甲烷（体积约占85~95%）
- **沼气**：池沼底部有机物在菌类发酵下生成
- **坑气**：煤形成过程中，植物残体分解而得

## 制取
实验室制法：将无水醋酸钠与碱石灰混合共热
CH₃COONa + NaOH =(加热) CH₄↑ + Na₂CO₃

工业制法：主要取自天然气；农村地区可借助甲烷菌发酵来制取

## 用途
1. 作燃料使用（家庭及工业上的气体燃料）
2. 作为化工原料（用于制取氯代物、炭黑、氢气、乙炔等）
