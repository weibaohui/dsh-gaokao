# 二糖

## 定义
二糖是由两分子单糖脱去一分子水缩合形成的碳水化合物。每分子二糖经水解后，可得到两分子单糖。

## 生成反应
2C₆H₁₂O₆ = C₁₂H₂₂O₁₁ + H₂O
　单糖　　　　二糖

## 水解反应
C₁₂H₂₂O₁₁ + H₂O = (加酸煮沸) C₆H₁₂O₆ + C₆H₁₂O₆
　二糖　　　　　　　　　　　单糖　　单糖

## 代表物
常见的二糖有蔗糖和麦芽糖两种，二者互为同分异构体，分子式均为C₁₂H₂₂O₁₁。

## 蔗糖与麦芽糖的比较

| 性质 | 蔗糖 | 麦芽糖 |
|---|---|---|
| 还原性 | 非还原性糖（无醛基） | 还原性糖（有醛基） |
| 银镜反应 | 不能发生 | 能发生 |
| 水解产物 | 葡萄糖 + 果糖 | 2个葡萄糖 |
| 来源 | 甘蔗和甜菜 | 淀粉受糖化酶作用 |

## 蔗糖水解
C₁₂H₂₂O₁₁ + H₂O = (H⁺或酶, 煮沸) C₆H₁₂O₆ + C₆H₁₂O₆
　蔗糖　　　　　　　　　　　　　果糖　　葡萄糖

## 麦芽糖水解
C₁₂H₂₂O₁₁ + H₂O = (酸或酶) 2C₆H₁₂O₆
　麦芽糖　　　　　　　　　葡萄糖

## 制取
- **蔗糖**：从甘蔗或甜菜的汁液中提取，需经过制汁→澄清处理→蒸发浓缩→结晶→分蜜等工序
- **麦芽糖**：以含淀粉的农产品（山芋、玉蜀黍、高粱）为原料，加入糖化酶使淀粉水解：
  2(C₆H₁₀O₅)n + nH₂O = (糖化酶, 60°C) nC₁₂H₂₂O₁₁
