# 乙醇

## 定义
乙醇（C₂H₅OH）俗称酒精，是酒的主要成分。分子中含有一个跟烃基（乙基）相连接的羟基。

## 分子结构
- 分子式：C₂H₆O
- 结构式：CH₃—CH₂—OH
- 含一个羟基（—OH），其中六个氢原子中五个跟碳原子直接结合，一个通过氧原子跟碳原子结合

经实验证明（钠跟乙醇反应产生氢气的体积测定），乙醇分子中只有一个氢原子被钠置换，即通过氧原子结合的那个特殊氢原子。

## 物理性质
- 无色液体，具有酒味
- 沸点78.3°C，比水轻（比重0.8克/毫升）
- 能以任何比率与水混溶
- 良好的溶剂，能溶解碘和油脂等

## 化学性质

### 1. 可燃性
C₂H₅OH + 3O₂ = 2CO₂ + 3H₂O + 327.6千卡

### 2. 跟碱金属反应
羟基上的氢原子被钠置换，生成乙醇钠：
2C₂H₅OH + 2Na = 2C₂H₅ONa + H₂↑

乙醇钠在水中不稳定，能生成NaOH，在有机反应里可当碱使用。

### 3. 跟氢卤酸反应
C₂H₅OH + HBr =(浓H₂SO₄) C₂H₅Br + H₂O

浓硫酸起双重作用：产生HBr和脱水（有利于正反应）。

### 4. 脱水反应
- 分子内脱水（160~180°C）：C₂H₅OH → CH₂=CH₂ + H₂O（生成乙烯）
- 分子间脱水（140°C）：2C₂H₅OH → (C₂H₅)₂O + H₂O（生成乙醚）

反应条件不同，产物不同。

## 用途
1. 燃料（酒精灯、喷灯，可代替汽油）
2. 溶剂（医药"酊"剂如碘酊）
3. 消毒防腐剂（能使蛋白质凝固杀菌）
4. 有机合成原料（合成橡胶、纤维、塑料、染料等）

## 制取
### 1. 发酵法
淀粉 →(淀粉酶) 葡萄糖 →(酒化酶) 乙醇
C₆H₁₂O₆ =(酒化酶) 2C₂H₅OH + 2CO₂↑

原料：糯米、高粱、玉蜀黍、山芋等含淀粉物质，或纤维素（废木材、稻草等）。

### 2. 合成法
利用石油加工的炼油气中的乙烯，在催化剂硫酸作用下跟水加成：
CH₂=CH₂ + H₂O =(H₂SO₄) C₂H₅OH
