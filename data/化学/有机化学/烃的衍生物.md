# 烃的衍生物

## 定义
烃分子中的一个或几个氢原子被其他元素的原子或原子团取代后所得到的生成物，称为烃的衍生物。其中决定化学特性的原子团即[[官能团]]。

## 分类

| 类别 | 通式 | 官能团 | 代表物 |
|---|---|---|---|
| 卤代烃 | RX | —X | 氯乙烷 C₂H₅Cl |
| 醇 | R—OH | —OH（羟基） | 乙醇 C₂H₅OH |
| 酚 | C₆H₅OH | —OH（连苯环） | 苯酚 C₆H₅OH |
| 醚 | R—O—R' | —O— | 乙醚 (C₂H₅)₂O |
| 醛 | R—CHO | —CHO（醛基） | 甲醛 HCHO |
| 酮 | R—CO—R' | —CO—（酮基） | 丙酮 CH₃COCH₃ |
| 羧酸 | R—COOH | —COOH（羧基） | 乙酸 CH₃COOH |
| 酯 | R—COO—R' | —COO— | 乙酸乙酯 CH₃COOC₂H₅ |

## 各类间的相互衍生关系

```
烷烃 →(卤代) 卤代烃 →(水解) 醇 →(去氢/氧化) 醛 →(氧化) 羧酸
                                    ↓ (加氢还原)
                                    醇
羧酸 + 醇 →(酯化) 酯 →(水解/皂化) 羧酸 + 醇
```
