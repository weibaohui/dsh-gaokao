# 官能团

## 定义
能够决定有机化合物化学特性的原子团，称为官能团。

## 常见官能团

| 官能团 | 名称 | 所属类别 |
|---|---|---|
| —X | 卤素 | [[卤代烃]] |
| —OH | [[羟基]] | [[醇类]]、[[苯酚]] |
| —O— | 醚键 | [[醚]] |
| —CHO | [[醛基]] | [[醛类]] |
| —CO— | 酮基 | [[酮]] |
| —COOH | [[羧基]] | [[羧酸]] |
| —COO— | 酯键 | [[酯]] |
| —NO₂ | 硝基 | [[硝基化合物]] |
| —NH₂ | 氨基 | [[胺]] |

## 要点
- 官能团决定了有机物的化学性质，也是[[烃的衍生物]]分类的依据；
- 含有相同官能团的化合物，其化学性质彼此相似。
