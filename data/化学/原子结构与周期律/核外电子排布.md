# 核外电子排布

## 内容
核外电子排布是指原子核外的电子按若干电子层进行分布的规律。电子的能量大小决定了其运转范围：能量较低者在距核较近处运转，能量较高者在距核较远处运转，由此形成不同的电子层。

核外电子排布的主要规则：
1. 电子分层排布，各电子层最多容纳的电子数为 **2n²**（n为电子层数）；
2. 第一层最多2个，第二层最多8个，第三层最多18个；
3. 任何原子的**最外电子层**最多不超过8个电子；
4. 已达最多电子数的层为饱和层，否则为不饱和层。

前19种元素的核外电子排布规律：
- 氢（1）→ 氦（2）：最外层电子1→2；
- 锂（3）→ 氖（10）：最外层电子1→8（出现第二层）；
- 钠（11）→ 氩（18）：最外层电子1→8（出现第三层）；
- 钾（19）：出现第四层。

由此可见，随原子序数递增，原子最外层电子数从1递增到8，周而复始，呈现**周期性变化**。

核外电子排布与元素性质的关系：
- 最外层为饱和层（如惰性气体He最外层2个、Ne/Ar等最外层8个）→ 化学性质非常稳定；
- 最外层不饱和 → 化学性质活泼，通过化学反应达到稳定结构。

核外电子排布与周期表位置的关系：
1. 电子层数 = 周期数；
2. 核内质子数 = 原子序数 = 核外电子数；
3. 主族元素最外层电子数 = 类序数 = 最高正化合价；负化合价 = 8 − 类序数；
4. 元素性质周期性变化的根本原因：核外电子（主要是最外层）周期性地重复同样的排布。
