# 元素周期表

## 内容
根据元素周期律，将已知元素按原子序数（核电荷数）递增的顺序排列成一个长列，再分为若干部分（每部分从最活泼的金属开始，到惰性气体结束），每一部分即为一个周期。将各周期上下重叠，使性质相似的元素处于同一纵行，便构成元素周期表。元素周期表是元素周期律的具体表现形式。

## 结构

### 横的方面——周期与列
共7个周期、10个列。

| 周期 | 元素数 | 类型 |
|---|---|---|
| 第一周期 | 2（H、He） | 短周期 |
| 第二周期 | 8（Li~Ne） | 短周期 |
| 第三周期 | 8（Na~Ar） | 短周期 |
| 第四周期 | 18 | 长周期（分2列） |
| 第五周期 | 18 | 长周期（分2列） |
| 第六周期 | 32 | 长周期（含镧系15种） |
| 第七周期 | 17（至今） | 不完全周期（含锕系） |

- 短周期：元素最外层电子数依次从1递增到8（第一周期从1到2），排布较为简单；
- 长周期：电子排布较复杂，前2个电子加在最外层，中间9个加在次外层，后6个再加回最外层，金属元素较多；
- 列：每一横行元素为一列，长周期分为偶数列和奇数列两列；
- 镧系元素（57~71）和锕系元素（89以后的14种）性质极为相似，在表中各占一格，其余排在表外。

### 纵的方面——类和族
共9个纵行（类），表上方以罗马数字标注类序数。

- 类序数 = 该类各元素的最高正化合价；
- 各类最高价氧化物通式：R₂O、RO、R₂O₃、RO₂、R₂O₅、RO₃、R₂O₇；
- 第IV类之后的非金属能生成气态氢化物，负化合价依次为−4、−3、−2、−1，通式分别为RH₄、RH₃、RH₂、RH；
- **零类**（第9纵行）：惰性气体，化合价为0；
- **第VIII类**（第8纵行）：过渡元素，连接长周期的偶数列和奇数列，共9个元素，化合价一般为+2或+3；
- **主族**：由短周期元素和长周期元素共同构成的族；
- **副族**：完全由长周期元素构成的族。

氢通常显+1价，置于第I类；在固态氢化物（NaH、CaH₂）中显−1价时，有时也置于第VII类。

## 原子结构与周期表的关系
1. 电子层数 = 周期数；
2. 核内质子数 = 原子序数 = 核外电子数；
3. 主族元素最外层电子数 = 最高正化合价 = 类序数；负化合价 = 8 − 类序数；
4. 元素性质周期性变化的根本原因：核外电子（主要是最外层）周期性地重复同样的排布。

## 重要意义
1. 推断元素性质（在表中的位置反映了其结构和性质）；
2. 预言新元素（门捷列夫曾预言钪、镓、锗等）；
3. 纠正原子量（如铯由123.4纠正为132.9）；
4. 探索新材料（农药相关元素区域、半导体Ge/Si）；
5. 指导学习和科学研究。
