# 磷酸

## 基本信息

- 分子式：H₃PO₄（正磷酸，简称磷酸）
- 磷为 +5 价
- 三价酸（含三个可电离的氢离子）

## 物理性质

- 纯磷酸为无色透明晶体，易溶于水
- 通常使用的是含磷酸 70~80% 的糖浆状溶液
- 中等强度的无机酸

## 制法

### 工业制法
- 磷酸钙（纤核磷灰石）与硫酸共热：
  - `Ca₃(PO₄)₂ + 3H₂SO₄ →(加热) 2H₃PO₄ + 3CaSO₄↓`
- 滤去硫酸钙沉淀即得磷酸溶液

### 由磷酐制取
- `P₂O₅ + 3H₂O →(热) 2H₃PO₄`

## 电离（三步）

- `H₃PO₄ ⇌ H⁺ + H₂PO₄⁻`（磷酸二氢根，1价，第一步电离较易）
- `H₂PO₄⁻ ⇌ H⁺ + HPO₄²⁻`（磷酸氢根，2价）
- `HPO₄²⁻ ⇌ H⁺ + PO₄³⁻`（磷酸根，3价）

## 磷酸盐

由于磷酸是三价酸，能生成三种不同的盐：

| 盐类 | 钠盐示例 | 溶解性 |
|------|---------|--------|
| 磷酸二氢盐 | NaH₂PO₄ | 溶解度最大 |
| 磷酸氢盐 | Na₂HPO₄ | 溶解度较小 |
| 正盐 | Na₃PO₄ | 几乎不溶（K、Na、铵盐除外） |

- 碱金属正盐在水中强烈水解，溶液呈强碱性（磷酸钠可作洗涤剂）

## 检验法

- 加硝酸银溶液产生黄色沉淀：
  - `PO₄³⁻ + 3Ag⁺ = Ag₃PO₄↓`（黄色）
- 加酸后沉淀溶解（但砷酸盐、硅酸盐也有类似反应，不够可靠）

## 磷肥

磷酸盐在农业上有重要意义。

### 1. 磷矿粉
- 天然磷矿石磨粉，主要成分 Ca₃(PO₄)₂（不溶，肥效慢）

### 2. 过磷酸钙（最常用）
- `Ca₃(PO₄)₂ + 2H₂SO₄ = 2CaSO₄ + Ca(H₂PO₄)₂`
- 磷酸二氢钙 + 硫酸钙的混合物
- 可溶性磷肥

### 3. 重过磷酸钙
- 纯 Ca(H₂PO₄)₂，肥效更高

### 4. 沉淀磷酸钙
- CaHPO₄，适用于酸性土壤

### 5. 磷酸铵肥料（安福粉）
- NH₄H₂PO₄ + (NH₄)₂HPO₄ 混合物
- 氮磷混合肥，肥效高

### 注意
- 磷肥不能与消石灰混用（生成不溶性 Ca₃(PO₄)₂ 失去肥效）
  - `Ca(H₂PO₄)₂ + 2Ca(OH)₂ = Ca₃(PO₄)₂↓ + 4H₂O`

## 用途

- 制造各种磷酸盐
- 制造磷肥
- 工农业常用酸类（仅次于硫酸、盐酸、硝酸）
