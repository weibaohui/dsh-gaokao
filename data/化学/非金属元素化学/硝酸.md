# 硝酸

## 基本信息

- 分子式：HNO₃
- 与硫酸、盐酸并称化学基本工业三强酸
- 氮为 +5 价（最高正价）

## 物理性质

- 纯硝酸为无色易挥发液体，有刺激性气味
- 沸点 83°C（沸腾时部分分解）
- 常用浓硝酸约 65%
- 98% 浓硝酸在空气里"发烟"（发烟硝酸，硝酸蒸气遇水蒸气形成液滴）
- 能以任何比率溶于水

## 化学性质

### 1. 强酸的通性
- 稀溶液完全电离出 H⁺
- 使蓝色石蕊变红
- 与碱性氧化物、碱、盐反应

### 2. 不稳定性
- 纯硝酸或浓硝酸见光/受热分解：
  - `4HNO₃ →(见光或受热) 2H₂O + 4NO₂↑ + O₂↑`
- 分解放出的 NO₂ 溶于溶液使其呈黄色
- 须存于棕色瓶，放黑暗低温处

### 3. 强氧化性
- 能氧化许多非金属（甚至引起燃烧）：
  - `C + 4HNO₃ = 2H₂O + 4NO₂↑ + CO₂↑`
- 能氧化多种有机物（纸张焦化、皮肤灼伤）

### 4. 与金属反应
- 与绝大多数金属反应（Au、Pt 除外）
- 不放出氢气（被氧化成水）
- 生成硝酸盐 + 水 + 氮的氧化物

#### 浓硝酸 + 铜
- `Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2H₂O + 2NO₂↑`（棕色气体）
- 实验室制 NO₂ 的方法

#### 稀硝酸 + 铜
- `3Cu + 8HNO₃(稀) →(加热) 3Cu(NO₃)₂ + 4H₂O + 2NO↑`（无色气体）
- 实验室制 NO 的方法

### 5. 王水
- 1 体积 HNO₃ + 3 体积 HCl
- 氧化能力更强，能溶解金和铂

## 制法

### 实验室制法
- 硝酸钠与浓硫酸共热（曲颈甑）：
  - `NaNO₃ + H₂SO₄(浓) →(加热) NaHSO₄ + HNO₃↑`
- 须用全玻璃仪器（硝酸腐蚀橡皮/软木塞）
- 加热温度不可过高（防硝酸分解）

### 工业制法（合成法）
基于氨的接触催化氧化：

1. **氨的接触氧化**：`4NH₃ + 5O₂ →(Pt, 800°C) 4NO + 6H₂O`
2. **一氧化氮的氧化**：`2NO + O₂ = 2NO₂`
3. **二氧化氮的吸收**：`3NO₂ + H₂O = 2HNO₃ + NO`
   - 生成的 NO 循环再氧化再吸收
   - 多塔逆流吸收法

- 一般制得约 50% 硝酸
- 制更浓硝酸：与浓硫酸（脱水剂）混合蒸馏，可得 90% 以上

## 用途

- 制造炸药（TNT、硝酸铵炸药等）
- 制造染料、塑料、药剂
- 制造硝酸铵（含氮量高的氮肥）
- 增强国防力量
