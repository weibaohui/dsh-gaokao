# 硝酸

## 基本信息

- 分子式：HNO₃
- 与硫酸、盐酸并称为化学基本工业三强酸
- 氮为 +5 价（最高正价）

## 物理性质

- 纯硝酸为无色、易挥发的液体，带刺激性气味
- 沸点 83°C（沸腾时会部分分解）
- 常用浓硝酸浓度约 65%
- 98% 浓硝酸在空气中会"发烟"（即发烟硝酸，硝酸蒸气遇水蒸气形成液滴）
- 能以任意比例溶于水

## 化学性质

### 1. 强酸的通性
- 稀溶液能完全电离出 H⁺
- 使蓝色石蕊变红
- 能与碱性氧化物、碱、盐反应

### 2. 不稳定性
- 纯硝酸或浓硝酸见光或受热时会分解：
  - `4HNO₃ →(见光或受热) 2H₂O + 4NO₂↑ + O₂↑`
- 分解释放的 NO₂ 溶于溶液中使其呈黄色
- 须贮存于棕色瓶中，并放置在黑暗低温处

### 3. 强氧化性
- 能氧化许多非金属（甚至引起燃烧）：
  - `C + 4HNO₃ = 2H₂O + 4NO₂↑ + CO₂↑`
- 能氧化多种有机物（使纸张焦化、灼伤皮肤）

### 4. 与金属反应
- 能与绝大多数金属反应（Au、Pt 除外）
- 不放出氢气（氢被氧化为水）
- 反应生成硝酸盐 + 水 + 氮的氧化物

#### 浓硝酸 + 铜
- `Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2H₂O + 2NO₂↑`（棕色气体）
- 这是实验室制取 NO₂ 的方法

#### 稀硝酸 + 铜
- `3Cu + 8HNO₃(稀) →(加热) 3Cu(NO₃)₂ + 4H₂O + 2NO↑`（无色气体）
- 这是实验室制取 NO 的方法

### 5. 王水
- 由 1 体积 HNO₃ 与 3 体积 HCl 混合而成
- 氧化能力更强，能溶解金和铂

## 制法

### 实验室制法
- 硝酸钠与浓硫酸共热（使用曲颈甑）：
  - `NaNO₃ + H₂SO₄(浓) →(加热) NaHSO₄ + HNO₃↑`
- 须使用全玻璃仪器（硝酸会腐蚀橡皮/软木塞）
- 加热温度不宜过高（以防硝酸分解）

### 工业制法（合成法）
基于氨的接触催化氧化：

1. **氨的接触氧化**：`4NH₃ + 5O₂ →(Pt, 800°C) 4NO + 6H₂O`
2. **一氧化氮的氧化**：`2NO + O₂ = 2NO₂`
3. **二氧化氮的吸收**：`3NO₂ + H₂O = 2HNO₃ + NO`
   - 生成的 NO 循环再氧化、再吸收
   - 采用多塔逆流吸收法

- 一般制得约 50% 的硝酸
- 制取更浓硝酸：与浓硫酸（作脱水剂）混合蒸馏，可获得 90% 以上浓度

## 用途

- 用于制造炸药（TNT、硝酸铵炸药等）
- 用于制造染料、塑料、药剂
- 用于制造硝酸铵（含氮量高的氮肥）
- 用于增强国防力量
