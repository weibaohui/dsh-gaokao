# 溴

## 基本信息

- 元素符号：Br，原子量：80
- 分子式：Br₂，分子量：160
- "溴"从恶臭得名
- 活动性比氯差，比碘强

## 物理性质

- 深红色、容易挥发的液体（常温下唯一液态卤素单质）
- 蒸气有非常难闻的窒息性恶臭，有毒
- 液态溴溅在皮肤上引起难治烫伤
- 沸点 58.8°C，凝固点 -7.3°C
- 微溶于水（20°C 时 3.4% 饱和溶液，显橙色，称"溴水"）
- 易溶于汽油、苯、二硫化碳等溶剂（可用萃取法分离）

## 化学性质

与氯相似但活动性不如氯：

### 与氢气反应
- `H₂ + Br₂ →(加热) 2HBr`
- 须在加热条件下化合，不发生爆炸

### 与水反应
- 比氯更慢，溴水可保存相当长时间

## 存在

- 自然界无游离态溴
- 溴化物（NaBr、KBr）主要存在于海水（约 0.007% 溴）
- 数量远少于氯化物

## 溴化氢（HBr）与氢溴酸

- 无色气体，有刺激性气味，易溶于水
- 水溶液为氢溴酸（强酸），性质与盐酸相似
- 比盐酸不稳定，能被浓硫酸氧化：
  - `2HBr + H₂SO₄ →(加热) Br₂↑ + SO₂↑ + 2H₂O`
- 实验室制法：`NaBr + H₂SO₄ →(加热) NaHSO₄ + HBr↑`（混有溴蒸气）

## 溴化银（AgBr）

- 淡黄色沉淀：`NaBr + AgNO₃ = AgBr↓ + NaNO₃`
- **感光性**：`2AgBr →(光照) 2Ag + Br₂`
- 用于照相和电影感光材料

## 溴化物的检验

- 加硝酸银溶液 → 淡黄色沉淀（AgBr）
- 不溶于稀硝酸

## 溴的制法

- 氯置换法：`2NaBr + Cl₂ = 2NaCl + Br₂`
- 氧化法：`4HBr + MnO₂ →(加热) MnBr₂ + 2H₂O + Br₂↑`

## 用途

- 制造药剂、染料
- 溴化银（照相术）
- 溴化钠/溴化钾（医学镇静剂）
