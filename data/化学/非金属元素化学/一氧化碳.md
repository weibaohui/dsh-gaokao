# 一氧化碳

## 基本信息

- 分子式：CO
- 由碳、氧两种元素组成，碳为 +2 价（属可变化合价）
- 由二氧化碳经炽热碳还原而得：`CO₂ + C →(高温) 2CO`

## 物理性质

- 为无色、无气味的气体
- 比空气稍轻：1 升 CO 重 1.25 克
- 难溶于水（20°C 时 1 体积水溶 0.2 体积 CO）
- 不与水发生作用（可用排水集气法收集）

## 化学性质

### 1. 可燃性
- 可在纯氧或空气中燃烧，发出蓝色火焰：
  - `2CO + O₂ →(点燃) 2CO₂`
- 燃烧时火焰温度可达 1400°C，是很有实用价值的气体燃料

### 2. 还原性
- 能夺取某些含氧化合物中的氧，是一种还原剂：
  - `Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂↑`（炼铁原理）
- 与碳类似，在高温下能还原金属氧化物

### 3. 剧毒性
- 与血色素的结合能力约为氧气的 210 倍
- 使血色素丧失输送氧气的功能（内窒息）
- 空气中含量达 0.06% 即有毒，0.15% 有生命危险，1% 在短时间内可致死
- 因无色无味，不易被察觉，危害性极大

## 工业制法

### 发生炉煤气
- 空气从底部鼓入煤气发生炉，碳不完全燃烧产生 CO：
  - `C + O₂ →(点燃) CO₂`（底层完全燃烧）
  - `CO₂ + C →(高温) 2CO`（中部还原）
- 主要成分：CO + N₂ + 少量 CO₂

### 水煤气
- 水蒸气通过红热的碳：
  - `C + H₂O(水蒸气) →(高温) CO↑ + H₂↑`
- 主要成分：CO + H₂
- 燃烧放热量约为发生炉煤气的 8 倍

## 用途

- 用作气体燃料（发生炉煤气、水煤气）
- 用作冶金工业的还原剂（炼铁）
