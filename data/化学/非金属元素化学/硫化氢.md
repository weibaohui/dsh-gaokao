# 硫化氢

## 基本信息

- 分子式：H₂S
- 硫跟氢的化合物，硫为 -2 价
- 自然界存在于火山气体、某些矿泉中
- 动植物残骸腐烂时蛋白质分解释放 H₂S（腐蛋臭味）

## 物理性质

- 无色气体，有特殊的腐卵臭味
- 比空气略重（1.172 倍）
- 能溶于水：20°C 时 1 体积水溶 2.4 体积 H₂S
- 有毒：吸入引起头痛、头晕、恶心；严重时嗅觉麻痹（危险），可致死

## 化学性质

### 1. 不稳定性
- 不如水稳定，300°C 以上即分解：
  - `H₂S →(300°C) H₂ + S`
- 说明硫的化学性质不如氧活泼

### 2. 可燃性（与氧反应）
- 不完全燃烧（空气不足）：`2H₂S + O₂ = 2H₂O + 2S`（氧置换出硫）
- 完全燃烧（空气充足）：`2H₂S + 3O₂ = 2H₂O + 2SO₂`（产生 SO₂）

### 3. 还原性
- 水溶液在空气中即被氧化变浑浊：
  - `2H₂S + O₂ = 2H₂O + 2S↓`
- 氯气可置换出硫化氢中的硫：`Cl₂ + H₂S = 2HCl + S`（证明氯比硫活泼）

## 氢硫酸（H₂S 水溶液）

- 弱酸，比盐酸弱得多
- 具有酸的一切通性
- 特性：
  1. 极易挥发（不能通过蒸发浓缩）
  2. 易被氧化（难保存）
  3. 能与多种金属盐反应生成不同颜色溶解度的硫化物

### 金属硫化物（用于鉴别金属）

| 硫化物 | 分子式 | 溶解性 | 颜色 |
|--------|--------|--------|------|
| 硫化钠 | Na₂S | 溶于水 | 无色 |
| 硫化亚铁 | FeS | 不溶水，溶于稀盐酸 | 黑褐 |
| 硫化锌 | ZnS | 不溶水，溶于稀盐酸 | 白 |
| 硫化镉 | CdS | 不溶水，不溶稀盐酸 | 黄 |
| 硫化铅 | PbS | 不溶水，不溶稀盐酸 | 黑 |
| 硫化铜 | CuS | 不溶水，不溶稀盐酸 | 黑 |
| 硫化汞 | HgS | 不溶水，不溶稀盐酸 | 黑 |

## 制法

- 硫化亚铁与稀酸反应（启普发生器）：
  - `FeS + H₂SO₄ = FeSO₄ + H₂S↑`
  - `FeS + 2HCl = FeCl₂ + H₂S↑`
