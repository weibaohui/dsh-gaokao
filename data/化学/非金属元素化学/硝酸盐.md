# 硝酸盐

## 基本信息

- 由硝酸根离子（NO₃⁻）和金属离子结合而成的离子化合物
- 大部分可用金属和硝酸直接反应制得
- 实验室常用试剂

## 物理性质

- 都是固体
- 都易溶于水
- 能精制成纯净晶体

## 化学性质

### 1. 加热分解（高温下不稳定）
高温下硝酸盐是强氧化剂（水溶液几乎无氧化性）。

分解规律分两类：

#### 活泼金属硝酸盐（K、Na等）
- 生成亚硝酸盐 + 氧气：
  - `2KNO₃ →(加热) 2KNO₂ + O₂↑`
  - 产物：亚硝酸钾（KNO₂）

#### 不活泼金属硝酸盐（Cu、Pb等）
- 生成金属氧化物 + 二氧化氮 + 氧气：
  - `2Cu(NO₃)₂ →(加热) 2CuO + 4NO₂↑ + O₂↑`

## 自然界存在的硝酸盐

| 名称 | 分子式 | 备注 |
|------|--------|------|
| 硝酸钠 | NaNO₃ | 智利硝石 |
| 硝酸钾 | KNO₃ | 钾硝石，黑火药原料 |
| 硝酸钙 | Ca(NO₃)₂ | |

## 检验法

**硝酸盐的检验**：
1. 固体试样 + 浓硫酸 + 铜片，加热
2. 产生棕色 NO₂ 气体

原理：
- `NaNO₃ + H₂SO₄(浓) →(加热) NaHSO₄ + HNO₃`
- `3Cu + 8HNO₃ = 3Cu(NO₃)₂ + 4H₂O + 2NO↑`
- `2NO + O₂(空气) = 2NO₂`（棕色）

注意：此法对少量或溶液试样不够准确。

## 用途

### 1. 制造炸药
- **黑火药**：75% KNO₃ + 10% S + 15% C
  - KNO₃ 利用强氧化性剧烈氧化硫和碳
  - 反应高速进行，气体体积膨胀约 2000 倍，发生爆炸
  - 不能用 NaNO₃ 代替（NaNO₃ 有潮解性）
- **"阿芒拿"**：NH₄NO₃ + 铝粉等可燃物

### 2. 用作肥料
- 最易被植物吸收的含氮无机物
- 常用：NaNO₃、KNO₃、Ca(NO₃)₂、NH₄NO₃
