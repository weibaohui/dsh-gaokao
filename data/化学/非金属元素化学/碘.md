# 碘

## 基本信息

- 元素符号：I，原子量：127
- 分子式：I₂，分子量：254
- "碘"希腊文原意为"紫色"
- 活动性比溴更弱，是卤族中化学性质最不活泼的

## 物理性质

- 紫黑色晶体
- 有**升华**性质：加热时固体直接气化成紫色蒸气，蒸气遇冷直接凝为固体（不经液态）
- 利用升华可精制碘
- 微溶于水（20°C 时仅 0.34 g/100 g）
- 易溶于酒精（碘酒/碘酊，用于消毒消肿）
- 易溶于汽油、二硫化碳等

## 化学性质

### 1. 与氢气反应
- 只有在相当高温下才能化合：
  - `H₂ + I₂ →(高温) 2HI`
- 碘化氢很不稳定，生成后立即有部分分解

### 2. 与非金属反应
- 只能跟磷直接化合

### 3. 特征反应——遇淀粉显深蓝色
- `碘 + 淀粉 → 深蓝色`（检验碘的特征反应）
- **注意**：只有单质碘才有此反应，碘化物中的碘无此反应
- 利用淀粉碘化钾试纸可检验氯气：
  - `2KI + Cl₂ = 2KCl + I₂`（生成的 I₂ 使淀粉变蓝）

## 存在

- 自然界无游离态碘
- 碘化物（NaI、KI）存在于海水（约 0.000005%）、矿泉、石油井水
- 海藻（海带等）能积集碘（风干后含碘可达 0.5%）
- 人的甲状腺含少量碘，对新陈代谢有重要作用
- 缺碘导致大脖子病（甲状腺肿大）

## 碘化氢（HI）与氢碘酸

- 无色气体，有刺激性气味，易溶于水
- 水溶液为氢碘酸（强酸）
- 最不稳定，能被空气中氧气氧化：
  - `4HI + O₂ = 2H₂O + 2I₂`（溶液变棕色）
- 不能用浓硫酸与碘化物反应制取（会被氧化）

## 碘化银（AgI）

- 黄色沉淀：`KI + AgNO₃ = AgI↓ + KNO₃`
- 有感光性：`2AgI →(光照) 2Ag + I₂`

## 碘的制法

- 从海带灰或海藻灰中提取
- 氯/溴置换法：
  - `2KI + Cl₂ = 2KCl + I₂`
  - `2KI + Br₂ = 2KBr + I₂`

## 用途

- 碘酒（消毒消肿）
- 含碘食物（海带、紫菜）预防甲状腺肿大
