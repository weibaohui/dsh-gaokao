# 磷肥

## 基本信息

- 磷肥是含磷的肥料，磷酸盐在农业上有重要意义
- 植物从土壤中吸收可溶性磷酸盐
- 天然磷矿石主要成分 Ca₃(PO₄)₂ 不溶于水，肥效慢

## 重要磷肥

### 1. 磷矿粉

- 天然磷矿石磨粉，主要成分 Ca₃(PO₄)₂
- 不溶于水，肥效慢

### 2. 过磷酸钙（最常用）

- `Ca₃(PO₄)₂ + 2H₂SO₄ = 2CaSO₄ + Ca(H₂PO₄)₂`
- 磷酸二氢钙 + 硫酸钙的混合物
- 可溶性磷肥

### 3. 重过磷酸钙

- 纯 Ca(H₂PO₄)₂，肥效更高

### 4. 沉淀磷酸钙

- CaHPO₄，适用于酸性土壤

### 5. 磷酸铵肥料（安福粉）

- NH₄H₂PO₄ 与 (NH₄)₂HPO₄ 混合物
- 氮磷混合肥，肥效高

## 注意

- 磷肥不能与消石灰混用（生成不溶性 Ca₃(PO₄)₂ 失去肥效）
  - `Ca(H₂PO₄)₂ + 2Ca(OH)₂ = Ca₃(PO₄)₂↓ + 4H₂O`
