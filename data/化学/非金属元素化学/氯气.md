# 氯气

## 基本信息

- 元素符号：Cl，原子量：35.5
- 分子式：Cl₂，分子量：71
- 是卤族元素中最具代表性、应用最广的元素

## 物理性质

- 为黄绿色气体（"氯"因颜色而得名），希腊文原意为"绿色"
- 具剧毒，带有剧烈的刺激性气味，会刺激鼻粘膜和喉头粘膜
- 比空气重 2.5 倍（标准状况下 1 升氯气重 3.17 克）
- 易液化：常温下加 6 atm 或常压下冷至 -34°C 即液化（呈黄色油状液体）
- 凝固点 -101°C（呈黄色固体）
- 常温下 1 体积水可溶 2.5 体积 Cl₂（即氯水）

## 化学性质

化学性质非常活泼，能与几乎所有金属、大部分非金属、水及有机化合物发生反应。

### 1. 与金属反应
- 钠：`2Na + Cl₂ = 2NaCl`（发出明亮的黄色火焰，产生白烟）
- 铜在氯气中燃烧：`Cu + Cl₂ = CuCl₂`（产生棕黄色烟）
- 铁在氯气中燃烧：`2Fe + 3Cl₂ = 2FeCl₃`（发出明亮火花，呈褐色）
- 氯气能与所有金属化合

### 2. 与氢气反应
- `H₂ + Cl₂ →(光照/点燃) 2HCl`（光照下发生爆炸化合）
- 常温下化合非常缓慢
- 氢气在氯气中燃烧也可生成 HCl

### 3. 与非金属反应
- 磷：`2P + 3Cl₂ = 2PCl₃`；`2P + 5Cl₂ = 2PCl₅`

### 4. 与水反应
- 氯水中部分氯分子与水反应：
  - `2Cl₂ + 2H₂O = 4HCl + O₂↑`
- 实际分两步进行：先生成盐酸和次氯酸（HClO），次氯酸再分解放出氧
- 次氯酸具有漂白和杀菌作用（这是氯气漂白和消毒的本质）
- 干燥氯气无漂白作用（需有水参与）

### 5. 与碱反应
- `2Cl₂ + 2Ca(OH)₂ = Ca(OCl)₂ + CaCl₂ + 2H₂O`（用于制漂白粉）
- 漂白粉的有效成分：次氯酸钙 Ca(OCl)₂

## 存在

- 自然界中不存在游离态氯（因过于活泼）
- 主要以 NaCl（食盐）的形式存在于海水（约含 3%）、井盐、池盐、岩盐中
- KCl 的分布也较广（钾石盐、光卤石）

## 制法

### 实验室制法
- 用二氧化锰氧化盐酸：
  - `4HCl + MnO₂ →(加热) MnCl₂ + Cl₂↑ + 2H₂O`
- 简便方法：高锰酸钾 + 浓盐酸（不需加热）
  - `2KMnO₄ + 16HCl = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O`
- 用下方排空气法收集（因比空气重）
- 尾气用 NaOH 溶液吸收

### 工业制法
- 电解食盐水溶液（同时产生 H₂ 和 NaOH）

## 用途

- 用于漂白织物、纸浆（需用潮湿氯气）
- 用于消毒自来水
- 用于制造杀虫剂（六六六 C₆H₆Cl₆、滴滴涕 C₁₄H₉Cl₅）
- 用于杀灭田鼠、仓库害虫
