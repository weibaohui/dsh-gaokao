# 氯气

## 基本信息

- 元素符号：Cl，原子量：35.5
- 分子式：Cl₂，分子量：71
- 卤族元素中最有代表性、应用最广的元素

## 物理性质

- 黄绿色气体（"氯"因颜色得名），希腊原文意为"绿色"
- 剧毒，有剧烈刺激性气味，刺激鼻粘膜和喉头粘膜
- 比空气重 2.5 倍（标准状况下 1 升氯气重 3.17 克）
- 易液化：常温加 6 atm 或常压冷至 -34°C 即液化（黄色油状液体）
- 凝固点 -101°C（黄色固体）
- 常温 1 体积水溶 2.5 体积 Cl₂（氯水）

## 化学性质

化学性质非常活泼，能跟几乎所有金属、大部分非金属、水及有机化合物反应。

### 1. 与金属反应
- 钠：`2Na + Cl₂ = 2NaCl`（明亮黄色火焰，白烟）
- 铜在氯气中燃烧：`Cu + Cl₂ = CuCl₂`（棕黄色烟）
- 铁在氯气中燃烧：`2Fe + 3Cl₂ = 2FeCl₃`（明亮火花，褐色）
- 氯气能跟所有金属化合

### 2. 与氢气反应
- `H₂ + Cl₂ →(光照/点燃) 2HCl`（光照下爆炸化合）
- 常温下化合非常缓慢
- 氢气在氯气中燃烧也可生成 HCl

### 3. 与非金属反应
- 磷：`2P + 3Cl₂ = 2PCl₃`；`2P + 5Cl₂ = 2PCl₅`

### 4. 与水反应
- 氯水中部分氯分子与水反应：
  - `2Cl₂ + 2H₂O = 4HCl + O₂↑`
- 实际分两步：先生成盐酸和次氯酸（HClO），次氯酸再分解放氧
- 次氯酸有漂白和杀菌作用（氯气的漂白/消毒本质）
- 干燥氯气无漂白作用（需水参与）

### 5. 与碱反应
- `2Cl₂ + 2Ca(OH)₂ = Ca(OCl)₂ + CaCl₂ + 2H₂O`（制漂白粉）
- 漂白粉有效成分：次氯酸钙 Ca(OCl)₂

## 存在

- 自然界无游离态氯（太活泼）
- 主要以 NaCl（食盐）形式存在于海水（约 3%）、井盐、池盐、岩盐
- KCl 分布也广（钾石盐、光卤石）

## 制法

### 实验室制法
- 二氧化锰氧化盐酸：
  - `4HCl + MnO₂ →(加热) MnCl₂ + Cl₂↑ + 2H₂O`
- 简便方法：高锰酸钾 + 浓盐酸（不加热）
  - `2KMnO₄ + 16HCl = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O`
- 下方排空气法收集（比空气重）
- 尾气用 NaOH 溶液吸收

### 工业制法
- 电解食盐水溶液（同时产生 H₂ 和 NaOH）

## 用途

- 漂白织物、纸浆（潮湿氯气）
- 消毒自来水
- 制造杀虫剂（六六六 C₆H₆Cl₆、滴滴涕 C₁₄H₉Cl₅）
- 杀灭田鼠、仓库害虫
