# 硫酸

## 基本信息

- 分子式：H₂SO₄
- 基本化学工业中最重要的产品之一
- 市售浓硫酸 98%，比重 1.84，沸点 338°C

## 物理性质

- 无色粘稠油状液体，几乎比水重一倍
- 不挥发酸（打开瓶盖不冒"烟"）
- 能以任何比与水混和，同时产生大量热
- 沸点 338°C（比盐酸、硝酸高得多）

## 化学性质

### 1. 强酸的通性
- 使蓝色石蕊变红
- 与活泼金属置换反应放出 H₂：`H₂SO₄(稀) + Zn = H₂↑ + ZnSO₄`
- 与碱性氧化物：`H₂SO₄ + CuO →(加热) CuSO₄ + H₂O`
- 与碱中和（二价酸，可生成正盐或酸式盐）
- 与盐复分解：`H₂SO₄ + NaCl →(加热) NaHSO₄ + HCl↑`（利用不挥发性制其他酸）

### 2. 浓硫酸的特殊性质

#### 强氧化性
- 与铜（不活泼金属）反应不放出 H₂：
  - `Cu + 2H₂SO₄(浓) →(加热) CuSO₄ + SO₂↑ + 2H₂O`
- 与非金属反应：`C + 2H₂SO₄(浓) →(加热) CO₂↑ + 2SO₂↑ + 2H₂O`
- **铁器钝化**：浓硫酸使铁表面形成致密氧化膜，可用铁器贮存

#### 吸水性/脱水性
- 吸水蒸气：用于干燥气体（洗气瓶）和干燥器
- 使有机物脱水碳化：`C₁₂H₂₂O₁₁ →(浓硫酸) 12C + 11H₂O`
- 与水形成水合物（H₂SO₄·H₂O、H₂SO₄·2H₂O），放出大量热
- 稀释时必须将浓硫酸缓慢注入水中（不可反向！）

## 工业制法（接触法）

三个主要过程：

### 1. 二氧化硫的制造
- 燃烧黄铁矿：`4FeS₂ + 11O₂ →(燃烧) 2Fe₂O₃ + 8SO₂↑`

### 2. 二氧化硫催化氧化成三氧化硫
- 炉气精制：除尘→洗涤（稀硫酸去砷化合物）→干燥（浓硫酸）
- 接触室：V₂O₅ 催化剂，约 500°C
- `2SO₂ + O₂ →(V₂O₅, 500°C) 2SO₃`

### 3. 三氧化硫的吸收
- 用 98% 浓硫酸吸收（不用水，避免酸雾损失）
- 生成发烟硫酸，稀释得各种浓度硫酸

## 用途

- 制造化肥（过磷酸钙、硫酸铵/肥田粉）
- 金属加工除锈
- 制造其他酸（盐酸、氢氟酸、氢硫酸等）
- 石油/植物油精炼
- 干燥剂/脱水剂（炸药、赛璐珞、染料）
- 制糖、制革等
