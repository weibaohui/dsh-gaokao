# 氨

## 基本信息

- 分子式：NH₃，氮为 -3 价
- 是现代化学工业中最重要的产品之一
- 注意：NH₃ 并非酸，不电离出 H⁺

## 物理性质

- 为无色、带刺激性气味的气体
- 比空气轻（为空气的 0.59 倍）
- 极易溶于水：常温下 1 体积水可溶约 700 体积 NH₃（比 HCl 更易溶）
- 可用于做喷泉实验
- 极易液化：冷却至 -33°C 或常温下加压至 7~8 atm 即凝结为无色液体
- 液氨易气化，能吸收大量热（可用作致冷剂）

## 化学性质

### 1. 与水反应
- `NH₃ + H₂O = NH₄OH`（氢氧化铵，属弱碱）
- `NH₄OH ⇌ NH₄⁺ + OH⁻`
- 氨水呈碱性（可使红色石蕊变蓝）
- 氢氧化铵受热分解：`NH₄OH →(加热) NH₃↑ + H₂O`

### 2. 与酸反应（生成铵盐）
- `NH₃ + HCl = NH₄Cl`（白烟反应——两根玻璃棒靠近时产生白烟）
- `NH₃ + HNO₃ = NH₄NO₃`
- `2NH₃ + H₂SO₄ = (NH₄)₂SO₄`

### 3. 与氧反应
- 在纯氧中燃烧：`4NH₃ + 3O₂ →(燃烧) 2N₂ + 6H₂O`
- **接触催化氧化**（工业制硝酸的基础）：
  - `4NH₃ + 5O₂ →(Pt催化剂, 加热) 4NO + 6H₂O`

## 铵与氨的区别

- **氨（NH₃）**：是一种化合物，可单独存在
- **铵（NH₄⁺）**：是带一个正电荷的阳离子（一价），不能单独存在
- 铵离子的性质与 K⁺、Na⁺ 相似

## 工业制法（合成氨）

### 反应原理
- `N₂ + 3H₂ ⇌ 2NH₃ + 22千卡`（属放热、体积缩小的可逆反应）

### 生产条件
- 温度：450~530°C
- 压强：200~320 atm
- 催化剂：还原铁（加入 K₂O、Al₂O₃ 以增强催化效果）

### 生产流程（三阶段）
1. **原料制备**：N₂（由蒸发液态空气获得）+ H₂（由水煤气分离获得），净化除去杂质后按 1:3 混合并压缩
2. **氨的合成**：在合成塔（接触室 + 热交换器）中进行，平衡时含 NH₃ 约 15%
3. **氨的液化和分离**：冷却使 NH₃ 液化分离，未反应的气体循环使用

### 化学平衡的应用
- 增大压强、降低温度 → 平衡向生成 NH₃ 的方向移动
- 温度不宜过低（反应速率太慢），压强不宜过高（设备条件受限）

## 用途

- 用于制造硝酸、铵盐（氮肥）
- 用作致冷剂（冷藏库、电冰箱）
- 用作塑料工业、纯碱工业、制药工业的原料
- 氨水（用作氮肥，但需注意其挥发性和腐蚀性）
