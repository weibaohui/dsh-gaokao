# 氮的氧化物

## 基本信息

- 氮的化合价不固定，可形成多种氧化物
- 氮跟氧化合时化合价可为 +1、+2、+3、+4、+5 价

## 重要氮的氧化物

### 1. 一氧化氮（NO）
- 无色气体
- 不溶于水
- 常温下很易与氧气进一步化合：
  - `2NO + O₂ = 2NO₂`（无色变棕色）
- 实验室制法（稀硝酸 + 铜加热）：
  - `3Cu + 8HNO₃(稀) →(加热) 3Cu(NO₃)₂ + 4H₂O + 2NO↑`
- 氮为 +2 价

### 2. 二氧化氮（NO₂）
- 棕色气体，有刺激性气味
- 有毒
- 易溶于水的酸性氧化物（NO 不溶于水）
- 溶于水生成硝酸和一氧化氮：
  - `3NO₂ + H₂O = 2HNO₃ + NO`
- 实验室制法（浓硝酸 + 铜）：
  - `Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2H₂O + 2NO₂↑`
- 氮为 +4 价

### 3. 其他氮的氧化物
| 名称 | 分子式 | 氮的化合价 |
|------|--------|-----------|
| 一氧化二氮 | N₂O | +1 |
| 三氧化二氮 | N₂O₃ | +3 |
| 五氧化二氮 | N₂O₅ | +5（最高正价） |

## NO 与 NO₂ 的关系

- `N₂ + O₂ →(电火花) 2NO`（氮气与氧气在电火花下化合）
- `2NO + O₂ = 2NO₂`（NO 遇空气立即变棕色）
- `3NO₂ + H₂O = 2HNO₃ + NO`（NO₂ 溶于水制硝酸）

这三步反应构成了工业制硝酸的基础：
1. 氨催化氧化制 NO
2. NO 氧化为 NO₂
3. NO₂ 被水吸收生成 HNO₃
