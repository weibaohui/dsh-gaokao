# 硫酸盐

## 基本信息

- 属硫酸的盐类
- 硫酸为二价酸，可形成正盐和酸式盐
- 除硫酸钡（BaSO₄）、硫酸铅（PbSO₄）外，其余均能溶于水
- 硫酸钙（CaSO₄）、硫酸银（Ag₂SO₄）则微溶于水

## 重要硫酸盐（矾类）

### 1. 胆矾（CuSO₄·5H₂O）
- 为蓝色晶体
- 农业上用于杀虫（波尔多液：硫酸铜+生石灰+水）
- 用于木材防腐
- 用于提炼纯铜、镀铜、制造铜化合物

### 2. 绿矾（FeSO₄·7H₂O）
- 为淡绿色结晶
- 农业上用于杀虫（防治果园病虫害）
- 用于木材防腐
- 用于制造蓝黑墨水、普鲁士蓝（蓝色颜料）

### 3. 皓矾（ZnSO₄·7H₂O）
- 为无色晶体
- 用于木材防腐
- 用于制造白色颜料（锌白/氧化锌）
- 医药上用于配制眼药水

### 其他重要硫酸盐
| 名称 | 分子式 | 用途 |
|------|--------|------|
| 硫酸钠（芒硝） | Na₂SO₄·10H₂O | 用作医药泻药，用于玻璃工业 |
| 硫酸镁（泻盐/苦盐） | MgSO₄·7H₂O | 用作医药泻药 |

## 检验法

**硫酸和硫酸盐的检验（两步法）**：
1. 加入氯化钡（或硝酸钡）溶液 → 产生白色沉淀（BaSO₄）
   - `H₂SO₄ + BaCl₂ = BaSO₄↓ + 2HCl`
   - `Na₂SO₄ + BaCl₂ = BaSO₄↓ + 2NaCl`
2. 加入稀盐酸或稀硝酸 → 白色沉淀不溶解
   - 以此区别于碳酸盐（BaCO₃ 可溶于酸）和亚硫酸盐（BaSO₃ 可溶于酸）
