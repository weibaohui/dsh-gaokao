# 二氧化硅

## 基本信息

- 分子式：SiO₂
- 又称硅石，是硅酸的酸酐（硅酐）
- 在自然界中大量存在

## 存在形态

### 结晶形（石英）
- **水晶**：纯净的无色透明棱柱状晶体
- 含杂质时呈现颜色：紫水晶、烟水晶等
- **石英岩**：不透明的石英
- 硅石与其他硅的化合物共同构成岩石：花岗岩、片麻岩等
- 普通砂是岩石风化的产物

### 无定形
- 构成某些低级水草（藻类）的细胞壁
- **硅藻土**：由藻类堆积而成的矿层，具有多孔性，吸附力很强
- 人工也可制得粉末状的无定形硅石

## 物理性质

- 性质非常稳定
- 常温下几乎不与其他物质反应（除 HF 和浓碱外）
- 不溶于水
- 高温下能熔化，但不挥发也不分解
- 冷却后变为透明或半透明的玻璃状物质（石英玻璃）

### 石英玻璃的特性
- 能透过紫外线（普通玻璃则不能）
- 膨胀系数极小：加热至红热后立即放入冷水中也不会破裂
- 用途：用于制造透过紫外线的水银灯、石英坩埚等耐温度剧变的化学仪器

## 化学性质

属于酸性氧化物（硅酸酐），但与二氧化碳存在重要区别：

### 1. 不能直接与水反应生成硅酸
- 与 CO₂ 不同（CO₂ + H₂O = H₂CO₃）
- 硅酸只能通过间接方法制取

### 2. 与碱性氧化物/碱反应（高温）
- `SiO₂ + CaO →(强热) CaSiO₃`（硅酸钙）
- `SiO₂ + 2NaOH →(强热) Na₂SiO₃ + H₂O`（硅酸钠）

### 3. 与盐反应（高温熔融）
- `SiO₂ + Na₂CO₃ →(高温) Na₂SiO₃ + CO₂↑`
- 二氧化硅将挥发性酸酐（CO₂）置换出来
- 体现了 SiO₂ 不挥发的特性

### 4. 与氢氟酸反应（特殊性）
- 可被 HF 腐蚀（与玻璃成分中的 SiO₂ 反应）

## 与二氧化碳的比较

| 性质 | SiO₂ | CO₂ |
|------|------|-----|
| 状态 | 固体 | 气体 |
| 溶于水 | 不溶 | 溶 |
| 与水反应 | 不反应 | 生成 H₂CO₃ |
| 挥发性 | 不挥发 | 易挥发 |
| 酸性氧化物 | 是 | 是 |

## 用途

- 水晶等天然产物可直接利用
- 石英玻璃（可透过紫外线、耐温度剧变）
- 砂（在建筑工程中大量应用）
- 硅藻土（用作吸附剂）
