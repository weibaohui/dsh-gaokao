# 酸性氧化物

## 定义
能与碱反应（但不能与酸反应）生成盐和水的氧化物，称为酸性氧化物。酸性氧化物又称"酸酐"，因为可以将其视为相应含氧酸脱水后的产物。

大部分非金属的氧化物都是酸性氧化物。

## 举例

| 酸性氧化物 | 相应的水化物（酸） |
|----------|-----------------|
| SO₃ | H₂SO₄ |
| P₂O₅ | H₃PO₄ |
| CO₂ | H₂CO₃ |

## 化学性质
1. **和水的反应**：除 SiO₂ 外，酸性氧化物都能与水直接化合生成相应的水化物——含氧酸。
   - SO₃ + H₂O = H₂SO₄
   - CO₂ + H₂O = H₂CO₃
   - P₂O₅ + 3H₂O（热水）= 2H₃PO₄
2. **和碱的反应**：酸性氧化物一般不能与酸反应，但能与碱反应生成盐和水。
   - CO₂ + 2NaOH = Na₂CO₃ + H₂O
   - SO₂ + 2NaOH = Na₂SO₃ + H₂O
3. **和碱性氧化物反应**：在一定条件下能相互化合生成盐。
   - SiO₂ + PbO =(强热)= PbSiO₃

## 酸酐
含氧酸分解后产生的非金属氧化物称为该酸的"酸酐"。
- SO₃ 称为硫酸酐（硫酐）
- SO₂ 称为亚硫酸酐（亚硫酐）
- CO₂ 称为碳酸酐（碳酐）

## 制法
1. 非金属直接氧化。
2. 含氧酸分解：H₂CO₃ = CO₂↑ + H₂O；H₂SO₃ = SO₂↑ + H₂O；H₂SO₄ =(加热)= SO₃↑ + H₂O。
