# 复分解反应

## 定义
在化学反应里，两种化合物相互交换成分，生成另外两种新的化合物的反应，叫做复分解反应。

## 举例
- 碱和盐的反应：3NaOH + FeCl₃ = 3NaCl + Fe(OH)₃↓（铁原子和钠原子交换位置）
- 酸和碱的中和：NaOH + HCl = NaCl + H₂O（氢氧根和氯原子交换位置）
- 盐和盐的反应：NaCl + AgNO₃ = AgCl↓ + NaNO₃
- 酸和盐的反应：HCl + AgNO₃ = AgCl↓ + HNO₃

## 进行到近乎完全的条件
要使酸、碱、盐在溶液里发生复分解反应并进行到近乎完全，至少必须具备下面三个条件中的一个：

1. **生成难溶性的物质**（沉淀析出）——如 AgCl↓、Cu(OH)₂↓、BaSO₄↓
2. **生成挥发性的气体**——如 H₂S↑、CO₂↑、HCl↑
3. **生成水**——如中和反应

如果不具备上述任何条件，反应就不能向一个方向进行到近乎完全。例如 NaCl + KNO₃ 混和后溶液里主要仍是四种离子，蒸干后得到四种盐的混和物。

## 从电离学说解释
碱、酸、盐在溶液里的复分解反应是离子间的反应。当某些离子能结合成难溶解的沉淀、容易挥发的气体或极难电离的物质（如水），这些离子实际上从溶液里分离出来，反应就向生成这些物质的方向进行到近乎完全。

## 基本反应类型
复分解反应连同化合反应、分解反应和置换反应是化学里最基本的四类化学反应。但也有少数反应不属于这四种基本类型（如碱和非金属氧化物的作用：2NaOH + CO₂ = Na₂CO₃ + H₂O）。
