# 酸的通性

## 定义
酸类共同的化学性质，是从盐酸、硫酸、硝酸等几种酸的性质中概括得出的。除硅酸外，其余的酸都能溶于水。

## 六点通性

### 1. 和指示剂的反应
一切酸的水溶液能使紫色石蕊试液或蓝色石蕊试纸变红，不能使无色酚酞溶液变色。

### 2. 和碱的反应（中和反应）
一切酸都能与碱反应生成盐和水。
- NaOH + HCl = NaCl + H₂O

### 3. 和金属氧化物的反应
酸与金属氧化物反应生成盐和水。
- H₂SO₄ + CuO = CuSO₄ + H₂O
- 2HCl + MgO = MgCl₂ + H₂O
工业上用盐酸去除金属表面锈层（焊接时涂"盐镪水"清锈）。

### 4. 和盐的反应
酸与盐发生复分解反应，生成一种新酸和新盐。
- 2HCl + CaCO₃ = H₂CO₃ + CaCl₂（H₂CO₃ 立即分解为 CO₂ 和 H₂O）
- HCl + AgNO₃ = AgCl↓ + HNO₃

### 5. 和金属的反应（置换反应）
酸分子中的氢原子能被某些活泼金属置换，释放氢气并生成盐。
- Zn + H₂SO₄ = ZnSO₄ + H₂↑
- 2HCl + Zn = ZnCl₂ + H₂↑

只有排在金属活动性顺序表中氢左侧的金属才能从酸溶液中置换出氢。

注意：浓硫酸和硝酸（稀或浓）具有氧化性，与金属反应时不能生成氢气。

酸与金属的置换反应还与酸本身的强弱有关：强酸反应剧烈，弱酸反应缓慢。

### 6. 分解反应
含氧酸在加热时常能分解（某些不稳定的含氧酸如亚硫酸、碳酸在常温下也能自行分解），生成非金属氧化物（酸酐）和水。
- H₂SO₄ =(加热)= SO₃↑ + H₂O
- H₂CO₃ = CO₂↑ + H₂O

## 从电离学说解释
在不同酸类的水溶液中，虽然阴离子是各种不同的酸根离子，但阳离子都是带1个正电荷的氢离子。酸溶液的通性实质上是一切酸类溶液中共有的氢离子（H⁺）的性质。
