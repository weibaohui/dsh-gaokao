# 离子方程式

## 定义
用离子符号表示化学反应的方程式，叫做离子方程式。

## 优点
- 比分子方程式更能反映反应实质
- 能反映某一类反应的共同规律
- 如 Ag⁺ + Cl⁻ = AgCl↓ 表示任何可溶性银盐和任何可溶性氯化物的反应

## 书写步骤
1. 写出分子方程式
2. 将易溶强电解质改写成离子形式；非电解质、弱电解质、难溶沉淀或气体保留分子式
3. 消去等号两边相同的离子，得简化离子方程式

## 举例
以 AgNO₃ + NaCl = AgCl↓ + NaNO₃ 为例：
1. 分子方程式：AgNO₃ + NaCl = AgCl↓ + NaNO₃
2. 改写离子形式：Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ = AgCl↓ + Na⁺ + NO₃⁻
3. 消去相同离子：Ag⁺ + Cl⁻ = AgCl↓
