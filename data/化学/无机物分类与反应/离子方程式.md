# 离子方程式

## 定义
用离子符号表示化学反应的方程式，称为离子方程式。

## 优点
- 比分子方程式更能揭示反应实质
- 能反映某一类反应的共同规律

## 书写步骤
1. 写出分子方程式
2. 将易溶强电解质改写为离子形式；非电解质、弱电解质、难溶沉淀或气体保留分子式
3. 消去等号两边相同的离子，得到简化离子方程式

## 举例
以 AgNO₃ + NaCl = AgCl↓ + NaNO₃ 为例：
1. 分子方程式：AgNO₃ + NaCl = AgCl↓ + NaNO₃
2. 改写离子形式：Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ = AgCl↓ + Na⁺ + NO₃⁻
3. 消去相同离子：Ag⁺ + Cl⁻ = AgCl↓
