# 盐的性质

## 概述
盐类不存在为一切盐所共有的离子，因此无法找到为一切盐所共有的性质。盐的定义只能从分子组成这一方面来给出。

## 四点化学性质

### 1. 盐和酸起复分解反应生成新盐和新酸
- 2HCl + CaCO₃ = H₂CO₃ + CaCl₂
- HCl + AgNO₃ = AgCl↓ + HNO₃

### 2. 盐和碱起复分解反应生成新盐和新碱
- 2NaOH + CuSO₄ = Cu(OH)₂↓ + Na₂SO₄
- 3NaOH + FeCl₃ = 3NaCl + Fe(OH)₃↓

### 3. 盐和盐起复分解反应生成两种新盐
- NaCl + AgNO₃ = AgCl↓ + NaNO₃（白色沉淀）
- 需满足复分解反应进行到近乎完全的条件（生成沉淀、气体或水）。

### 4. 盐和金属的置换反应
盐分子中的金属原子能被在金属活动性顺序表中排在它前面的更活泼金属所置换，生成新盐和新金属。
- CuSO₄ + Fe = FeSO₄ + Cu（铁表面附上紫红色铜）
- CuSO₄ + Zn = ZnSO₄ + Cu

只有化学性质较为活泼的金属才能将较不活泼的金属从其盐溶液中置换出来。铜不能将铁或锌从铁盐或锌盐溶液中置换出来。

## 溶解性规律
- 钠盐、钾盐、硝酸盐均能溶于水。
- 盐酸盐中仅 AgCl、Hg₂Cl₂ 不溶，PbCl₂ 微溶。
- 硫酸盐中仅 BaSO₄、PbSO₄ 不溶，CaSO₄ 微溶。
- 大部分金属的硫化物、碳酸盐、磷酸盐、硅酸盐不溶于水，仅其钠盐、钾盐可溶。

## 从电离学说解释
盐类电离生成金属阳离子和酸根阴离子，但不存在为一切盐类所共有的阴离子或阳离子，因此盐类没有共有的通性。
