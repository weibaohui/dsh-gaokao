# 碱的通性

## 定义
碱类共同的化学性质，是从氢氧化钠、氢氧化钙等几种碱的性质中概括得出的。

## 五点通性

### 1. 和指示剂的反应
- 可溶性碱的水溶液能使紫色石蕊试液或红色石蕊试纸变蓝，使无色酚酞试液变红。
- 不溶性碱因不溶于水，不能使指示剂变色。

### 2. 和酸的反应（特征反应）
一切碱类（无论可溶或不可溶）都能与酸反应生成盐和水。
- 2NaOH + H₂SO₄ = Na₂SO₄ + 2H₂O
- Cu(OH)₂ + H₂SO₄ = CuSO₄ + 2H₂O

### 3. 和氧化物的反应
碱类能与某些氧化物（主要是非金属氧化物）反应生成盐和水。
- Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O
- 2NaOH + SO₂ = Na₂SO₃ + H₂O

### 4. 和盐的反应
可溶性碱能与盐反应生成另一种新盐和新碱。
- 3NaOH + FeCl₃ = 3NaCl + Fe(OH)₃↓（棕红色絮状沉淀）

### 5. 分解反应
不溶性碱大多不稳定，受热容易分解生成金属氧化物和水。
- Cu(OH)₂ =(加热)= CuO + H₂O
- 2Fe(OH)₃ =(加热)= Fe₂O₃ + 3H₂O
- 可溶性碱（NaOH、KOH、Ca(OH)₂）加热时不易分解。

## 从电离学说解释
碱类在水溶液中电离生成的阴离子都是氢氧根离子（OH⁻）。各种碱类水溶液所表现出的共同性质，并非碱分子本身的性质，而是各种碱类水溶液中共有的氢氧根离子的性质。
