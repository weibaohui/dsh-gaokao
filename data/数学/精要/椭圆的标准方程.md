# 椭圆的标准方程

焦点在 x 轴：`x²/a² + y²/b² = 1`（a > b > 0）；焦点在 y 轴则 x、y 互换。

## 基本量

- 焦距 c：`a² = b² + c²`（注意与双曲线 a² = b² + c² 不同！）
- 离心率：`e = c/a ∈ (0,1)`，e 越大越扁
- 顶点 (±a, 0)、(0, ±b)；焦点 (±c, 0)

## 常用结论

- 椭圆上一点到两焦点距离之和恒为 2a
- 焦点到长轴两端点距离为 a+c 与 a−c（通径相关）
- 点在椭圆内/外：代 x²/a²+y²/b² 与 1 比较

## 易错点

- "焦点在 x 轴"看分母大小：x² 下方分母大才在 x 轴
- 与双曲线公式混记
