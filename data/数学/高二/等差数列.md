# 等差数列

**定义**：从第 2 项起，每一项与前一项的差等于同一个常数 d（公差）。

## 公式

- 通项：`an = a₁ + (n−1)d`
- 前 n 项和：`Sn = n(a₁+an)/2 = na₁ + n(n−1)d/2`

## 核心性质

- 若 `m + n = p + q`，则 `am + an = ap + aq`
- **等差中项**：a、A、b 成等差 ⟺ `2A = a + b`
- Sn、S₂n−Sn、S₃n−S₂n 仍成等差
- `Sn` 是关于 n 的二次函数且常数项为 0

## 前 n 项和最值

- d < 0 时 Sn 有最大值：找最后一个非负项
- d > 0 时 Sn 有最小值：找最后一个非正项
