# 等比数列

**定义**：从第 2 项起，每一项与前一项的比等于同一个常数 q（公比，q ≠ 0）。

## 公式

- 通项：`an = a₁·qⁿ⁻¹`
- 前 n 项和：q ≠ 1 时 `Sn = a₁(1−qⁿ)/(1−q)`；q = 1 时 `Sn = na₁`

## 核心性质

- 若 `m + n = p + q`，则 `am·an = ap·aq`
- **等比中项**：a、G、b 成等比 ⟺ `G² = ab`（注意 G 有两解且需同号）

## 易错点

- 求和前**必须讨论 q = 1** 的情形
- 等比数列各项均不为 0
- q < 0 时数列正负摆动
