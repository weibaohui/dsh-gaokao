# 光合作用

**总反应式**：

`CO₂ + H₂O —光能/叶绿体→ (CH₂O) + O₂`

## 光反应（类囊体薄膜上）

- 水的光解：H₂O → [H]（NADPH）+ O₂
- ATP 的合成：ADP + Pi + 光能 → ATP
- 条件：光、色素、酶

## 暗反应/碳反应（叶绿体基质中）

- CO₂ 的固定：CO₂ + C₅ → 2C₃
- C₃ 的还原：C₃ + [H] + ATP → (CH₂O) + C₅

## 影响因素

- 光照强度：光补偿点（光合=呼吸）、光饱和点
- CO₂ 浓度、温度（影响酶活性）

## 高频曲线分析

- 突然停止光照：C₃ ↑、C₅ ↓（ATP/[H] 减少，还原受阻）
- 突然减少 CO₂：C₃ ↓、C₅ ↑

关联：与 [[细胞呼吸]] 对照记忆，净光合 = 总光合 − 呼吸。
