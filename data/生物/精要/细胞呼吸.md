# 细胞呼吸

## 有氧呼吸三阶段

1. **第一阶段（细胞质基质）**：葡萄糖 → 丙酮酸 + [H] + 少量 ATP
2. **第二阶段（线粒体基质）**：丙酮酸 + H₂O → CO₂ + [H] + 少量 ATP
3. **第三阶段（线粒体内膜）**：[H] + O₂ → H₂O + 大量 ATP

总反应式：`C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量`

## 无氧呼吸（细胞质基质）

- 酒精发酵：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ + 少量能量（酵母菌、植物）
- 乳酸发酵：C₆H₁₂O₆ → 2C₃H₆O₃ + 少量能量（乳酸菌、动物肌细胞）

## 易错点

- 无氧呼吸只在**第一阶段**释放能量产生 ATP
- O₂ 只参与有氧呼吸第三阶段，CO₂ 产生于第二阶段
- 见 [[光合作用]] 比较：光合储能，呼吸释能
