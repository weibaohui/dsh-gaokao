# 简谐振动的合成

## 同一直线上同频率的合成
两个频率相同的简谐振动合成之后，合运动仍是同频率的简谐振动：

x = Acos(ωt + φ)

其中：
- 振幅：A = √(A₁² + A₂² + 2A₁A₂cos(φ₂ - φ₁))
- 初相：tanφ = (A₁sinφ₁ + A₂sinφ₂)/(A₁cosφ₁ + A₂cosφ₂)

## 特殊情况
- **同相**（位相差 = 2Kπ）：两振动步调一致，合振幅最大 A = A₁ + A₂
- **反相**（位相差 = (2K+1)π）：两振动步调相反，合振幅最小 A = |A₁ - A₂|

## 旋转矢量法
用旋转矢量来表示简谐振动，通过矢量合成（平行四边形法则）求出合振动。旋转矢量的模为振幅，与 x 轴的夹角为位相。

## 频率成倍数的合成
两个频率成简单整数比的简谐振动合成后，合振动具有周期性，其频率等于最低的频率（即基频）。
