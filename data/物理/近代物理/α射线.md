# α射线

## 定义
在放射性衰变过程中释放出的α粒子流，其本质是氦原子核（⁴₂He）

## 基本性质
| 性质 | 数值 |
|------|------|
| 本质 | 氦核（⁴₂He） |
| 电荷 | +2e |
| 质量 | 4倍氢原子质量 |
| 速度 | ≤c/10 |
| 电离能力 | 最强 |
| 穿透能力 | 最弱（空气中cm级） |

## 特点
- 电离本领居三种射线之首，而穿透本领则最弱
- 仅凭一张薄纸就能将其拦截
