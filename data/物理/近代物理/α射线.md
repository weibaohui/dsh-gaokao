# α射线

## 定义
放射性衰变中放出的α粒子流，本质为氦核（⁴₂He）

## 基本性质
| 性质 | 数值 |
|------|------|
| 本质 | 氦核（⁴₂He） |
| 电荷 | +2e |
| 质量 | 4倍氢原子质量 |
| 速度 | ≤c/10 |
| 电离能力 | 最强 |
| 穿透能力 | 最弱（空气中cm级） |

## 特点
- 电离能力最强，但穿透能力最弱
- 一张纸即可挡住
