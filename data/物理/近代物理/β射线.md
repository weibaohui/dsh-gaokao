# β射线

## 定义
放射性衰变中放出的β粒子流，本质为高速电子（⁰₋₁e）

## 基本性质
| 性质 | 数值 |
|------|------|
| 本质 | 高速电子（⁰₋₁e） |
| 电荷 | -e |
| 质量 | 1/7200个α粒子 |
| 速度 | ≤0.9995c |
| 电离能力 | 较弱 |
| 穿透能力 | 较强（铝中mm级） |

## 特点
- 电离能力较弱，穿透能力较强
- 需铝板才能挡住
