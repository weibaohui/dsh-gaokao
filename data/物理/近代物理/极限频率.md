# 极限频率

## 定义
能使某种金属发生[[光电效应]]的最小入射光频率，记作ν₀

## 公式

$$\nu_0 = \frac{W}{h}$$

- W：金属的逸出功
- h：普朗克常数 = 6.63×10⁻³⁴ J·s

## 物理意义
- 只有当入射光频率 ν ≥ ν₀ 时，才会发生光电效应
- 当 ν < ν₀ 时，无论光多强、照射多久都不会发生光电效应
- 不同金属的逸出功不同，因而极限频率也不同

## 典型金属极限频率
| 金属 | 极限频率(Hz) |
|------|-------------|
| 铯 | 4.515×10¹⁴ |
| 钠 | 6.000×10¹⁴ |
| 锌 | 8.065×10¹⁴ |
| 银 | 1.158×10¹⁵ |
| 铂 | 1.529×10¹⁵ |
