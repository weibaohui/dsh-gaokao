# γ射线

## 定义
放射性衰变时释放出的γ射线，本质为光子形态的电磁波，其频率高于3×10¹⁹ Hz

## 基本性质
| 性质 | 数值 |
|------|------|
| 本质 | 电磁波/光子 |
| 电荷 | 0 |
| 质量 | 0 |
| 速度 | c（光速） |
| 电离能力 | 最弱 |
| 穿透能力 | 最强（铅中m级） |

## 特点
- 电离本领最弱，而穿透本领最强
- 要用厚铅板或混凝土才能有效屏蔽
- γ衰变过程中核电荷数与质量数均保持不变

## 应用
- 医学领域：用于癌症放射治疗（Co-60）
- 工业领域：用于内部缺陷的γ探伤
- 与[[电磁波谱]]相关
