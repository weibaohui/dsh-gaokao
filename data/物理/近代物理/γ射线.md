# γ射线

## 定义
放射性衰变中放出的γ射线，本质为电磁波（光子），频率 >3×10¹⁹ Hz

## 基本性质
| 性质 | 数值 |
|------|------|
| 本质 | 电磁波/光子 |
| 电荷 | 0 |
| 质量 | 0 |
| 速度 | c（光速） |
| 电离能力 | 最弱 |
| 穿透能力 | 最强（铅中m级） |

## 特点
- 电离能力最弱，穿透能力最强
- 需厚铅板或混凝土才能挡住
- γ衰变不改变核电荷数和质量数

## 应用
- 医学：癌症治疗（Co-60）
- 工业：γ探伤
- 关联到[[电磁波谱]]
