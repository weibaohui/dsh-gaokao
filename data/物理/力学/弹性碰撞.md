# 弹性碰撞

## 定义
动能和动量都守恒的碰撞（如钢球、象牙球碰撞）。

## 公式（一维正碰）
- 动量守恒：m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'
- 动能守恒：½m₁v₁² + ½m₂v₂² = ½m₁v₁'² + ½m₂v₂'²

## 解得
- v₁' = [(m₁-m₂)v₁ + 2m₂v₂]/(m₁+m₂)
- v₂' = [2m₁v₁ + (m₂-m₁)v₂]/(m₁+m₂)

## 特殊情况
1. m₁ = m₂：交换速度（v₁' = v₂，v₂' = v₁）。若v₂ = 0则v₁' = 0，v₂' = v₁
2. m₂ ≫ m₁且v₂ = 0：v₁' ≈ -v₁（弹回），v₂' ≈ 0（如球碰墙）
