# 虚拟语气

表示与事实相反的假设或主观愿望。

## if 条件句三种时态

| 时间 | if 从句 | 主句 |
|------|---------|------|
| 现在相反 | did / were | would do |
| 过去相反 | had done | would have done |
| 将来相反 | did / were to do / should do | would do |

- If I **were** you, I would accept it.（表现在）
- If he **had come** yesterday, he **would have met** her.（表过去）

## 其他常考结构

- wish + 从句：现在用 did，过去用 had done，将来用 would do
- would rather + 从句：did（表现在将来）/ had done（表过去）
- suggest / demand / order / insist（坚持要求）+ that 从句用 **(should) do**
- It is important / necessary that... **(should) do**
- as if 从句：did / had done

## 易错点

- suggest 表"表明"、insist 表"坚持认为"时**不用**虚拟
- 错综时间条件句：从句表过去、主句表现在
